# Assign a workspace moderator

Complete the following steps to assign a new moderator to Automation HQ:

1. Sign in to your Workato account.
   
2. Go to **Automation HQ** and select the **Workspace moderators** tab.
   
   ![Workspace moderators table](/assets/workspace-moderator-table.B2-_l97V.png)_Workspace moderators table_
   
3. Click the **\+ Assign workspace moderators** button. The **Assign workspace moderator** interface appears.
   
   ![Add workspace moderator interface](/assets/workspace-moderator-assign-workspace.BuWuEfpL.png)_Add workspace moderator interface_
   
4. Select a collaborator from the **Collaborator** drop-down menu.
   
5. Assign an **Environment role**. This role applies across all managed workspaces the moderator can access. Refer to the [Environment roles](/en/user-accounts-and-teams/role-based-access/new-model/system-environment-roles) documentation to learn more about the permissions included in each role.
   
6. Assign a **Project role**. This role defines project-level access and applies across all managed workspaces. Refer to the [Project roles](/en/user-accounts-and-teams/role-based-access/new-model/system-project-roles) documentation for available permissions.
   
7. Optional. Toggle **Manage all workspaces** to grant the moderator access to all current and future managed workspaces. If disabled, manually select one or more workspaces from the list.
   
8. Click **Assign workspace moderator** to complete the process. Workato adds the new moderator to the workspace moderator interface.
   

The collaborator is now assigned as a workspace moderator with the specified environment and project roles.
