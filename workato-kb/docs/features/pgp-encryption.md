# Encrypt and decrypt files with PGP

Use PGP encryption to secure files before you transfer them between systems or store them in shared environments. PGP (Pretty Good Privacy) combines symmetric encryption with public and private key cryptography to protect confidentiality, ensure data integrity, and confirm authenticity.

Workato supports PGP encryption and decryption through the [PGP tools by Workato](/en/connectors/pgp-by-workato) connector. This connector allows you to encrypt sensitive data, decrypt files securely, and verify or sign messages.

## Set up PGP tools by Workato

Complete the following steps before you use the PGP tools by Workato connector:
