> View and filter the Workato activity audit log by period, collaborators, clients, and asset type from the Operations hub.

# View audit logs

Users with the [required access](/en/features/activity-audit-log#view-logs) can view audit activity logs by navigating to **Operations hub > Activity audit**.

Use the filters at the top of the page to filter logs based on selected criteria. For example: To view a specific user's activities, click **All users** and select the user from the menu.

* * *

## Filter the activity audit log

The activity audit log enables you to filter activity based on (time) **Period**, **Collaborators/clients**, and **Asset** type.

Period

Filter the activity audit log by time period.

**Available filters:**

- Last hour
- Last 24 hours
- Last 7 days
- Last 30 days
- Any time
- Custom range

Collaborators/clients

Filter the activity audit log by the collaborators and/or API clients in your workspace.

**Available filters:**

- All collaborators/clients
- Specific collaborators in your workspace
- Specific API clients in your workspace

Asset

Filter the activity audit log by asset type.

**Available filters:**

- API Access profiles
- API clients
- API collections
- API endpoints
- API policies
- Account
- Workflow apps portal
- Common data models
- Connections
- Custom apps
- Custom connectors
- Data tables
- Environment properties
- Lookup tables
- Message templates
- On-prem agent
- On-prem group
- Packages
- Pages
- Project properties
- Projects & Folders
- Event topics
- Recipes
- Resource
- Test case

* * *

## Stream activity audit logs

To ensure logs are retained according to your needs, we recommend using the **Activity log streaming** feature.

When configured, this feature streams audit log data to the destination of your choice. Refer to the [Audit log streaming guide](/en/features/activity-audit-log-streaming) for more information.
