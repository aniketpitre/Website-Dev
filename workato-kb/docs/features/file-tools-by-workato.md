# File tools by Workato

File tools by Workato is a versatile and powerful connector designed to facilitate the handling and movement of files within your automated workflows.

## Use cases

Explore the capabilities of the File tools by Workato connector in our [use cases](/en/getting-started/workato-use-cases) documentation. Discover how you can use the File tools by Workato connector to create powerful multi-app workflows and automations:

- Use the [Get file from URL](/en/features/get-file-from-url) action to create a recipe that [automatically transfers new and updated field reports](/en/getting-started/use-cases/plangrid-sharepoint) from PlanGrid to Microsoft SharePoint.
- Use the [Compress files](/en/features/compress-files) action to create a [recipe](/en/features/compress-files#example-compress-all-files-in-a-folder) that downloads file contents from multiple apps, compresses the downloaded files into a single zip file, and sends the zip file as an email attachment.
- Use the [Uncompress a file](/en/features/uncompress-files) action to build a [recipe](/en/features/uncompress-files#example-uncompress-a-zip-file) that unzips a file, extracts its contents, parses the CSV data if applicable, and bulk upserts records into NetSuite.
