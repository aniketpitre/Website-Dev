# User interface

Workato’s **Data tables** interface exists at the project level. It enables you to manage your data tables within a specific project through the Workato UI.

![Data tables interface](/assets/image15.C9MysqOl.png)_Manage your data tables_

This interface allows you to:

- [Create a new table](/en/data-tables/user-interface/create)
- [Create a new column](/en/data-tables/user-interface/column-create)
- [Edit a column](/en/data-tables/user-interface/column-edit)
- [Delete a column](/en/data-tables/user-interface/column-delete)
- [View table data](/en/data-tables/user-interface/view)
- [Edit table data](/en/data-tables/user-interface/edit)
- [Rename a data table](/en/data-tables/user-interface/rename)
- [Delete a data table](/en/data-tables/user-interface/delete)
- [Download a data table as CSV](/en/data-tables/user-interface/download-csv)
