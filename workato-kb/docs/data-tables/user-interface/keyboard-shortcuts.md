> Reference for Workato data table keyboard shortcuts on Mac and Windows for selecting, editing, and managing table data.

# Keyboard shortcuts

The following keyboard shortcuts enable you to manage table data using your keyboard. Keyboard shortcuts are available for both Mac and Windows operating systems.

* * *

## Mac shortcuts

<dl><dt>?</dt><dd>Show/hide the help menu</dd><dt>command + s</dt><dd>Save table</dd><dt>command + space</dt><dd>Select column</dd><dt>shift + space</dt><dd>Select record</dd><dt>shift + ↑</dt><dd>Select range of records (ascending)</dd><dt>shift + ↓</dt><dd>Select range of records (descending)</dd><dt>command + i</dt><dd>Insert column</dd><dt>shift + enter</dt><dd>Add record</dd><dt>enter</dt><dd>Edit selected cell</dd><dt>command + ↑</dt><dd>Jump to the edge of the table</dd><dt>command + ↓</dt><dd>Jump to the edge of the table</dd><dt>command + →</dt><dd>Jump to the edge of the table</dd><dt>command + ←</dt><dd>Jump to the edge of the table</dd><dt>tab</dt><dd>Move between cells (forward)</dd><dt>shift + tab</dt><dd>Move between cells (backward)</dd></dl>

* * *
