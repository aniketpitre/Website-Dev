# Delete a column

Deleting a column is a permanent action and cannot be undone.

![Data tables](/assets/delete-column.BLsWRHoM.png)_Delete a column_

To delete a column:

1. Hover over the column name.
   
2. Click ... (ellipsis).
   
3. Select **Delete column**.
