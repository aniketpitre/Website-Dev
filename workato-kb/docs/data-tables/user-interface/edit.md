> Edit Workato data table data by adding, updating, and deleting rows using your mouse or keyboard shortcuts in the data tables interface.

# Edit table data

The Data tables interface supports editing and deleting table data. You can interact with your data using your mouse or by using [keyboard shortcuts](/en/data-tables/user-interface/keyboard-shortcuts).

* * *

## Add a new row

Data tables support up to 1,000,000 (one million) records/rows for each data table. Workato numbers each row on the left side of the table.

![Data tables](/assets/add-row.Cy67WIWz.png)_Add a new row to your data table_

To add a new row to a data table:

1. In your data table, click **+** underneath the row numbers.
   
2. Enter information into each column field.
   
3. Click ✓ (checkmark) to save column data.
   

* * *

### Add a new row using keyboard shortcuts

1. Press **shift + enter**.
   
2. Enter information into each cell. Use **tab** and **tab + shift** to navigate between cells.
   
3. Press **command/ctrl + s** to save column data.
   

* * *

## Edit a row

You can edit the data in a row. A row is a complete record of data.

![Data tables](/assets/edit-row.DzMTD6wz.png)_Edit a row in a data table_

To edit a row:

1. Click into the table cell you plan to modify, and make the necessary changes.
   
2. Edit additional cells in that row if necessary.
   
3. Click **✓** (checkmark) to save column data.
   
4. To discard your changes, click **x** (remove).
   

### Edit a row using keyboard shortcuts

1. Select a cell by clicking into it.
   
2. Press **enter**.
   
3. Make the necessary changes.
   
4. Press **command/ctrl + s** to save your changes.
   

* * *

## Delete a row

You can delete the data in a row.

![Data tables](/assets/delete-row.sq0Y1I2g.png)_Delete one or more rows_

To delete a row:

1. Select one or more row numbers of the rows you plan to delete. Row numbers appear on the left side of the table.
   
   You can also select entries and right-click to delete them.
   
2. Click **Delete**.
