> Add or update users and assign Admin or Analyst roles in the ELT Pipeline for Snowflake accelerator from the App homepage.

# Add/update user

This guide describes features that are only available to users with an **Admin** role.

To add or update a user:

1. Open Slack or Microsoft Teams and navigate to the **App homepage**.
   
2. Select **Add/Update User**.
   
3. Configure the input fields in the **Add/Update User** interface.
   
   <dl><dt>User email</dt><dd>This is the Slack email of a user who plans to use the ELT Pipeline Bot.</dd><dd><dl class="horizontal-dl"><dt>Sample value:</dt><dd>lucycarrigan@example.com</dd></dl></dd><dt>Role</dt><dd>A user's role determines their permissions when interacting with the ELT Pipeline Bot.</dd><dd><dl class="horizontal-dl"><dt>Analyst</dt><dd>Analysts can create, search, and see their own pipelines. Analysts cannot perform actions on pipelines created by other users.</dd><dt>Admin</dt><dd>Admins can create, search, and edit their own pipelines. Admins can also perform these actions on pipelines created by other users.</dd></dl></dd><dt>User status</dt><dd>Defines if the user has access to the App home page.</dd><dd><dl class="horizontal-dl"><dt>Allowed values:</dt><dd><ul><li>Active</li><li>Inactive</li></ul></dd></dl></dd></dl>
   
4. Click **Submit**.
