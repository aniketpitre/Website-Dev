# AIML accelerator installation guide

## Prerequisites

- You must have a Workato subscription.
- You must have access to AWS Sagemaker.
- You must have the `AIML Accelerator.zip` package.

## Install the asset package

To install the package into your workspace:

1. In Workato, create a new project. Name the project **AIML**.
   
2. Import the package `AIML Accelerator.zip` using the [Recipe Lifecycle Management](/en/recipe-development-lifecycle/import) tool or with the [Import package into a folder API.](/en/workato-api/recipe-lifecycle-management#import-package-into-a-folder)
