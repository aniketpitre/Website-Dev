# Embedded Partner API FAQs

Get answers to frequently asked questions (FAQs) about Embedded partner APIs.

What are Embedded Partner APIs?

[Embedded Partner APIs](/en/oem/oem-api#embedded-api) are a collection of endpoints for interacting with customers, recipes, and more.

How do I know which base URL to use?

The [base URL](/en/oem/oem-api#base-url) of your endpoint depends on the data center you use. Here are the base URLs for each of Workato's data centers:

- **US Data Center**: [https://app.workato.com/api/](https://app.workato.com/api/)
- **EU Data Center**: [https://app.eu.workato.com/api/](https://app.eu.workato.com/api/)
- **JP Data Center**: [https://app.jp.workato.com/api/](https://app.jp.workato.com/api/)
- **SG Data Center**: [https://app.sg.workato.com/api/](https://app.sg.workato.com/api/)
- **AU Data Center**: [https://app.au.workato.com/api/](https://app.au.workato.com/api/)
- **IL Data Center**: [https://app.il.workato.com/api/](https://app.il.workato.com/api/)
- **CN Data Center**: [https://app.workatoapp.cn/api/](https://app.workatoapp.cn/api/)
- **KR Data Center**: [https://app.kr.workato.com/api/](https://app.kr.workato.com/api/)
- **UK Data Center**: [https://app.uk.workato.com/api/](https://app.uk.workato.com/api/)

Will a deprecated endpoint continue to work?

Yes, [deprecated endpoints](/en/oem/oem-api/managed-users#quick-reference) will continue to work, but will not be updated after deprecation.

How can I access Embedded API endpoints?

You must have an Embedded workspace to access [Embedded API endpoints](/en/oem/oem-api/api-platform#api-platform). Contact your Workato representative for more information.

What is a bearer token?

A [bearer token](/en/oem/oem-api#authentication) is a simplified way to authenticate and authorize access to web applications and APIs. Bearer tokens store user credentials and authorization for access and requests.
