# Embedded API - Dynamic field mapping

Use the Dynamic field mapping endpoints to build a customized user experience for your end customers. Dynamic field mapping APIs work alongside the other features of [Dynamic field mapping](/en/oem/dynamic-field-mapping).

## Roles and permissions

You must ensure that the customer workspace API client role is scoped to use Dynamic field mapping endpoints.

> **401 UNAUTHORIZED PERMISSION ERROR**
> 
> Your customers may receive a `401 unauthorized` error message if you don't grant specific permissions for Dynamic field mapping endpoints.

Complete the following steps to scope Dynamic field mapping permissions in a customer workspace:

1. Sign in to your Workato account.
   
2. Go to **Workspace Admin > API Clients > Client Roles**.
   
3. Locate and expand the **Data Mapper and Field maps introspection** section.
   
4. Select the endpoints to which you plan to grant customer permissions.
   
5. Click **Save changes**.
   

## Rate limits

Dynamic field mapping resources have the following rate limit:

| Type | Resource | Quota |
| --- | --- | --- |
| All | All [Dynamic field mapping](/en/oem/oem-api/dynamic-field-mapping.html) endpoints | 60 requests per minute |

### Quick reference

| Type | Resource | Description |
| --- | --- | --- |
| GET | [/api/v2/managed\_users/:managed\_user\_id /recipes/:recipe\_id/field\_map\_introspections](#list-all-field-map-introspections-in-a-recipe) | List all field map introspections in a specific recipe. |
| GET | [/api/v2/managed\_users/:managed\_user\_id /recipes/:recipe\_id/field\_map\_introspections/:id](#list-field-map-introspections-for-a-specific-field-map-schema) | List the field map introspections for a specific field map schema. |
| PUT | [/api/v2/managed\_users/:managed\_user\_id /recipes/:recipe\_id/field\_map\_introspections/:id](#update-field-map-introspections) | Update field mapping for a specific field map schema. |
| PUT | [/api/v2/managed\_users/:managed\_user\_id /recipes/:recipe\_id/field\_map\_introspections](#update-field-map-introspections-batch) | Update field mapping for multiple field map schemas. |
| POST | [/api/v2/managed\_users/:managed\_user\_id /recipes/:recipe\_id/field\_map\_introspections/:id /refresh\_schema](#refresh-field-map-schema) | Refresh a recipe’s schema to update field map introspections. |
| POST | [/api/v2/managed\_users/:managed\_user\_id /recipes/:recipe\_id/field\_map\_introspections/:id/pick\_list](#retrieve-picklist-values-for-field-map-introspections) | Retrieve picklist values for specific fields within a field map introspection of a recipe. |

> **DYNAMIC FIELD MAPPING V2 ENDPOINT PATH**
> 
> All Dynamic field mapping endpoints use a new `v2` path, which has been included in the documentation. The [base URL](/en/oem/oem-api#base-url) is unchanged.

## List all field map introspections in a recipe

<api-code no-copy-method>

```
GET https://YOUR_DATA_CENTER/api/v2/managed_users/:managed_user_id/recipes/:recipe_id/field_map_introspections
```

</api-code>

### URL parameters

| Name | Type | Description |
| --- | --- | --- |
| managed\_user\_id | **string** _required_ | Embedded customer ID/external ID. External ID must be prefixed with an E (for example, EA2300) and the resulting ID should be URL encoded. |
| recipe\_id | **string** _required_ | The ID of the recipe. |

### Sample request

<api-code>

```shell
curl --location 'https://YOUR_DATA_CENTER/api/v2/managed_users/:managed_user_id/recipes/:recipe_id/field_map_introspections' \
--header 'Accept: */*' \
-H 'Authorization: Bearer <api_token>'
```

</api-code>

## Update field map introspections

<api-code no-copy-method>

```
PUT https://YOUR_DATA_CENTER/api/v2/managed_users/:managed_user_id/recipes/:recipe_id/field_map_introspections/:id
```

</api-code>

### URL parameters

| Name | Type | Description |
| --- | --- | --- |
| managed\_user\_id | **string** _required_ | Embedded customer ID/external ID. External ID must be prefixed with an E (for example, EA2300) and the resulting ID should be URL encoded. |
| recipe\_id | **string** _required_ | The ID of the recipe. |
| id | **string** _required_ | Field map introspection ID. |

### Payload

| Name | Type | Description |
| --- | --- | --- |
| field\_map\_schema | **array** _required_ | The field map schema list. |
| field\_map\_schema\[type\] | **string** _required_ | The field map schema type. Use `map` when mapping input data to a target field. Use `static` when input data should remain unchanged or unedited. Use `nullify` when a field must be set to `null` for specific use cases. Use `skip` when no value should be passed for a field, leaving its current value unchanged. |
| field\_map\_schema \[source\_line\] | **string** _required_ | Value of the `line_ref` from the `sources` list. Found in the responses of the [List field map introspections by recipe](#list-all-field-map-introspections-in-a-recipe) and [List field map introspections by field map schema](#list-field-map-introspections-for-a-specific-field-map-schema) endpoints. |
| field\_map\_schema \[source\_provider\] | **string** _required_ | Required if type is `map`. Value of the `provider` from the `sources` list. Found in the responses of the [List field map introspections by recipe](#list-all-field-map-introspections-in-a-recipe) or [List field map introspections by field map schema](#list-field-map-introspections-for-a-specific-field-map-schema) endpoints. |
| field\_map\_schema \[source\_path\] | **string** _required_ | Required if type is `map`. Path of the source field for mapping. This `path` is defined in introspection responses `sources[].full_output_schema[].path` or `targets[].full_input_schema[].path`. Include that `path` as the `source_path` in the update payload. The `path` value can be nested depending on the step’s schema. |
| field\_map\_schema \[value\] | **string** _optional_ | Value of target for static mapping. Required if type is `static`. |
| field\_map\_schema \[target\_path\] | **string** _required_ | Path of the target field. The `path` value can be nested depending on the step’s schema. |

## Update field map introspections (batch)

Update field mappings for multiple field map schemas in a single request.

This endpoint matches the [Update field map introspections](#update-field-map-introspections) endpoint, except that it doesn't require a field map introspection ID.

<api-code no-copy-method>

```
PUT https://YOUR_DATA_CENTER/api/v2/managed_users/:managed_user_id/recipes/:recipe_id/field_map_introspections
```

</api-code>

### URL parameters

| Name | Type | Description |
| --- | --- | --- |
| managed\_user\_id | **string** _required_ | Embedded customer ID/external ID. External ID must be prefixed with an E (for example, EA2300) and the resulting ID must be URL encoded. |
| recipe\_id | **string** _required_ | The ID of the recipe. |

### Payload

This endpoint uses the same payload structure as the [Update field map introspections](#update-field-map-introspections) endpoint.

| Name | Type | Description |
| --- | --- | --- |
| field\_map\_schema | **array** _required_ | The field map schema list. |
| field\_map\_schema \[type\] | **string** _required_ | The field map schema type. Use `map` when mapping input data to a target field. Use `static` when input data must remain unchanged or unedited. Use `nullify` when a field must be set to `null` for specific use cases. Use `skip` when no value is be passed for a field, leaving its current value unchanged. |
| field\_map\_schema \[source\_line\] | **string** _required_ | Value of the `line_ref` from the `sources` list. Found in the responses of the [List field map introspections by recipe](#list-all-field-map-introspections-in-a-recipe) and [List field map introspections by field map schema](#list-field-map-introspections-for-a-specific-field-map-schema) endpoints. |
| field\_map\_schema \[source\_provider\] | **string** _required_ | Required if type is `map`. Value of the `provider` from the `sources` list. Found in the responses of the [List field map introspections by recipe](#list-all-field-map-introspections-in-a-recipe) or [List field map introspections by field map schema](#list-field-map-introspections-for-a-specific-field-map-schema) endpoints. |
| field\_map\_schema \[source\_path\] | **string** _required_ | Required if type is `map`. Path of the source field for mapping. This `path` is defined in introspection responses `sources[].full_output_schema[].path` or `targets[].full_input_schema[].path`. Include that `path` as the `source_path` in the update payload. The `path` value can be nested depending on the step’s schema. |
| field\_map\_schema \[value\] | **string** _optional_ | Value of target for static mapping. Required if type is `static`. |
| field\_map\_schema \[target\_path\] | **string** _required_ | Path of the target field. The `path` value can be nested depending on the step’s schema. |

```json
{ "field_map_schema": [ { "type": "map", "source_line": "df955367", "source_path": [ "payload", "data", "firstName" ], "target_path": [ "FirstName" ] }, { "type": "map", "source_line": "df955367", "source_path": [ "payload", "data", "lastName" ], "target_path": [ "LastName" ] }, { "type": "map", "source_line": "df955367", "source_path": [ "payload", "data", "company" ], "target_path": [ "Company" ] }, { "type": "map", "source_line": "df955367", "source_path": [ "payload", "data", "industry" ], "target_path": [ "Industry" ] }, { "type": "static", "value": "N/A", "target_path": [ "City" ] }, { "type": "nullify", "target_path": [ "AnnualRevenue" ] }, { "type": "skip", "target_path": [ "assignment_rule_id" ] }, { "type": "static", "value": "ABC", "target_path": [ "SICCode__c" ] } ] }
```

## Retrieve picklist values for field map introspections

<api-code no-copy-method>

```
POST https://YOUR_DATA_CENTER/api/v2/managed_users/:managed_user_id/recipes/:recipe_id/field_map_introspections/:id/pick_list
```

</api-code>

### URL parameters

| Name | Type | Description |
| --- | --- | --- |
| managed\_user\_id | **string** _required_ | Embedded customer ID/external ID. External ID must be prefixed with an E (for example, EA2300) and the resulting ID should be URL encoded. |
| recipe\_id | **string** _required_ | The ID of the recipe. |
| id | **string** _required_ | Field map introspection ID. |

### Payload

| Name | Type | Description |
| --- | --- | --- |
| pick\_list\_path | **array** _required_ | The picklist field path. |
| field\_map\_schema | **array** _required_ | The field map schema list. This must include all mappings that you set at the point of picklist rendering if you have picklist-dependent values selected. |
| field\_map\_schema\[type\] | **string** _required_ | Values can be: `map`, `static`, `nullify`, or `skip`. |
| field\_map\_schema\[source\_provider\] | **string** _optional_ | Source provider for mapping. Required if type is `map`. |
| field\_map\_schema\[source\_path\] | **string** _optional_ | Path of the source field for mapping. Required if type is `map`. |
| field\_map\_schema\[value\] | **string** _optional_ | Value of target for static mapping. Required if type is `static`. |
| field\_map\_schema\[target\_path\] | **string** _required_ | Path of the target field. |

<api-code>

```shell
curl --location 'https://YOUR_DATA_CENTER/api/v2/managed_users/:managed_user_id/recipes/:recipe_id/field_map_introspections/:id/pick_list' \ --header 'Content-Type: application/json' \ --header 'Authorization: Bearer <api_token>' \ --data '{ "pick_list_path": [ ":pick_list_path_value" ], "field_map_schema": [{ "type": "map", "source_line": ":source_line", "source_path": [":source_path_value"], "target_path": [":target_path_value"] }] }'
```

</api-code>
