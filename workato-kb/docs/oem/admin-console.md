# Embedded Admin console

The Admin console is the central hub for Embedded partners to manage, monitor, and provision customers. Partners can access sharing settings, customer information, and usage metrics through the Admin console.

> **AGGREGATION OF METRICS**
> 
> If environments are enabled, connection and task metrics are aggregated across all customer environments.

![Admin console](/assets/admin-console-dashboard2.2Y493cep.png)_Embedded Admin console_

## Accessing the Admin console

1. Log in as one of the following:
   
   - **Owner of the partner team account.**
   - **Member of the Admin team.** To add members to the Admin team, refer to [Teams and collaboration](/en/user-accounts-and-teams/team-collaboration).
   - **Collaborator with [sufficient privileges](/en/user-accounts-and-teams/role-based-access/new-model/privileges-reference#manage-customers).** If you have a role that grants permission to create and edit other roles, you can assign granular RBAC privileges to a custom role. This allows you to give a collaborator access to one or more tabs in the Admin console.
2. Access the Admin console from the navigation bar by selecting either **Manage customers** or **Admin > Manage customers**. Your permissions determine which link is visible.
   

## Admin console tabs

The Admin console contains the following tabs:

- [Customers](/en/oem/admin-console/customers)
- [Customer managers](/en/oem/admin-console/customer-managers)
- [Shared connectors](/en/oem/admin-console/shared-connectors#shared-connectors)
- [Usage metrics](/en/oem/admin-console/usage-metrics)
- Settings (to manage [Audit log streaming](/en/oem/admin-console/settings) and [Branding](/en/oem/branding))

> **AUDIT LOG STREAMING TAB ACCESS**
> 
> Note that the [Audit log streaming](/en/oem/admin-console/settings) tab is only visible to admins and workspace owners. Collaborators with access to the [Settings](/en/user-accounts-and-teams/role-based-access/new-model/privileges-reference#manage-customers) tab only have the ability to manage branding.
