# Workspaces in Automation HQ

The **Workspaces** interface clearly lists all workspaces in the organization, **Billable recipes** used and the quota allowed for each workspace, **Tasks used in billing period** and the quota permitted, the number of **Collaborators** in each workspace, and the **Connected apps** in each workspace.

_Managed workspaces in HQ workspace_

## Details of workspaces

<dl><dt>Billable recipes</dt><dd>This column reports the <strong>number</strong> of billable recipes as a fraction of the <strong>quota</strong>, or the maximum number of recipes allocated to the workspace. If the number of recipes is approaching the quota, Workato renders the numbers in red, to alert users that they should review and adjust quotas.</dd><dt>Tasks used in billing period</dt><dd>In this column, you can see the number of <strong>tasks</strong> used in the workspace from the beginning of the billing period, as a fraction of the <strong>quota</strong>, or the maximum number of tasks allocated to the workspace. If the number of tasks is approaching the quota, Workato renders the numbers in red, to alert users that they should review and adjust quotas.</dd><dt>Collaborators</dt><dd>The system reports the number of collaborators in the managed workspace.</dd><dt>Connected apps</dt><dd>This column contains the logos of the apps that the managed workspace can access.</dd></dl>

## Search

The **Search** bar helps you find the correct workspace by name.

## Create a workspace

To create a new workspace in Automation HQ, follow the instructions in [Create a managed workspace](/en/ahq-managed-workspace-create).

## Details of a workspace

You can easily have a more detailed view of each [workspace](/en/ahq-managed-workspace) that Automation HQ manages by clicking the name of that workspace.
