# View Test case

This article contains useful information about viewing and understanding a test case.

To view a test case, select a recipe and navigate to **Test cases**.

## Mock badge

Workato applies a **Mocked** badge to every step you mock in your test case.

![Mock badge](/assets/mock-badge.B5Dgb7Mp.png)_Mock badge_

* * *

## Check badge

Workato applies a **{N} checks** badge to every step in your test case that has checks, where **{N}** is a variable equal to the number of checks applied to the step.

![Check badge](/assets/check-badge.CGrDGbMM.png)_Check badge_

* * *

## Mock and check badges

Workato applies a **Mocked | {N} checks** badge to steps in your test case that are mocked and have checks.

![Mock and check badges](/assets/check-mock-badge.CIuknAqJ.png)_Check and mock badges_

* * *

## View step input config

You can view the step input config for each step in your test case.

1. To view the config, select a step.
   
2. Select the **Input** tab from the right panel.
   
3. View/modify the fields that appear.
   
   ![View step input](/assets/view-step-input.-qZDrBQB.png)_View step input_
