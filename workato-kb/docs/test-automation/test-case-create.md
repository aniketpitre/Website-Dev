# Create a test case

Create a test case at the recipe-level.

1. Click **New test case**.
   
2. The **Test case** interface appears.
   
3. Give the test case a unique, descriptive name.
   
   ![Name the test case](/assets/test-case-name.Cc3qQWKB.png)_Name the test case_
