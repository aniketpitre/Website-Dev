# Workspace-level dashboards

The guide demonstrates how to create an Insights dashboard at the workspace-level. Refer to the [Create a Workflow apps dashboard](/en/insights/workflow-app-dashboard-add) to learn how to create a dashboard within a Workflow app.

## Create a workspace dashboard

Complete the following steps to create a workspace-level dashboard:

1. Go to **Platform > Insights** in Workato using the side navigation bar.
   
2. Click **+** (plus) to create a new dashboard.
   
   ![Create a new dashboard](/assets/dashboard-create.CKu0GHIu.png)_Create a new dashboard_
   
3. Name your dashboard.
   
4. Choose a template to use as the basis of your dashboard. The following options are available:
   
   - Workspace overview
   - Project overview
   - Blank
   
   **Workspace overview template**
   
   ![Workspace overview template](/assets/workspace-template-setup.DWOA9kt6.gif)_Workspace overview template_
   
   **Project overview template**
   
   ![Project overview template](/assets/project-template-setup.BS10TiVL.gif)_Project overview template_
   
   Select a project to load a dynamic preview of the template.
   
   **Blank template**
   
   ![Blank template](/assets/blank-template-setup.ZSDKhpiL.png)_Blank template_
   
5. Customize your dashboard by dragging and dropping components and editing chart data.
   
   ![Add components](/assets/components-add.wwyaL2W5.png)_Add components to your dashboard_
