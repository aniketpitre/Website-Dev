> Manage Insights dashboards as your reporting needs change, including how to rename, clone, and delete dashboards in your workspace.

# Manage dashboards

You can rename, clone, or delete Insights dashboards as your reporting needs change.

Refer to [Edit components](/en/insights/components-edit) to learn how to edit dashboard components.

## Rename a dashboard

Complete the following steps to rename a dashboard:

1. Go to **Platform > Insights**.
   
2. Click the **...** (ellipsis) next to the dashboard you plan to rename, then select **Rename**.
   
   ![Rename dashboard](/assets/rename-dashboard.DBqJy04Z.png)_Rename dashboard_
   
3. Enter a new name for the dashboard.
   
4. Click **✓** to confirm your changes.
   

## Clone a dashboard

Complete the following steps to clone a dashboard:

1. Go to **Platform > Insights**.
   
2. Click the **...** (ellipsis) next to the dashboard you plan to clone, then select **Clone**.
   
   ![Clone dashboard](/assets/dashboard-clone.vSyjCKWG.png)_Clone dashboard_
   

Workato automatically opens the cloned dashboard in the dashboard editor.

## Delete a dashboard

Complete the following steps to delete a dashboard:

1. Go to **Platform > Insights**.
   
2. Click the **...** (ellipsis) next to the dashboard you plan to delete, then select **Delete**.
   
   ![Delete dashboard](/assets/delete-dashboard.BoBtu383.png)_Delete dashboard_
   
3. Click **Delete dashboard** again to confirm.
