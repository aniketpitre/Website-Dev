# Prebuilt MCP servers

MCP (Model Context Protocol) servers enable AI models to safely and reliably interact with business applications and services. Workato offers prebuilt MCP servers through ready-to-use templates with tools that can be customized to fit specific workflows and requirements.

Prebuilt MCP servers are organized into the following categories:

- [Process MCP servers](#process-mcp-servers) complete a specific business process. These servers often connect multiple apps and use multi-step workflows.
- [Data and analytics MCP servers](#data-and-analytics-mcp-servers) transform, aggregate, and derive insights from data. These servers often connect multiple apps to analyze data across platforms.
- [App-specific MCP servers](#app-specific-mcp-servers) perform CRUD operations and access an app's foundational capabilities.

> **GETTING STARTED**
> 
> Get started with Workato MCP servers in [AI Hub > Enterprise MCP > Custom servers](https://app.workato.com/mcp/custom). Refer to the [Start with a prebuilt MCP server](/en/mcp/prebuilt-mcps) guide or a specific server's documentation for installation and configuration steps.
