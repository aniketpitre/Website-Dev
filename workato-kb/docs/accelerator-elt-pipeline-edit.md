# View/edit a pipeline

You must view a pipeline before you can edit it. To view/edit a pipeline:

1. Open Slack or Microsoft Teams and navigate to the **App homepage**.
   
2. Choose a pipeline from the list of pinned pipelines.
   
3. The **App homepage** enables you to **View**, **Activate**, or **Unfollow** a pinned pipeline. Click **View**.
   
   You can [search for a pipeline](/en/accelerator-elt-pipeline-search) from the **App homepage** if you do not see the pipeline you want to view/edit.
