# Manual provisioning

You can manually configure user provisioning. This option doesn't enable you to sync users or groups from your IdP. You must define the user's access and user group membership when you manually add a user.

## Prerequisites

You must have the following configurations before you can enable JIT provisioning:

- A [configured SAML-SSO provider](/en/control-plane/authentication#set-up-a-saml-sso-provider) for Control plane

## Enable manual provisioning

Complete the following steps to configure manual provisioning:

1. Sign in to your Workato account.
   
2. Expand the workspaces menu.
   
3. Click **Control plane**.
   
4. Sign in using your Control plane credentials or SSO.
   
5. Go to **Control plane settings > Authentication**.
   
6. Go to the **Identity provider (IdP) for SAML SSO** section and click the provisioning **Setup now** link for the IdP where you plan to enable manual provisioning.
   
7. Click **Manual provisioning** in the **Provisioning** modal.
   
   ![Click Manual provisioning](/assets/manual-provisioning.B2SaxeqR.png)_Click **Manual provisioning**_
   
8. Click **Done**.
