# Connectors

Workato connectors are the foundation of your automation strategy. Connectors enable Workato to securely connect with and exchange data between your business applications. This enables you to build powerful automated workflows without writing complex integration code.

Each connector provides the following features:

- **Authentication**: Secure connection setup and credential management.
- **[Triggers](/en/recipes/triggers)**: Events that start your automated workflows. For example: A new customer record was created.
- **[Actions](/en/recipes/steps#action-step)**: Operations your workflows can perform. For example: create a ticket, send an email, or update a record.

## Get started

Workato provides over 1,000 connectors in three categories to enable you to integrate with most business applications:

- [Pre-built connectors](/en/connectors/prebuilt-connectors) offer ready-to-use connectors with setup guides, required permissions, available triggers and actions, and troubleshooting guidance.
- [Universal connectors](/en/developing-connectors) extend connectivity options and enable you to create custom triggers and actions for APIs or web services that don't have existing connectors, using protocols like HTTP, OpenAPI, GraphQL, and SOAP.
- [Community connectors](/en/developing-connectors/community/community) provide user-contributed connectors for additional applications.

Visit the [Workato Integration Library](https://www.workato.com/integrations) to browse all supported apps.
