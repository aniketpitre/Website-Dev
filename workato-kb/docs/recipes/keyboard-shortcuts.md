> Reference for Workato recipe design keyboard shortcuts on Mac and Windows, covering zoom, save, undo, redo, comments, and skipping steps.

# Keyboard shortcuts for recipe design

The following keyboard shortcuts allow you to streamline recipe design using your keyboard. Keyboard shortcuts are available for both Mac and Windows operating systems.

- ## Mac keyboard shortcuts
  
  - Zoom in
  - `command` + `opt` + `+`
  - Zoom out
  - `command` + `opt` + `-`
  - Fit to screen
  - `command` + `opt` + `[`
  - Skip / unskip steps in a recipe
  - `command` + `/`
  - Reset to default
  - `command` + `opt` + `0`
  - Add a comment
  - `command` + `opt` + `a`
  - Copy selected text
  - `command` + `c`
  - Open the browser Find feature to search for a key term
  - `command` + `g`
  - Save the recipe
  - `command` + `s`
  - Paste copied text _above_ the selected content
  - `command` + `opt` + `v`
  - Paste copied text _below_ the selected content
  - `command` + `v`
  - Undo
  - `command`\+ `z`
  - Redo
  - `command`\+ `shift` + `z`

- ## Windows keyboard shortcuts
  
  - Zoom in
  - `Ctrl` + `+`
  - Zoom out
  - `Ctrl` + `-`
  - Skip / unskip steps in a recipe
  - `Ctrl` + `/`
  - Add a comment
  - `Ctrl` + `a`
  - Copy selected text
  - `Ctrl` + `c`
  - Save the recipe
  - `Ctrl` + `s`
  - Paste
  - `Ctrl` + `v`
  - Undo
  - `Ctrl` + `z`
  - Redo
  - `Ctrl` + `shift` + `z`
