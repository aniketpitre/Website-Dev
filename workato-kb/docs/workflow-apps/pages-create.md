> Create a page in Workato Workflow apps from the Projects section and add it to an application to build your app interface.

# Create a page

![Create a new page](/assets/page-create.Bi7Ss03L.png)_Create a new Page_

Complete the following steps to create a page:

1. Sign in to your Workato account.
   
2. Go to **Projects** in the navigation bar.
   
3. Click **Create > Page** or press C+A.
   
4. Specify the name of the page.
   
   The name you choose is displayed in the project/folder.
   
5. If the application does not already exist in the project, Workato will set it up automatically with the same name as the project.
   
6. If a data table is already selected for an application, Workato pre-selects it. Otherwise, you can choose from a list of existing data tables within the parent project or create a data table on demand.
   
7. Select one of the [templates](/en/workflow-apps/page-templates). You can [edit](/en/workflow-apps/pages-customize) the page later.
