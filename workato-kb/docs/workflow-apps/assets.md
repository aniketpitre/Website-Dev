> Manage Workflow app assets from the Workflow app tab, including connected data tables, recipes, and unused assets, or create new ones.

# App assets

The bottom portion of the **Workflow app** tab provides a full overview of the assets in your Workflow app, including connected [data tables](/en/data-tables), recipes, and any unused assets.

You can also create new assets and link them to your app in this interface.

![App assets](/assets/app-view-assets.CaLTlvdM.png)_Connect your assets_

* * *

## Manage data tables

Workato displays the [data tables](/en/data-tables) connected to your Workflow app by default. You can create a new data table by clicking **+** (plus).

Complete the following steps to manage a data table:

1. Click **...** (ellipsis).
   
2. Manage the data table according to your requirements. The following actions are available:
   
   - Rename table
   - Delete table
3. Optional. Select a data table to edit it in the data table editor.
   

* * *

## Manage recipes

This section displays the recipes that integrate with external systems through [run recipe actions](/en/workflow-apps/component-actions/run-recipe) and form your app's request and approval logic, if applicable.

Complete the following steps to manage a recipe:

1. Go to **Recipes**.
   
2. Click **...** (ellipsis).
   
3. Manage the recipe according to your requirements. The following actions are available:
   
   - Rename recipe
   - Edit recipe
   - Start recipe
   - Clone recipe
   - Delete recipe
