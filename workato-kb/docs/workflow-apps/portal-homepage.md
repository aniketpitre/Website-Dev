> Learn how the Workflow apps portal homepage displays application tiles app-users can access and an inbox of tasks assigned to them.

# Portal homepage

The portal homepage displays tiles with all the applications app-users can access. The Workato Administrator sets up application access. Access is defined in the [App settings](/en/workflow-apps/builder-experience#app-settings) at the project level. See [user groups](/en/workflow-apps/setup-and-access#app-access-manage) for more information on how to define app access.

_App homepage_

Additionally, the page contains an inbox. The inbox includes all of the tasks assigned to the app-user. This includes both tasks assigned to the app-user directly and tasks assigned to groups they belong to. Click the task to navigate to the task page.
