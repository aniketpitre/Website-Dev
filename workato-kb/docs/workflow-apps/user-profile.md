> Learn how to use the Workflow apps portal user profile to manage your name, password, connections, and notification settings.

# User profile

![User profile](/assets/apps-portal-profile.BhxehFLs.png)_User profile_

Your user profile contains your personal settings. The following sections are available in your user profile:

- Profile
  
- Allows you to change your first and last name.
  
- Password
  
- Allows you to change your password.
  
- Connections
  
- Manage connections used in [verified user access](/en/workflow-apps/verified-user-access).
  
- Notifications
  
- Allows you to configure who receives notifications.
