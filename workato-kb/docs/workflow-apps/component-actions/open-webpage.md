# Open a webpage action

Specific page components enable you to direct app users to a specific URL from the Workflow apps portal.

## Compatible components

| Component | Trigger event |
| --- | --- |
| Button | Button click |

## Configure an Open a webpage action

Complete the following steps to configure an **Open a webpage** action on button click:

1. Select a **Button** component.
   
2. Go to the **Action** panel. The **Trigger** event, `Button is clicked` is pre-selected.
   
3. Use the **Action** drop-down to select `Open a webpage`.
   
4. Enter the URL to open in the **Webpage URL** field.
   
5. Optional. Use the **Open in a new browser tab** toggle to determine whether the webpage opens in a new browser tab.
   
6. Click **Save**.
