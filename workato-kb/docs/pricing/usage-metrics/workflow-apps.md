# Workflow app usage

Workato measures Workflow apps usage in seats. A seat is an entitlement that grants one end-user access to a Workflow app.

## Workflow app calculation rules

- Seats are counted by provisioned assignment, not by active use.
- Workflow app builders, the users who create Workflow apps in the workspace, aren't counted as seats. Only end-users assigned to use deployed Workflow apps consume seats.
- Reassigning a seat to a different end-user doesn't change the total seat count.
- Any recipes invoked by a Workflow app are measured separately, following their own usage metric. Refer to [Understand usage](/en/pricing/usage-metrics) for the full metric list. Recipe usage is billed separately from seats.
