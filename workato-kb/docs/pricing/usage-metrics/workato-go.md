# Workato GO usage

Workato measures Workato GO usage in seats. A seat is an entitlement that grants one end-user access to Workato GO.

## Workato GO calculation rules

- Seats are counted by provisioned assignment, not by active use.
- Reassigning a seat to a different user doesn't change the total seat count.
- Any recipes invoked by a Workato GO app are measured separately, following their own usage metric. Refer to [Understand usage](/en/pricing/usage-metrics) for the full metric list.
