# Workbot

[Workbot](https://www.workato.com/platform/workbot?utm_source=docs&utm_medium=referral&utm_campaign=workbot) is a bot platform that allows you to build customizable workflows.

Eliminate app-hopping. Connect to your critical business applications and bring the power of those services into a single interface.

Set up monitoring and notification for key events, build a helpline with ChatOps, or streamline provisioning of company resources with a request bot - all directly from your company's chat software. Workato supports Slack, Microsoft Teams, and Facebook Workplace.
