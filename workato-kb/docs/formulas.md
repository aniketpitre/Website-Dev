# Formulas

Users can use formulas to transform data using Workato. Formulas allow users to easily work with and format data. Formulas in Workato are included in allowlists of Ruby methods. Not all Ruby methods are supported. Contact your Customer Success Manager to request new formulas for the allowlist. Syntax and functionality for these formulas are generally unchanged.

Workato allows you to work with the following standard data types:

- [String](/en/formulas/string-formulas)
- [Integer or number](/en/formulas/number-formulas)
- [Date or datetime](/en/formulas/date-formulas)
- [List](/en/formulas/array-list-formulas)
- [Complex data types](/en/formulas/complex-data-types)

For further assistance with creating and refining formulas, consider using Workato's Copilot. Copilot offers tailored suggestions and guidance for formula creation, helping you effectively transform and format your data. [Learn more about Copilot in formula mode](/en/recipes/copilot-in-formula-mode).
