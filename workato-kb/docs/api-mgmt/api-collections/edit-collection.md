# Edit an API collection

You can access and edit an API collection after you create it. Complete the following steps to edit an API collection:

1. Sign in to your Workato account.
   
2. Go to **Platform > API platform > API collections**.
   
3. Select the API collection you plan to edit. This opens the **API collections** overview page.
   
4. Click the collection you plan to edit. This opens the API collection overview page.
   
5. Use the overview page to manage the collection:
   
   - [Create](/en/api-mgmt/configure-recipe-endpoint#step-1-create-the-endpoint), remove, or edit endpoints.
   - [Test](/en/api-mgmt/testing-endpoints#test-recipe-endpoint) individual endpoints.
   - Update collection details such as the name, version, or description.
   - Manage clients and access settings.
