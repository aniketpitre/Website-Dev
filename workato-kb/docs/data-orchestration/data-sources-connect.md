# Connect to data sources

Workato provides over 1,200 different pre-built app connectors, the ability to create custom connectors with our Connector SDK, and secure on-premise connectivity. Workato offers universal connectivity to a wide range of data sources. This provides flexibility to build data pipelines that fit your custom data orchestration requirements.

Workato supports the following data sources for data orchestration:

- Software as a Service (SaaS) platforms
- On-premise systems and ground applications
- Enterprise Resource Planning (ERP) systems
- Databases
- File servers and other data repositories
- CSV, JSON, and XML

## How to connect to data sources and destinations

Workato provides documentation with step-by-step instructions on how to connect to various data sources. These guides include authentication and authorization requirements, configuration settings for each data source type, and instructions on how to use data sources in recipes.

- Pre-built connectors

- Custom connectors
  
- Refer to our [Connector SDK](/en/developing-connectors/sdk) documentation to learn how to build custom connectors.
  
- On-prem connectivity
  
- Refer to the [On-prem connectivity](/en/developing-connectors/sdk) guide to learn how to access on-prem systems.
