# API recipe use cases

API recipe use cases are designed to help you discover the power programmatic task automation through practical, real-world applications on the Workato platform.

An API recipe is a specialized recipe that transforms your automation workflows into callable API endpoints. You can expose these endpoints to external partners, applications, or other recipes within your organization.

API recipes enable you to:

- Provide real-time access to business data to partners and external systems
- Trigger workflows through external applications to initiate automations in your Workato environment
- Create standardized APIs that multiple recipes or applications can consume

> **USE CASES ARE INTENDED AS EXAMPLES ONLY**
> 
> Use cases are intended to serve as examples. API recipe modifications such as API trigger configuration, action configuration, and conditional logic may require adjustments for your specific setup.

### [Add users to Google Workspace](https://docs.workato.com/en/getting-started/use-cases/api-recipes/add-users-to-google-workspace.html)

This use case integrates [Workato API platform and Google Workspace](https://docs.workato.com/en/getting-started/use-cases/api-recipes/add-users-to-google-workspace.html) and enables you to add users to your Google Workspace programmatically with your preferred Command line interface (CLI) or when a new employee is detected in BambooHR.

### [Create Zendesk tickets with API requests](https://docs.workato.com/en/getting-started/use-cases/api-recipes/create-zendesk-tickets.html)

This use case integrates [Workato API platform and Zendesk](https://docs.workato.com/en/getting-started/use-cases/api-recipes/create-zendesk-tickets.html) to let teams programmatically create support tickets through CLI tools without accessing the Zendesk UI.
