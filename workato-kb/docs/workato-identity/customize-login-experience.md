# Customize login experience

You can customize the login experience for your end users by configuring your organization's branding and colors. These settings apply to the Workato Identity login page, authorization page, and browser tabs.

Complete the following steps to customize your login experience:

1. Sign in to your Workato account.
   
2. Go to **Workspace admin**. The **Access control** page displays by default.
   
3. Click **Login experience** in the sidebar.
   
   ![Default login experience settings](/assets/default-login-experience.B5geGJKM.png)_Default login experience settings_
   
4. Go to the **Logo** section and drag or upload a logo. Accepts PNG or SVG files up to 5MB.
   
5. Go to the **Favicon** section and drag or upload a favicon. Accepts ICO or PNG files up to 1MB. A 32×32px image is recommended.
   
6. Enter a name for your app in the **App name** field. This is the name that displays on the login page, authorization page, and browser tabs.
   
7. Go to the **Login form footer** section and provide footer information, such as text or links.
   
8. Go to the **Google Fonts URL** field and enter the font URL to use a custom font.
   
9. Go to the **Page background color** field and enter the color hex code or click the color box to enter RGB values. This value is applied to the full-page background behind the login and authorization modal. Defaults to `#F1F5F9`.
   
   ![Enter the color hex code or click the color box to enter RBG values](/assets/select-color.DRCWeONn.png)_Enter the color hex code or click the color box to enter RBG values_
   
10. Go to the **Form background color** field and enter the color hex code or click the color box to enter RGB values. This value is applied to the login and authorization modal background. Defaults to `#FFFFFF`.
    
11. Go to the **Brand color** field and enter the color hex code or click the color box to enter RGB values. This value is applied to buttons on the login and authorization modal. Defaults to `#108291`.
    
12. Go to the **Primary text color** field and enter the color hex code or click the color box to enter RGB values. This value is applied to headings and body text within the login and authorization modal. Defaults to `#373D47`.
    
13. Go to the **Secondary text color** field and enter the color hex code or click the color box to enter RGB values. This value is paired with your primary text color for optimal contrast, such as the `Log in` button text. Defaults to `#FFFFFF`.
    
    ![Customized login experience](/assets/customized-login.B78ihDYG.png)_Customized login experience_
    
14. Click **Save changes**.
