# Workato Identity IAM Developer API

Workato Identity provides APIs that enable you to programmatically manage [user identities](/en/workato-identity/add-end-user-manually#add-an-end-user-manually), [group memberships](/en/workato-identity/user-groups#user-group-management), and [access control](/en/workato-identity/identity-provider-user-access#identity-provider-user-access).

Refer to [Workato Identity IAM](/en/workato-api/workato-identity-iam) Developer API for more information.

## Enable Workato Identity IAM

Complete the following steps to enable Workato Identity IAM endpoints in your workspace.

1. Sign in to your Workato account.
   
2. Go to **Workspace admin > API clients > API client roles**.
   
3. Select your existing admin role or click **\+ Add client role**.
   
4. Select **Admin** in the sidebar.
   
5. Go to the **Workspace details** section.
   
6. Expand the **IAM** section.
   
7. Select the checkboxes of the API endpoints you plan to enable.
   
   ![Select the API endpoints you plan to enable](/assets/enable-iam-endpoints.BzKUms6n.png)_Select the checkboxes of the API endpoints you plan to enable_
   
8. Click **Save changes**.
