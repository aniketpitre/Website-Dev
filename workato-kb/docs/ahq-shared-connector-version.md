# Version a connector

If you have a new version of a shared connector, you can change it very easily in Automation HQ.

> **Prerequisite**
> 
> You must first develop, test, and deploy a [connectors](/en/developing-connectors/sdk), and then [share](/en/ahq-shared-connector-share) it.

Complete the following steps to version a connector in Automation HQ:

1. Sign in to your Workato account.
   
2. Go to **Automation HQ**.
   
3. Select the **Shared connectors** tab.
   
   ![Shared connectors tab](/assets/automation-hq-workspace-shared-connectors-version.omt0evat.png)_Change version of shared connector_
   
4. Click the **Version** icon for your connector. This opens the **Switch \[Connector\_Name\] shared version** modal.
   
   ![Switch shared version modal](/assets/automation-hq-workspace-shared-connectors-version-switch._mD9xzdM.png)_Switch version of shared connector_
   
5. Use the drop-down menu to select the new version of your connector.
   
   ![Select the new version of your connector](/assets/automation-hq-workspace-shared-connectors-version-switch-confirm.903miGlD.png)_Select the new version of your connector_
   
6. Click **Share connector**. The new version of the connector appears in the **Shared connectors** list.
   
   ![New version of the connector](/assets/automation-hq-workspace-shared-connectors-version-new.HwK2YMdB.png)_New version of the connector, automatically shared with all workspaces_
