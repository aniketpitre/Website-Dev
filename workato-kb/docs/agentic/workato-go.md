# Workato GO

Workato GO is an [Agentic](/en/agentic/agentic) feature that unifies AI-driven workflows, knowledge searches, and transactional interactions within a single, cohesive interface. It eliminates the need to switch between disconnected tools, search systems, and workflows.

> **FEATURE AVAILABILITY**
> 
> Workato GO is available to all users in the US, EU, AU, JP, SG, IL, KR, and UK data centers. Workato GO models are hosted in the US, EU, and APAC regions and respect data residency requirements where possible. Workato GO isn't available to workspaces in the CN data center. This reflects local regulatory requirements and applies to our multi-tenant and [Virtual Private Workato (VPW)](/en/cloud-hosting-editions/hosting-editions#virtual-private-workato) offerings.
> 
> Contact your Customer Success representative if you're interested in using Workato GO or require additional information.

## Key features

Workato GO provides the following capabilities:

- **Knowledge searches**: This feature combines public resources and multiple third-party applications used by your company to find answers across internal data sources like Google Drive, Slack, Confluence, Salesforce, and more.
- **Federated search**: Searches multiple artifacts, such as attachments, documents, chats, and more, from a connected data source to retrieve real-time information. Federated search isn't available for all data source connectors. Refer to [Federated search](/en/agentic/workato-go/data-sources#federated-search) for more information.
- **Integrated chat**: You can interact with agents and Enterprise data through a single prompt-driven interface.
- **Context-aware routing**: Workato GO determines whether a query is handled by a genie, a search result, or both.
- **Simplified task flow**: Forms, approvals, and user confirmations are built into the interface to avoid switching between apps.

## Workato GO interface

Workato GO consists of the following interface panels that power its contextual understanding to help you complete work:

### Search bar

The search box enables you to search for specific information, documents, and updates, as well as tell Workato GO what you plan to accomplish. For example:

- `Most recent sales proposal for Acme`
- `Q2 planning`
- `I need to create a Google slide for a new prospect`

Refer to [Search for knowledge](/en/agentic/workato-go/search#search-for-knowledge) for more information.

### Prompts

The **Prompts** section provides targeted prompts to keep you on track. For example:

- `File an expense report in Coupa`
- `Create a ticket in Jira`
- `Create PTO in Workday`

### Frequently visited

The **Frequently visited** section provides an overview of the resources you've visited frequently to enable quick access to information. For example:

- `Sales proposal for Acme`
- `Gong discovery call with Acme`
- `Confluence Acme product requirements document`

### Calendar

The **Calendar** section shows your scheduled meetings for today. For example:

- `Planning committee biweekly meeting 12pm-12:45pm`
- `Product sync meeting 2pm-2:30pm`

## Integration with Agent Studio

Workato GO integrates with [Agent Studio](/en/agentic/agent-studio) to enable you to interact with genies. You can complete tasks, retrieve information, and respond to approvals within Workato GO.

Integration between Workato GO and Agent Studio also lets you use your Workato GO account as a knowledge base data source for Agent Studio genies.

### Display genie KPIs in Workato GO with Action Board

You can visualize your [KPI](/en/agentic/agent-studio/action-board) metrics in Workato GO by creating thumbnail cards. This enables you to build a dashboard of KPI indicators called an [Action Board](/en/agentic/agent-studio/action-board#display-kpis-in-workato-go-with-action-board). You must have at least one KPI to create a thumbnail to display in Workato GO.

Refer to [Agent Studio Action Board for Workato GO](/en/agentic/agent-studio/action-board) for more information.
