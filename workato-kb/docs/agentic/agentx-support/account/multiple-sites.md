# AgentX Support - Multiple sites

AgentX Support allows for multiple site implementations, allowing you to onboard active sites such as help centers, marketing sites, or development sites.

> **FEATURE AVAILABILITY**
> 
> This feature is only available to users on specific pricing plans. Refer to your pricing plan and contract to learn more.

The multiple sites feature helps organizations create:

- Sandbox environments
- Multi-brand environments

The interface displays information specific to the currently selected active site.

Hover over a site to select another active site. The selected site becomes active and shows all associated objects and analytics.
