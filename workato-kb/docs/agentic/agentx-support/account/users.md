# AgentX Support - Users

Admins can invite other users and configure access to different features in AgentX Support. Users receive an invitation to set up their account after you add them.

## Add a user

Complete the following steps to add a new user:

1. Go to **Account > Users**.
   
2. Click **Add User** to add a new user.
   
3. Enter the user's email in the **Email** field.
   
   ![Add a new user](/assets/add-user.WkRfJK-0.png)_Add a new user_
   
4. Optional. Select the **Admin** checkbox to assign the user with an admin role. Admins have account level privileges to add users and connections.
   
5. Select the apps the user can access and their [roles](/en/agentic/agentx-support/account/permissions-and-roles) for each app.
   
6. Optional. Use the **Sites** drop-down menu to select the [sites](/en/agentic/agentx-support/account/multiple-sites) the user can access.
   
7. Click **Submit** to invite the user. The new user receives instructions on setting up their account in their inbox.
   

## Edit user permissions

Complete the following steps to edit a user's permissions:

1. Click **Edit** next to the user you plan to update.
   
2. Update the user's details. You can modify their email, assign or remove app roles, and toggle admin access.
   
   ![Edit permissions](/assets/edit-permissions.DxuI83fL.png)_Edit permissions_
   
   Refer to [Permissions and roles](/en/agentic/agentx-support/account/permissions-and-roles) for details on available roles.
   
3. Click **Submit** to confirm your changes.
   

## Delete a user

You can delete a user by clicking **Delete** and **OK** to confirm.
