> Deep dive into the messages

# AgentX Support - View messages

You can view all messages exchanged between customers and the AI agent. This is useful for reviewing specific interactions, filtering by message type, and troubleshooting conversations.

You can access message history by selecting **Advanced > Messages** in the sidebar.

![Messages table](/assets/messages-table.BAgYUjqY.png)_Messages table_

The messages table allows you to:

- See who sent the message (AI agent or user)
- View the type of flow node that generated the message
- Read the exact message shown to the customer
- Open the full conversation where the message appeared

## Filter messages

You can filter messages using the following fields:

- Node type
- Action type
- Sender
- Conversation ID
- Message ID
- Date range

![Filter messages](/assets/filter-messages.BlDaJTls.png)_Filter messages_
