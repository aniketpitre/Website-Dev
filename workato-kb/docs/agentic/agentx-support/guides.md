# AgentX Support - Guides

Guides are interactive step-by-step flows that assist users in resolving issues or navigating complex topics. They support AI responses, business rules, API callouts, and decision-making functionality to provide dynamic, personalized guidance.

![Example troubleshooting guide](/assets/example-guide.CcwPxbZ2.png)_Example troubleshooting guide_

## Create a guide

Complete the following steps to create a guide:

1. Go to **Guide > Guides Flows**.
   
   ![Guides](/assets/guides-flows.C_UP5Gtw.png)_Guides_
   
2. Click **Create**.
   
3. Enter a name for the guide in the **Flow Name** field.
   
   ![Create a guide](/assets/create-guide.DqPF0FiE.png)_Create a guide_
   
4. Enter a description in the **Description** field. The guide name and description should as descriptive as possible for the AI to be able to show guides in search or when embedded in the AI agent.
   
5. Specify the type of guide to create. Options include:
   
   - Normal
   - Stepper
6. Click **Submit** to create the guide.
   

After creating a guide, you can start building it using [Guide Step](/en/agentic/agentx-support/nodes/core#guide-step) nodes. Each node contains content to display, a question to ask the user, and a set of selectable answers.

Drag and connect nodes in the flow builder to define the path a user takes based on their responses.
