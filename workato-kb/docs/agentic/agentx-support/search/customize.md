# AgentX Support - Customize search

AgentX Support allows you to customize the search interface to align with your brand identity. You can access this page by going to **Search > UI**.

![Customize search](/assets/search-ui.COpnoLs-.png)_Customize search_

This page includes two main sections:

- **Settings**: Configure theme options and add custom styling and scripts.
- **Search view**: Preview the theme as it appears in the search interface.
