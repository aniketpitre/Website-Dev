# AgentX Support - Search analytics

The **Global search** page gives visibility into what users are searching for and how effective the search experience is. It includes key metrics such as unique searches, click-through rates, top queries, and document engagement, along with breakdowns by locale and other dimensions.

You can access this page by going to **Search > Analytics**.

## Overview

The **Overview** tab highlights key indicators of overall search performance.

| Metric | Definition |
| --- | --- |
| Unique Searches | Total number of distinct search queries made by users. |
| Click-Through Rate | Percentage of searches that resulted in at least one click. |
| Breakdown by Locale | Distribution of searches segmented by user locale. |
| Top Clicked Documents | List of documents that received the most clicks from search results. |
| Top Search Queries | Most frequently entered search queries. |

## Query

The **Query** section provides detailed insights into user behavior and query performance.

| Metric | Definition |
| --- | --- |
| Unique Users | Number of distinct users who performed searches. |
| Click Breakdown by Vertical | Distribution of clicks across different content sources. For example, Help Center, Community, Articles. |
| Queries with High Click Position | Queries where users clicked results near the top of the list. For example, position 1–3. |
| Queries with Low Click Position | Queries where users clicked results lower in the list. For example, position 5+. |
| Search Breakdown by Typeahead | Percentage of searches initiated through typeahead (autocomplete) versus manual entry. |
| Click Breakdown by Typeahead | Percentage of clicks that came from typeahead-generated results. |
| Click Breakdown by Position | Distribution of clicks by the position of the result in the search list. |
| Characters Typed per Search | Average number of characters users typed before submitting a query. |

## Geo

The **Geo** tab shows how search performance varies by region.

| Metric | Definition |
| --- | --- |
| Top 5 Locale | The five most active user locales based on search activity. |
| Top 5 Countries | The five countries with the highest volume of searches. |
| Search Breakdown by Locale | Distribution of searches across different locales. |

## Content gap

The **Content gap** section helps identify queries where content may be missing or underperforming.

| Metric | Definition |
| --- | --- |
| Data Sources | Content repositories included in search. For example, knowledge base, support tickets. |
| Popular Queries with Low Click-Through Rate | Frequently searched terms that rarely result in clicks, indicating possible content gaps. |

## Filter the dashboard

Apply filters to focus on specific timeframes or user segments.

| Filter | Definition |
| --- | --- |
| Date Range | Quotas analytics to a specified time period. |
| Locale | Filters data by the user's selected or inferred language/region. |
| Daily/Weekly/Monthly | Changes the data aggregation granularity to show trends over different time intervals. |
