# AgentX Support - AI agents

AI agents are conversational workflows powered by natural language understanding. These agents allow you to automate support, guide users through complex processes, and connect with external systems through APIs.

You can design dynamic conversations that adapt to user input, pass data between steps, and deliver personalized experiences across multiple channels.

## Create an AI agent

Complete the following steps to create an AI agent:

1. Sign in to AgentX Support.
   
2. Click **Create**.
   
   ![Create an AI agent](/assets/ai-agents.DyLloqlt.png)_Create an AI agent_
   
3. Enter a name for your AI agent in the **Label** field.
   
4. Select **Agent** in the **Type** field.
   
5. Click **Submit**.
   
   > **RETURN TO AI AGENTS INTERFACE**
   > 
   > You can return to the AI agents interface by selecting the badge that displays your agent's name beneath the AgentX Support logo.
   > 
   > ![Return to AI agents list](/assets/return-to-agents.7RNvKOZi.png)_Return to AI agents list_
