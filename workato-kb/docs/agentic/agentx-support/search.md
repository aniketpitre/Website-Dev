# AgentX Support - Search

The **Search** feature helps users quickly find accurate answers by combining AI-powered responses with content from multiple [knowledge sources](/en/agentic/agentx-support/knowledge-sources). It enables personalized, efficient self-service support and reduces the time agents spend answering frequently asked questions.

## Key features

The AgentX Support search experience includes the following key features:

- **Federated search**: Allows users to search across multiple knowledge sources including knowledge bases, documentation, and community forums from a single [interface](/en/agentic/agentx-support/search/experience).
- **AI-powered answers**: Provides summarized responses to user queries using large language models, with links to the source content for transparency.
- **Result groups**: Segments search results by content type to help users navigate responses more easily.
- **Typeahead suggestions**: Offers real-time predictive results as users type.

## Explore search settings

- **[Analytics](/en/agentic/agentx-support/search/analytics)**: Track user queries, click-through rates, typeahead performance, and identify gaps in your content.
- **[Customize search](/en/agentic/agentx-support/search/customize)**: Adjust the visual appearance of the search bar and results interface to match your brand.
- **[Experience](/en/agentic/agentx-support/search/experience)**: Preview how the AI interprets queries, shows answers, and displays result groups.
