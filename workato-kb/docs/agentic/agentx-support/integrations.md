# AgentX Support - Integrations

You can connect your AI agent or ticket automation flows to external systems such as CRMs, help desks, or e-commerce platforms.

Common use cases include:

- Creating and updating tickets
- Fetching order status
- Modifying orders

AgentX Support also allows you to reference endpoints exposed by [API recipes](/en/api-mgmt/api-recipes/) created in the [API platform](/en/api-management). You can use these endpoints in your flows to fetch or send data from external systems.
