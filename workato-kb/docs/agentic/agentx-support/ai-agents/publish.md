# AgentX Support - Publish changes

You can publish your AI agent and flows to make updates available to users. Each one has two states: **Draft** and **Published**.

## Publish an AI agent

Changes you make, such as adding skills or updating sentences, are saved in the draft version of the AI agent. These changes won't go live until you publish them.

Complete the following steps to publish an AI agent:

1. Select your AI agent.
   
2. Click the icon.
   
3. Click **Publish changes**.
   
   ![Publish the AI agent](/assets/publish-changes.FVwSBUDI.png)_Publish the AI agent_
   
4. Click **OK** to confirm.
   

> **AI AGENT AND FLOW PUBLICATIONS ARE SEPARATE**
> 
> Publishing an AI agent doesn't automatically publish its associated flows. Each flow must be published separately. If a flow doesn't have a published version, the AI agent uses its latest draft.

## Publish a flow

Changes to a flow are saved as a new draft version. You must publish the flow to make the changes available in the published AI agent.

Complete the following steps to publish a flow:

1. Select a flow.
   
2. Click **Publish**.
   
   ![Publish the flow](/assets/publish-flow.kWTaBBCj.png)_Publish the flow_
   
3. Click **Yes** to confirm.
