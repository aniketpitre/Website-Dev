# AgentX Support - Flows

A flow is a conversational workflow that walks customers through different actions or provides information. When an AI agent understands an intent, it responds by taking the user through a flow.

When you [create a skill](/en/agentic/agentx-support/ai-agents/skills#create-a-skill), AgentX Support automatically creates a corresponding flow.

The [conversation flow builder](/en/agentic/agentx-support/conversation-flow-builder) allows you to build flows using forms, questions, conditional rules, and pre-built add-ons.

![Build flows](/assets/flows.-uopqQWj.png)_Build flows_

## Create a flow

Complete the following steps to create a flow:

1. Select an AI agent.
   
2. Go to **Actions > Flows**.
   
3. Click **\+ Create**.
   
   ![Flows](/assets/new-flow.CIqvtCcQ.png)_Flows_
   
4. Enter a name in the **Flow name** field.
   
5. Optional. Fill in the **Description** field.
   
   ![Create a flow](/assets/create-flow.CKub2KQ3.png)_Create a flow_
   
6. Optional. Fill in the **Copy from** field.
   
7. Click **Submit**.
   

## Create a folder

You can create folders to organize your flows.

1. Select an AI agent.
   
2. Go to **Actions > Flows**.
   
3. Hover over **\+ Create** and select **New folder**.
   
4. Enter a folder name and click **Save**.
   

## Edit flow settings

Complete the following steps to edit a flow's settings:

1. Click the icon next to the flow.
   
2. Select **Settings**.
   
3. Edit the following fields:
   
   - Flow name
   - Description
   - Folder
   - Labels
   
   ![Edit flow settings](/assets/edit-flow-settings.CgE7E3_A.png)_Edit flow settings_
   
4. Click **Save**.
