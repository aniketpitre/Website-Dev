# Add administrators

You can add administrators to manage data sources and view the activity log.

Complete the following steps to add administrators to your Workato GO account:

1. Sign in to your Workato account.
   
2. Go to **Manage > Workato GO admin**.
   
3. Go to the **Administrators** section and use the **End users** drop-down menu to select the users you plan to add as administrators.
   
4. Click **Save**.
   

## End-user groups

Use [Workato Identity](/en/workato-identity/user-groups#user-group-management) to manage your end-user groups.
