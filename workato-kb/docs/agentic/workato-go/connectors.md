# Workato GO Connectors

Workato GO connectors are adapted versions of standard [Workato connectors](/en/connectors) that have been enhanced to support Workato GO. These connectors retain the same authentication methods, actions, and triggers as their standard counterparts, but include additional configuration options.

Available Workato GO connectors:

- [Gong](/en/agentic/workato-go/connectors/gong)
