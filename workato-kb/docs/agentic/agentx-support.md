# AgentX Support

[AgentX Support](https://agentx-support.workato.com/) is an AI-powered support automation solution designed to streamline customer service workflows and reduce resolution times. AgentX Support integrates knowledge search, automation, and live chat into a single experience to help teams deliver scalable support across multiple channels.

  

> **FEATURE AVAILABILITY**
> 
> AgentX Support is available only to customers using the US data center.
> 
> You must review and accept our [AI feature addendum](https://www.workato.com/legal/ai-feature-addendum) before you can use AgentX Support. Contact your Customer Success Representative for more information.

## Key features

AgentX Support combines several powerful features to deliver fast, scalable, and intelligent customer support across channels.

- **Federated search**
  
  - Allows users to search across multiple [knowledge sources](/en/agentic/agentx-support/knowledge-sources), including knowledge bases, documentation, and community forums from a single [interface](/en/agentic/agentx-support/search/experience).
  - Displays AI-generated in-line answers to help users resolve issues faster.
  - Segments search results by content type to help users find responses more easily.
  - Learn more about [search](/en/agentic/agentx-support/search).
- **Live chat on support site**
  
  - Enables real-time chat with an AI agent.
  - Supports live agent handoff to [Zendesk](/en/agentic/agentx-support/nodes/add-ons#zendesk-sunshine-conversations-handover), [Salesforce](/en/agentic/agentx-support/nodes/add-ons#salesforce-live-agent-handover), and [Slack](/en/agentic/agentx-support/nodes/add-ons#slack-live-chat-handover) with full context retention.
  - Uses forms and guided [flows](/en/agentic/agentx-support/ai-agents/flows) to collect structured input and perform actions.
  - Learn more about [AI agents](/en/agentic/agentx-support/ai-agents).
- **Low-code/no-code automation builder**
  
  - [Build workflows](/en/agentic/agentx-support/conversation-flow-builder) that automate tasks or guide users.
  - Design dynamic [forms](/en/agentic/agentx-support/nodes/core#form) and [guides](/en/agentic/agentx-support/guides) to capture specific inputs.
  - Connects with APIs, apps, and databases for backend automation.
  - Learn more about the [conversation flow builder](/en/agentic/agentx-support/conversation-flow-builder) and the [nodes](/en/agentic/agentx-support/nodes) you can use to build flows and guides.
- **Search analytics**
  
  - Tracks usage trends across search queries, result clicks, and engagement.
  - Measures how often typeahead suggestions are used.
  - Highlights content gaps to improve self-service resources.
  - Learn more about [search analytics](/en/agentic/agentx-support/search/analytics).
- **Agent analytics**
  
  - Shows session metrics such as volume, self-service rate, and average engagement time.
  - Categorizes user interactions by device and browser.
  - Provides insight into AI agent effectiveness and user behavior.
  - Learn more about [agent analytics](/en/agentic/agentx-support/analytics).
