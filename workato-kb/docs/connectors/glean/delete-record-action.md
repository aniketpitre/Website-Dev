# Glean - Delete record action

The **Delete record** action deletes a Glean record you specify.

## Input

| Input fields | Description |
| --- | --- |
| Object | Specify the object type you plan to delete. |

> **ADDITIONAL INPUT FIELDS**
> 
> The recipe editor generates additional input fields based on the **Object** type you select. Use these fields to specify the record you plan to delete.

## Output

The **Delete record** action's output fields vary based on your selected **Object** type.
