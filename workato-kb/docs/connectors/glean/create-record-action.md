# Glean - Create record action

The **Create record** action creates a new record in Glean.

## Input

| Input fields | Description |
| --- | --- |
| Object | Specify the type of object you plan to create. |

> **ADDITIONAL INPUT FIELDS**
> 
> The recipe editor generates additional input fields based on the **Object** type you select. Use these fields to specify the record's content.

## Output

The **Create record** action's output fields vary based on your selected **Object** type.
