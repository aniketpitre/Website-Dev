# Glean - Execute operation action

The **Execute operation** action performs an operation in Glean. The available operations are dynamically generated based on the endpoints in Glean's OpenAPI. If an API endpoint doesn’t match the other Workato actions, it is contained in the **Execute operation** action.

## Input

| Input fields | Description |
| --- | --- |
| Operation | Specify the operation to perform. |

> **ADDITIONAL INPUT FIELDS**
> 
> The recipe editor generates additional input fields based on the **Operation** you select. Use these fields to specify the details of the operation.

## Output

The **Execute operation** action's output fields vary based on your selected **Operation**.
