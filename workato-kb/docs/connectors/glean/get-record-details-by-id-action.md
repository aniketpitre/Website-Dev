# Glean - Get record details by ID action

The **Get record details by ID** action retrieves the details of a Glean record you specify.

> **NOT SUPPORTED BY INDEXING API**
> 
> The **Get record details by ID** action is not supported by Glean's Indexing API.

## Input

| Input fields | Description |
| --- | --- |
| Object | Specify the object you plan to retrieve. |

> **ADDITIONAL INPUT FIELDS**
> 
> The recipe editor generates additional input fields based on the **Object** type you select. Use these fields to specify the record details.

## Output

The **Get record details by ID** action's output fields vary based on your selected **Object**.
