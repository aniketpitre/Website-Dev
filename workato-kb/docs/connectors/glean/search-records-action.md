# Glean - Search records action

The **Search records** action retrieves a list of Glean records that match the criteria you specify.

> **NOT SUPPORTED BY INDEXING API**
> 
> The **Search records** action is not supported by Glean's Indexing API.

## Input

| Input fields | Description |
| --- | --- |
| Object | Specify the type of object you plan to retrieve from Glean. |

> **ADDITIONAL INPUT FIELDS**
> 
> The recipe editor generates additional input fields based on the **Object** type you select. Use these fields to specify the search criteria.

## Output

The **Search records** action's output fields vary based on your selected **Object**.
