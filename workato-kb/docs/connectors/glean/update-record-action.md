# Glean - Update record action

The **Update record** action updates the details of a Glean record you specify.

> **NOT SUPPORTED BY INDEXING API**
> 
> The **Update record** action is not supported by Glean's Indexing API.

## Input

| Input fields | Description |
| --- | --- |
| Object | Specify the type of object you plan to update. |

> **ADDITIONAL INPUT FIELDS**
> 
> The recipe editor generates additional input fields based on the **Object** type you select. Use these fields to specify the new content of the record.

## Output

The **Update record** action's output fields vary based on your selected **Object**.
