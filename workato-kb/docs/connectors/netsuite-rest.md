# NetSuite REST

[NetSuite](http://www.netsuite.com/) is an enterprise resource planning (ERP) and cloud business management software suite provided by Oracle. It offers comprehensive software solutions for organizations, including support for ERP/Financials, CRM, and ecommerce.

Workato's NetSuite REST connector enables you to communicate with NetSuite's REST APIs.

## API version

The NetSuite REST connector uses the [NetSuite REST API](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/book_1559132836.html#subsect_13133350732). Refer to the [NetSuite REST API Browser](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_157373386674.html#subsect_157373789239) for API reference.

> **NETSUITE VERSION BASED ON INSTANCE AVAILABILITY**
> 
> The NetSuite connector automatically defaults to the version available for your instance.

## Connect to the NetSuite REST connector

The NetSuite REST connector supports OAuth 2.0 machine-to-machine (M2M) authentication.

Learn how to [connect to NetSuite](/en/connectors/netsuite-rest/connect).
