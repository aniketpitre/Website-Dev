# Zoho CRM - Update lead action

The **Update lead** action updates the lead that matches the Zoho CRM ID you provide.

## Input

| Input field | Description |
| --- | --- |
| Lead ID | Enter the ID of the lead to update. |
| Salutation | Enter the salutation. For example: `Mr.`, `Ms.`, `Dr.`. |
| First name | Enter the first name of the lead. |
| Title | Enter the job position of the lead. |
| Last name | Enter the last name of the lead. |
| Company | Enter the company name associated with the lead. |
| Lead source | Select the lead source. For example: `Advertisement`, `Cold call`, `Employee referral`, `External referral`, `Onlinestore`, `Partner`, `Public relations`, `Sales mail alias`, `Seminar partner`, `Seminar-internal`, `Trade show`, `Web download`, `Web research`, `Chat`. |
| Industry | Select the industry. For example: `ASP`, `Data/Telecom OEM`, `ERP`, `Government/Military`, `Large Enterprise`, `ManagementISV`, `MSP (Management Service Provider)`, `Network Equipment (Enterprise)`, `Non-management ISV`, `Optical Networking`, `Service Provider`, `Small/Medium Enterprise`, `Storage Equipment`, `Storage Service Provider`, `Systems Integrator`, `Wireless Industry`. |
| Annual revenue | Enter the annual revenue of the company where the lead is working. |
| Phone | Enter the phone number of the lead. |
| Mobile | Enter the mobile number of the lead. |
| Fax | Enter the fax number of the lead. |
| Email | Enter the email address of the lead. |
| Secondary email | Enter another email address of the lead. |
| Skype ID | Enter the Skype ID of the lead. |
| Twitter | Enter the Twitter handle of the lead. |
| Website | Enter the website of the lead. |
| Lead status | Select the lead status. For example: `Contact in Future`, `Not contacted`, `Contacted`, `Junk lead`, `Lost lead`, `Pre-qualified`. |
| Rating | Select the rating: `Acquired`, `Active`, `Market failed`, `Project canceled`, `Shutdown`. |
| Number of employees | Enter the number of employees in the lead's company. |
| Email opt out | Specify whether to opt the lead out of email communications. |
| Street | Enter the street address of the lead. |
| City | Enter the name of the city where the lead lives. |
| State | Enter the name of the state where the lead lives. |
| Zip code | Enter the postal code of the lead's address. |
| Country | Enter the name of the lead's country. |
| Description | Enter any additional details about the lead. |

## Output

| Output field | Description |
| --- | --- |
| Lead ID | The unique identifier of the updated lead. |
| Created time | The timestamp when the lead was created. |
| Modified time | The timestamp when the lead was modified. |
| Created by | The user who created the lead. |
| Modified by | The user who last modified the lead. |
