> Create a new contact record in Zoho CRM to manage individual customer and lead information.

# Zoho CRM - Create contact action

The **Create contact** action creates a contact in Zoho CRM.

## Input

| Input field | Description |
| --- | --- |
| Salutation | Enter the salutation. For example: `Mr.`, `Ms.`, `Dr.`. |
| First name | Enter the first name of the contact. |
| Last name | Enter the last name of the contact. |
| Department | Enter the department of the contact. |
| Title | Enter the job position of the contact. |
| Email | Enter the primary email address of the contact. |
| Phone | Enter the office phone number of the contact. |
| Mobile | Enter the mobile number of the contact. |
| Fax | Enter the fax number of the contact. |
| Account name | Specify the account related to the contact. |
| Vendor name | Specify the vendor related to the contact. |
| Campaign source | Specify the associated campaign. |
| Lead source | Specify the source from which the contact is created. |
| Reports to | Specify the person to whom the contact reports. |
| Reporting to | Enter the ID of the contact to whom this contact reports. This ID must be linked to the account you selected. |
| Skype ID | Enter the Skype ID of the contact. |
| Date of birth | Enter the contact's date of birth. |
| Assistant | Enter the name of the contact's assistant. |
| Assistant phone | Enter the phone number of the contact's assistant. |
| Mailing street | Enter the primary street address of the contact. |
| Mailing city | Enter the primary city of the contact. |
| Mailing state | Enter the primary state or province of the contact. |
| Mailing country | Enter the primary country of the contact. |
| Mailing zip | Enter the primary postal code of the contact. |
| Email opt out | Specify whether to opt the contact out of email communications. |
| Description | Enter any additional details about the contact. |
| Other phone | Enter an alternative phone number of the contact. |
| Secondary email | Enter another email address of the contact. |
| Other zip | Enter an alternative postal code of the contact. |
| Other street | Enter an alternative street address of the contact. |
| Other city | Enter an alternative city of the contact. |
| Other state | Enter an alternative state or province of the contact. |
| Other country | Enter an alternative country of the contact. |
| Home phone | Enter the home phone number of the contact. |
| Twitter | Enter the Twitter handle of the contact. |

## Output

| Output field | Description |
| --- | --- |
| Contact ID | The unique identifier of the created contact. |
| Created time | The timestamp when the contact was created. |
| Modified time | The timestamp when the contact was modified. |
| Created by | The user who created the contact. |
| Modified by | The user who last modified the contact. |
