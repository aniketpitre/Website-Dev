# Zoho CRM - Delete standard object action

The **Delete standard object** action deletes a standard object in Zoho CRM.

## Input

| Input field | Description |
| --- | --- |
| Module name | Select the standard module containing the object. |
| ID | Enter the unique identifier of the object to delete. |

## Output

| Output field | Description |
| --- | --- |
| Status | The status of the deletion operation. |
