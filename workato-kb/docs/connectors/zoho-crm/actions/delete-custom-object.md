# Zoho CRM - Delete custom object action

The **Delete custom object** action deletes a custom object in Zoho CRM.

## Input

| Input field | Description |
| --- | --- |
| Module name | Select the custom module containing the object. |
| ID | Enter the unique identifier of the object to delete. |

## Output

| Output field | Description |
| --- | --- |
| Status | The status of the deletion operation. |
