> Create a new deal record in Zoho CRM to track sales opportunities and pipeline.

# Zoho CRM - Create deal action

The **Create deal** action creates a deal in Zoho CRM.

## Input

| Input field | Description |
| --- | --- |
| Deal name | Enter the name of the deal. |
| Account name | Specify the name of the account to which the deal belongs. |
| Contact name | Specify the contact related to the deal. |
| Deal type | Specify the type of deal: `New Business` or `Existing Business`. |
| Lead source | Specify the lead source. |
| Campaign source | Specify the associated campaign. |
| Amount | Enter the amount that can be expected after closing the deal. |
| Closing date | Enter the expected close date. |
| Next step | Enter the next step of the sales process. |
| Stage | Specify the sales stage. |
| Probability | Enter the probability of closing the deal. |
| Description | Enter any additional details about the deal. |

## Output

| Output field | Description |
| --- | --- |
| Deal ID | The unique identifier of the created deal. |
| Created time | The timestamp when the deal was created. |
| Modified time | The timestamp when the deal was modified. |
| Created by | The user who created the deal. |
| Modified by | The user who last modified the deal. |
