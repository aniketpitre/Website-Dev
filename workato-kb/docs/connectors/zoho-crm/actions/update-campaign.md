# Zoho CRM - Update campaign action

The **Update campaign** action updates the campaign that matches the Zoho CRM ID you provide.

## Input

| Input field | Description |
| --- | --- |
| Campaign ID | Enter the ID of the campaign to update. |
| Campaign name | Enter the name of the campaign. |
| Type | Select the campaign type. For example: `Conference`, `Webinar`, `Trade show`, `Public relations`, `Partners`, `Referral program`, `Advertisement`, `Banner ads`, `Direct mail`, `Email`, `Telemarketing`, `Others`. |
| Status | Select the campaign status: `Planning`, `Active`, `Inactive`, `Complete`. |
| Start date | Enter the date on which the campaign starts. |
| End date | Enter the date on which the campaign ends. |
| Expected revenue | Enter the revenue expected after launching the campaign. |
| Actual cost | Enter the actual amount spent on the campaign. |
| Budgeted cost | Enter the planned amount to be spent on the campaign. |
| Expected response | Enter the expected response percentage for the campaign. Maximum length is 9 characters. |
| Number sent | Enter the number of leads or contacts to whom the campaign details have been sent. |
| Description | Enter any additional details about the campaign. |
| Survey Department | Enter the department responsible for the survey. |
| Survey Type | Enter the type of survey associated with the campaign. |
| Survey | Enter the survey name or identifier. |
| Survey URL | Enter the URL for the survey. |
| Department ID | Enter the unique identifier for the department. |

## Output

| Output field | Description |
| --- | --- |
| Campaign ID | The unique identifier of the updated campaign. |
| Created time | The timestamp when the campaign was created. |
| Modified time | The timestamp when the campaign was modified. |
| Created by | The user who created the campaign. |
| Modified by | The user who last modified the campaign. |
