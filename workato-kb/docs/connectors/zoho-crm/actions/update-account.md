# Zoho CRM - Update account action

The **Update account** action updates the account that matches the Zoho CRM ID you provide.

## Input

| Input field | Description |
| --- | --- |
| Account ID | Enter the ID of the account to update. |
| Account name | Enter the company name. |
| Website | Enter the URL of the company's website. |
| Employee count | Enter the number of employees in the account's company. |
| Ownership | Specify the ownership type: `Public`, `Private`, `Subsidiary`, or `Other`. |
| Industry | Specify the industry type for the company. |
| Annual revenue | Enter the annual revenue of the account. |
| Phone | Enter the phone number of the account. |
| Fax | Enter the fax number of the account. |
| Parent account | Specify the parent company name. |
| Account type | Specify the type of account. |
| Account number | Enter the reference number for the account. |
| Ticker symbol | Enter the ticker symbol of the company. |
| Billing street | Enter the billing street address of the account. |
| Billing city | Enter the billing city of the account. |
| Billing state | Enter the billing state or province of the account. |
| Billing country | Enter the billing country of the account. |
| Billing code | Enter the billing postal code of the account. |
| Shipping street | Enter the shipping street address of the account. |
| Shipping city | Enter the shipping city of the account. |
| Shipping state | Enter the shipping state or province of the account. |
| Shipping code | Enter the shipping postal code of the account. |
| Shipping country | Enter the shipping country of the account. |
| Account site | Enter the name of the account's location. For example: `Headquarters` or `London`. |
| Rating | Specify the rating of the account: `Acquired`, `Active`, `Market failed`, `Project canceled`, `Shutdown`. |
| SIC code | Enter the Standard Industrial Classification code of the account. Maximum length is 9 characters. |
| Description | Enter any additional details about the account. |
| Associated contacts | Specify the contacts associated with this account. |

## Output

| Output field | Description |
| --- | --- |
| Account ID | The unique identifier of the updated account. |
| Created time | The timestamp when the account was created. |
| Modified time | The timestamp when the account was modified. |
| Created by | The user who created the account. |
| Modified by | The user who last modified the account. |
