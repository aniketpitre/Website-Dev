# Typeform

[Typeform](https://www.typeform.com) is an online platform used by marketers, researchers, and businesses to collect data and generate leads using forms, surveys, quizzes, and apps.

The Typeform connector allows you to monitor Typeform for new forms and responses, retrieve form and response information, and search records.

## Prerequisites

Workato requires a client ID and client secret to establish a connection to Typeform. Refer to the Typeform [Create an application](https://www.typeform.com/developers/get-started/applications/#1-create-an-application-in-the-typeform-admin-panel) guide to generate these values using `https://www.workato.com/oauth/callback` as the redirect URI.

## Connection setup

1. Click **Create > Connection** or press C twice.
   
2. Provide a name for your connection in the **Connection name** field.
   
   ![Typeform connection fields](/assets/typeform-connection.iKzMwSfD.png)_Typeform connection fields_
   
3. Use the **Location** drop-down menu to select the project where you plan to store the connection.
   
4. Search for and select **Typeform** as your connection on the **New connection** page.
   
5. Enter your **Client ID** and **Client secret** [generated in Typeform](#prerequisites).
   
6. Click **Connect**.
