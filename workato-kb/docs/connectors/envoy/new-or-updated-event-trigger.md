# Envoy - New/updated event trigger

The **New/updated event** trigger activates when a new or updated event occurs in Envoy. To activate the trigger, you must activate the webhook app in Envoy and enter the webhook endpoint URL for all the events you plan to trigger. Refer to the [Envoy documentation](https://developers.envoy.com/hub/docs/create-webhooks) for more information.

## Input

| Input field | Description |
| --- | --- |
| Event Name | Specify the event to monitor. |

## Output

The output fields are determined by the event selected in the input. Map the relevant datapill from the datatree to subsequent steps.
