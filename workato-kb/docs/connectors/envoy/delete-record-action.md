# Envoy - Delete record action

The **Delete record** action enables you to delete a record from Envoy.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the object whose record you plan to delete. Fields load dynamically based on your selection. Only the Invite object is supported for this action. |
| ID | Unique identifier of the record. |

## Output

| Output field | Description |
| --- | --- |
| Data | Data of the record deleted. |
| Meta | Metadata related to the record. |
