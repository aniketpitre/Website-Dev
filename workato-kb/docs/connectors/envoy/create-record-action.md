# Envoy - Create record action

The **Create record** action enables you to create a record in Envoy.

## Input

| Input field | Description |
| --- | --- |
| Object | Specify the object to create a record. Fields load dynamically based on the object you select. |

## Output

The output fields are determined by the object selected in the input. Map the relevant datapill from the datatree to subsequent steps.
