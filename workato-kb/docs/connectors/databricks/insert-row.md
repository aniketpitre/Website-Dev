# Databricks – Insert row in table action

The **Insert row in table** action adds a new row to a selected table in your Databricks workspace. You must select a target table and provide values for the columns you plan to insert.

## Input

| Input field | Description |
| --- | --- |
| Table | Select the Databricks table where you plan to insert a new row. Only the first 1,000 tables are displayed. Enter the table name if your table doesn't appear in the drop-down menu. |
| Columns | Enter values for the columns you plan to populate. Workato displays column fields after you select a table based on the table's schema. |

Additional input fields may appear based on the **Table** you select.

## Output

This action doesn't return output.
