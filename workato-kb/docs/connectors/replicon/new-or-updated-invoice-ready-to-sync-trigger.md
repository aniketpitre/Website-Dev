# Replicon - New/updated ready to sync invoice trigger

This trigger picks up new or updated invoices that are created in your Replicon instance. Each new or update invoice is processed as an individual job.

![New/updated ready to sync invoice trigger](/assets/new-or-updated-invoice-ready-to-sync-trigger.DdMJKdao.png)_New/updated ready to sync invoice_

## Input

<dl id="replicon-new-updated-invoice-input"><dt>Trigger poll interval</dt><dd>Specifies how frequently Workato polls for new client(s). This is an optional parameter.</dd></dl>

## Output

The output of this trigger will be a datatree that contains information about the new or updated Replicon invoice.
