# Replicon - New user trigger

This trigger picks up new users that are created in your Replicon instance. Each new user is processed as an individual job.

![New user trigger](/assets/new-user-trigger.DSGdGoW_.png)_New user trigger_

## Input

<dl id="replicon-new-user-input"><dt>Trigger poll interval</dt><dd>Specifies how frequently Workato polls for new client(s). This is an optional parameter.</dd></dl>

## Output

The output of this trigger will be a datatree that contains information about the new Replicon user.
