# Replicon - New client trigger

This trigger picks up new clients that are created in your Replicon instance. Each new client is processed as an individual job.

![New client trigger](/assets/new-client-trigger.DgXu8L-3.png)_New client trigger_

## Input

The client trigger has the following input field:

<dl id="replicon-new-client-input"><dt>Trigger poll interval</dt><dd>Specifies how frequently Workato polls for new client(s). This is an optional parameter.</dd></dl>

## Output

The output of this trigger is a datatree that contains information about the new Replicon client.
