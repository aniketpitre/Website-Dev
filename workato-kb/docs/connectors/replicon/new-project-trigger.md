# Replicon - New project trigger

This trigger picks up new projects that are created in your Replicon instance. Each new project is processed as an individual job.

![New project trigger](/assets/new-project-trigger.CQDRpLY_.png)_New project trigger_

## Input

<dl id="replicon-new-project-input"><dt>Trigger poll interval</dt><dd>Specifies how frequently Workato polls for new client(s). This is an optional parameter.</dd></dl>

## Output

The output of this trigger will be a datatree that contains information about the new Replicon project.
