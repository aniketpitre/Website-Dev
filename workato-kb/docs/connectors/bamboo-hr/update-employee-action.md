# BambooHR - Update employee action

This action updates an employee record in your BambooHR instance identified by the employee ID.

## Input

![Update employee action](/assets/update-employee-action.BCVW-aDw.png)_Update employee action_

| Input field | Description |
| --- | --- |
| Employee ID | The employee ID assigned by BambooHR. |
| Employee input fields | For a full list of employee input fields, see [Field names](https://documentation.bamboohr.com/docs/list-of-field-names). |

## Output

There are no outputs to this action.
