# Deputy - Create employee action

This action creates a new employee record in your Deputy instance.

![Create employee action](/assets/create-employee-action.COESXxJ1.png)_Create employee action_

## Input

<dl><dt>First name</dt><dd>The employee's first name.</dd><dt>Last name</dt><dd>The employee's last name.</dd><dt>Company ID</dt><dd>The ID of the company associated with the employee.</dd><dt>Role</dt><dd>The employee's role.<br>Optional field.</dd><dt>Email address</dt><dd>The employee's email address.<br>Optional field.</dd><dt>Mobile number</dt><dd>The employee's mobile number.<br>Optional field.</dd><dt>Stress profile</dt><dd>The employee's stress profile.<br>Optional field.</dd><dt>Date of birth</dt><dd>The employee's date of birth.<br>Optional field.</dd></dl>

## Output

The output of this action is a datatree that contains information about the new employee object.

Find out more about the [employee object](https://www.deputy.com/api-doc/Resources/Employee/).
