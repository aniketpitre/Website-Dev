> The Create task action in the Deputy connector creates a new task record with a question, start and end dates, and a responsible user.

# Deputy - Create task action

This action creates a new task record in your Deputy instance.

![Create task action](/assets/create-task-action.BrshPFrs.png)_Create task action_

## Input

<dl><dt>Question</dt><dd>The question assigned to the task.</dd><dt>Start date</dt><dd>The start date of the task.<br>Optional field.</dd><dt>End date</dt><dd>The end date of the task.<br>Optional field.</dd><dt>User responsible ID</dt><dd>The ID of the user responsible for the task.<br>Optional field.</dd></dl>

## Output

The output of this action will be a datatree that contains information about the new task object.

Find out more about [task object](https://www.deputy.com/api-doc/Resources/Task/).
