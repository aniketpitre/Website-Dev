> The Create resource action in the Deputy connector creates a resource such as an employee agreement, employee workplace, or training record.

# Deputy - Create resource action

This action creates a resource in your Deputy instance. Supported resources are:

- EmployeeAgreement
- EmployeeWorkplace
- TrainingRecord

![Create resource action](/assets/create-resource-action.Bo_UTvyj.png)_Create resource action_

## Input

<dl><dt>Resource type</dt><dd>The type of resource to be created.</dd><dt>Resource data</dt><dd>The data for resource to be created. Available fields will vary based on the selected resource type above.</dd></dl>

## Output

The output of this action is a datatree that contains information about the resource object created.
