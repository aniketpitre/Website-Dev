# Deputy - Update employee action

This action updates an existing employee record in your Deputy instance.

![Update employee action](/assets/update-employee-action.BbxJekwu.png)_Update employee action_

## Input

<dl><dt>Employee ID</dt><dd>The ID of the employee to be updated.</dd><dt>First name</dt><dd>The employee's first name.<br>Optional field.</dd><dt>Last name</dt><dd>The employee's last name.<br>Optional field.</dd><dt>Company ID</dt><dd>The ID of the company associated with the employee.<br>Optional field.</dd><dt>Role</dt><dd>The employee's role.<br>Optional field.</dd><dt>Email address</dt><dd>The employee's email address.<br>Optional field.</dd><dt>Mobile number</dt><dd>The employee's mobile number.<br>Optional field.</dd><dt>Stress profile</dt><dd>The employee's stress profile.<br>Optional field.</dd><dt>Date of birth</dt><dd>The employee's date of birth.<br>Optional field.</dd></dl>

## Output

The output of this action will be a datatree that contains information about the new employee object.

Find out more about [employee object](https://www.deputy.com/api-doc/Resources/Employee/).
