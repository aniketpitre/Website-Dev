> The Get resource action in the Deputy connector retrieves a resource such as an employee, agreement, workplace, or training record.

# Deputy - Get resource action

This action retrieves a resource in your Deputy instance. Supported resources are:

- Employee
- EmployeeAgreement
- EmployeeWorkplace
- TrainingRecord

![Get resource action](/assets/get-resource-action.XeGXe0oX.png)_Get resource action_

## Input

<dl><dt>Resource type</dt><dd>The type of resource to be retrieved.</dd><dt>Resource</dt><dd>The resource to be retrieved. Supports selection from a list of available resources in your Deputy instance or manual input of the resource ID.</dd></dl>

## Output

The output of this action is a datatree that contains information about the new resource object.
