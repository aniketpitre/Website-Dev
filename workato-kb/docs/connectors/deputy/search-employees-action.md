> The Search employees action in the Deputy connector finds employees that match a given employee display name.

# Deputy - Search employees action

This action searches for employees matching the search parameter in your Deputy instance.

![Search employees action](/assets/search-employees-action.DuHJD_jY.png)_Search employees action_

## Input

<dl><dt>Employee display name</dt><dd>The employee's display name.</dd></dl>

## Output

The output of this action will be a list of datatree that contains information about the employees searched.

Find out more about [employee object](https://www.deputy.com/api-doc/Resources/Employee/).
