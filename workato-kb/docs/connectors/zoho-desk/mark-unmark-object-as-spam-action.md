# Zoho Desk - Mark/unmark object as spam action

The **Mark/unmark object as spam** action enables you to mark or unmark a record as spam in Zoho Desk.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the object to create the record. Fields load dynamically based on the object you select. |

## Output

| Output field | Description |
| --- | --- |
| Success | Indicates if the object was marked or unmarked as spam successfully. |
