# Zoho Desk - Close ticket action

The **Close ticket** action enables you to close a ticket in Zoho Desk.

## Input

| Input field | Description |
| --- | --- |
| Object | Specify the object to create the record. Fields load dynamically based on the object you select. |
| Ticket IDs | Enter the IDs of tickets to close. |

## Output

| Output field | Description |
| --- | --- |
| Success | Indicates if the comment was added successfully. |
