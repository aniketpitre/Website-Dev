# Apify - Get record by ID action

The **Get record by ID** action retrieves an Actor, Actor build, or Actor run from Apify by ID.

## Input

Input fields are dynamically generated based on the object you select. The following input field is common to all objects. Refer to the [Apify API documentation](https://docs.apify.com/api/v2) for more information on available input fields.

| Input field | Description |
| --- | --- |
| Object | Select the object you plan to retrieve. Options include **Actor**, **Actor build**, or **Actor run**. |

## Output

Output fields are dynamically generated based on the object you select. Refer to the [Apify API documentation](https://docs.apify.com/api/v2) for more information on available output fields.
