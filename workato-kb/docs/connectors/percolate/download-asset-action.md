# Percolate - Download asset action

The **Download asset** action enables you to retrieve an asset from the Percolate asset library by specifying the asset's ID.

![Download asset in Percolate action](/assets/download-asset-action.D57vHuXs.png)_Percolate - Download asset action_

## Input

| Input field | Description |
| --- | --- |
| Asset ID | Enter the ID of the Percolate asset that you plan to download. |

## Output

| Output field | Description |
| --- | --- |
| File content | The content of the downloaded file. |
| Size | The size of the file. |
