# Percolate - Update object's production workflow step action

The **Update object's production workflow step** action allows you to update an object through its production workflow stages.

![Update Object's Production Workflow Step in Percolate action](/assets/production-workflow-step-action.BRuHDdKc.png)_Percolate - Update object's production workflow step action_

## Input

| Input field | Description |
| --- | --- |
| Object type | Specify the type of the object you plan to update. |
| Team | Enter the teams or team ID associated with the object. |
| Production workflow | Identify the production workflow that the object is part of. |
| From step keys | Provide a CSV of step IDs that the object transitions from. |
| To step key | Specify the step key where the object transitions to. |
| Object ID | Enter the unique identifier of the object you plan to update. |

## Output

This action does not have any output fields.
