# Percolate - Get object details by ID action

The **Get object details by ID** action allows you to retrieve detailed information about an object using its unique ID. Select from the list of objects that Workato currently supports, then provide the ID of your chosen object.

![Get object details by ID in Percolate action](/assets/get-object-details-by-id-action.BTqBa9Vj.png)_Percolate - Get object details by ID action_

## Input

| Input field | Description |
| --- | --- |
| Object name | Specify the type of object to retrieve details for. |
| Team IDs | Enter a list of teams or team IDs related to the object. |
| Team Metadata | Select a value if you require metadata for the team, particularly if your object is linked to the team ID input field or if you select more than 100 teams. Selecting a team overrides this field's input. |
| Object ID | Enter the unique identifier of the object. |

## Output

The output of this action varies based on the type of object you select.
