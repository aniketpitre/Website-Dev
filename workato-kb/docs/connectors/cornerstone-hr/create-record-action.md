# Cornerstone HR - Create record action

The **Create record** action creates a record, such as a user, in Cornerstone HR.

## Input

Input fields dynamically generate based on the object you select. The following field is common to all objects. Refer to the [Cornerstone API documentation](https://apiexplorer.csod.com) for a complete list of input fields.

| Input field | Description |
| --- | --- |
| Object | Select the object you plan to create. Options are **User**, **LO**, and **Goal**. |

## Output

Output fields dynamically generate based on the object you select. Refer to the [Cornerstone API documentation](https://apiexplorer.csod.com) for a complete list of output fields.
