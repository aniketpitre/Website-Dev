# Cornerstone HR - Cancel goal action

The **Cancel goal** action updates a goal's status to cancelled in Cornerstone HR.

## Input

| Input field | Description |
| --- | --- |
| Goal ID | Enter the internal ID of the goal you plan to cancel. |
| User ID | Enter the ID of the user who owns the goal. |
| Title | Enter the title of the goal you plan to cancel. |

## Output

| Output field | Description |
| --- | --- |
| Data | An array containing the updated goal record, including its **Status**. |
| Status | The HTTP status code of the response. |
| Updated records | The number of goal records updated. |
| Timestamp | The date and time the goal status was updated. |
