> The Create folder action in the Egnyte connector lets you create a new, named folder at a specified path in Egnyte.

# Egnyte - Create folder action

The **Create folder** action allows you to create a new folder in Egnyte.

![Create folder action](/assets/create-folder-action.CJgDPiCy.png)_Create folder action_

## Input

| Input field | Description |
| --- | --- |
| Folder | Select the path where you plan to store the new folder. |
| Folder name | Enter a name for the folder. |

## Output

| Output field | Description |
| --- | --- |
| Path | The path to the folder. For example: `/Shared/wood_gnome`. |
| Folder ID | The ID of the folder. For example: `7fa1ffb5-ffc5-4a11-b597-90e6a9de7f45`. |
