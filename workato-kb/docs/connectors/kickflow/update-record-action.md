# Kickflow - Update record action

The **Update record** action updates an existing record in Kickflow.

## Input

Input fields dynamically generate based on the object you select. The following input field is common to all objects. Refer to the [Kickflow](https://developer.kickflow.com/rest/spec) documentation for a complete list of input fields.

| Input field | Description |
| --- | --- |
| Object | Select the type of record to update, such as a ticket. Additional fields load dynamically based on the object you select. |

## Output

Output fields dynamically generate based on the object you select. Refer to the [Kickflow](https://developer.kickflow.com/rest/spec) documentation for a complete list of output fields.
