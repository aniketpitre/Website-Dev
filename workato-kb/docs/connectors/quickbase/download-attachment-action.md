> The Download attachment action in the Quickbase connector lets you download a file attachment from a record using its file URL.

# Quickbase - Download attachment action

This action downloads an attachment from Quickbase.

## Input

| Field | Description |
| --- | --- |
| File URL | You can find the File URL in the output of other Quickbase triggers or actions, or you can enter the URL directly. |

## Output

| Field | Description |
| --- | --- |
| File content | The content of the downloaded file. |
