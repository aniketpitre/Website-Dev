# Eventbrite - Create/update contact action

The **Create/update contact** action allows you to add a new contact to a specified list in Eventbrite. If a contact with the specified email already exists in the list, this action replaces the existing contact with the new contact record.

![Create or Update Contact action](/assets/create-update-contact-action.dzvWOIES.png)_Eventbrite - Create/update contact action_

## Input

| Input field | Description |
| --- | --- |
| List name | Enter the exact, case-sensitive name of the contact list where you plan to create or update a contact. |
| Email | Enter the unique email address that identifies the contact within the list. |
| First name | Enter the first name of the contact. |
| Last name | Enter the last name of the contact. |

## Output

| Output field | Description |
| --- | --- |
| Created | Confirmation that the contact was created or updated successfully. |
