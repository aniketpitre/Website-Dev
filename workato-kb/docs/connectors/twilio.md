# Twilio

[Twilio](https://www.twilio.com) provides communications platform as a service (CPaaS) features that work in the background to bridge the gap between web-based applications and telephones.

## API version

Refer to [Twilio's API documentation](https://www.twilio.com/docs/api) for specific information, including:

- Twilio REST API
- Twilio Messaging API
- Twilio Voice API
- TwiML

## Connection setup

1. Provide a **Connection name** that identifies which Twilio instance Workato is connected to.
   
   ![Twilio Connection](/assets/twilio-connection-setup.C78Vus2Y.png)_Create your connection_
   
2. Enter your Twilio **Account SID**. Your Account SID can be found in the **Account Info** section of your Twilio dashboard.
   
3. Enter your Twilio **Auth token**. Your Auth token can be found in the **Account Info** section of your Twilio dashboard.
   
4. Click **Connect**.
