# Trello - List lists action (batch)

The **List lists** action retrieves the lists on a board you specify.

## Input

| Field | Description |
| --- | --- |
| Board name | Specify the name of the board to retrieve lists from. |
| Filter | Specify which lists to return. Default is `Open`. |

## Output

| Field | Description |
| --- | --- |
| Lists | A list of the board's lists. Each contains fields such as `ID`, `Name`, `Closed`, `Board ID`, `Position`, and `Type`. |
