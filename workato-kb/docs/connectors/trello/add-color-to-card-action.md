# Trello - Add color to card action

The **Add color to card** action adds a color label to a card you specify.

## Input

| Field | Description |
| --- | --- |
| Card name | Specify the card to change. |
| Color | Specify the color to add. Valid values include: `blue`, `orange`, `green`, `red`, `purple`, `pink`, `lime`, `sky`, and `grey`. |
| Label name | Provide a name for the label. |

## Output

| Field | Description |
| --- | --- |
| ID | The ID of the card. |
| ID board | The ID of the board that contains the card. |
| Name | The name of the label. |
| Color | The color of the label. |
| Uses | The number of times the label is used across cards. |
