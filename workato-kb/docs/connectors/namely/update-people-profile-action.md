# Namely - Update people profile action

The **Update people profile** action allows you to update an employee profile that you specify.

![Update people profile action](/assets/update-people-profile-action.oSIgZTB9.png)_Update people profile action_

## Input

| Input field | Description |
| --- | --- |
| Profile ID | Enter the ID of the employee profile you plan to update. |
| First name | Enter the first name of the person whose profile you plan to update. This field is optional. |
| Last name | Enter the last name of the person whose profile you plan to update. This field is optional. |

## Output

| Output field | Description |
| --- | --- |
| ID | The ID of the employee. |
| Company UUID | The universally unique ID (UUID) of the company associated with the employee. |
| Email | The email address of the employee. |
| First name | The first name of the employee. |
| Last name | The last name of the employee. |
| employee status | The status of the employee. For example: `active`. |
| Updated at | The timestamp when the employee's information was last updated. |
| Created at | The timestamp when the employee's profile was created. |
| Preferred name | The preferred name of the employee. |
| Preferred last name | The preferred last name of the employee. |
| Image | Details about the employee's profile image, including file ID, filename, MIME type, original file path, and thumbnail paths. |
| Full name | The full name of the employee. |
| Job title | Details about the employee's job title, including ID, title, parent ID, whether the job title is active, and associated salary bands. |
| Reports to | Information about who the employee reports to, including ID, first name, last name, preferred name, and email. |
| Employee type | The type of employment of the employee. For example: `Full Time`. |
| Access role | The access role of the employee within the system. |
| Ethnicity | The ethnicity of the employee. |
| Team positions | The team positions held by the employee. |
| Is Namely admin | Indicates whether the employee is an admin within Namely. |
| Date format | The date format preferred by the employee. |
| Start date | The start date of the employee. |
| Linkedin URL | The LinkedIn URL of the employee, if any. |
| Office direct dial | The direct dial number for the employee's office. |
| Office phone | The general phone number for the employee's office. |
| Veteran protected classes | Information about veteran protected classes for the employee. |
| Middle name | The middle name of the employee. |
| Bio | The biography of the employee. |
| Office main number | The main phone number for the employee's office. |
| Office | Details about the employee's office address, including address lines, city, state ID, country ID, ZIP code, and phone number. |
| Groups | The groups the employee is part of. |
| Teams | The teams the employee is part of. |
