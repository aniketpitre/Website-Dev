# Veeva Vault - Get record action

The **Get record** action retrieves the full metadata for a single Vault object record by its ID in Veeva Vault.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the Vault object. For example, **Product**. This list is populated dynamically from your Vault. |
| Record ID | The Vault record ID. For example `00P000000000301`. |

## Output

Output fields are dynamically generated based on the object you select. Refer to the [Veeva Vault](https://developer.veevavault.com/api/26.1/) documentation for more information.
