# NocoDB - Manage linked records (batch) action

The **Manage linked records (batch)** action lists, links, or unlinks related rows for a `LinkToAnotherRecord` field in NocoDB.

## Input

Input fields are dynamically generated based on the object you select. The following input field is common to all objects. Refer to the [NocoDB](https://nocodb.com/apis/v2/data) documentation for more information on available input fields.

| Input field | Description |
| --- | --- |
| Object | Select the object you plan to manage. |

## Output

The output of this action varies based on the object you select. Refer to the [NocoDB](https://nocodb.com/apis/v2/data) documentation for more information on available output fields.
