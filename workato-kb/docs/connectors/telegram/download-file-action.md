# Telegram - Download file action

The **Download file** action downloads a file's binary content from Telegram's servers.

## Input

| Input field | Description |
| --- | --- |
| File path | Enter the file's path on Telegram's servers, for example `photos/file_0.jpg`. You can get this from the [Get file](/en/connectors/telegram/get-file-action) action. |

## Output

| Output field | Description |
| --- | --- |
| File content | The binary content of the downloaded file. |
