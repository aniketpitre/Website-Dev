# IFS connector - Search records action

The **Search records** action searches for a record in Industrial and Financial Systems (IFS) Cloud. You can select an IFS service to work with. IFS service availability depends on your IFS instance configuration.

## Input

| Input field | Description |
| --- | --- |
| IFS Service | Select the IFS service to work with from the list. Alternatively, you can enter the service name. |
| Object | Select the object to search for. The list of available objects is generated dynamically based on the IFS service you select. |

## Output

The output for this action is dynamically generated based on the IFS service and object you select.
