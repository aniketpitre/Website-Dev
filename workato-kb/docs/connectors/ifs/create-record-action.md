> Use the Create record action to create a record in IFS.

# IFS connector - Create record action

The **Create record** action creates a record in Industrial and Financial Systems (IFS) Cloud. You can select an IFS service to work with. IFS service availability depends on your IFS instance configuration.

## Input

| Input field | Description |
| --- | --- |
| IFS Service | Select the IFS service to work with from the list. Alternatively, you can enter the service name. |
| Object | Select the object to create. The list of available objects is generated dynamically based on the service you select. |

## Output

The output for this action is dynamically generated based on the IFS service and object you select.
