# Amazon SES - Create object action

The **Create object** action creates an object in Amazon SES. Select the object you plan to create and provide relevant input fields for that object.

## Input

| Input field | Description |
| --- | --- |
| Object | **Required**. Type the name of the object you plan to create. You can choose from the following options: **Contact**: The end user who receives the email. You can add contacts to a contact list and associate them with an SES topic.; **Contact list**: A list containing contacts that have subscribed to one or more specific topics.; **Email template**: An email template containing the subject line, HTML format, and text-body. |

## Output

| Output field | Description |
| --- | --- |
| Status | Indicates whether the object was created. |
