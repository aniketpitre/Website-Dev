# Amazon SES - Update object action

The **Update object** action updates an object in Amazon SES. Select the object you plan to update to use this action. Fill in any related input fields after selecting the object.

## Input

| Input field | Description |
| --- | --- |
| Object **Required** | Select the object you plan to update. You can choose from the following options: **Contact**: The end user who receives the email. You can add contacts to a contact list and associate them with an SES topic.; **Contact list**: A list that contains contacts that have subscribed to one or more specific topics.; **Email template**: An email template containing the subject line, HTML format, and text-body. |

## Output

| Output field | Description |
| --- | --- |
| Status | Indicates whether the object is updated. |
