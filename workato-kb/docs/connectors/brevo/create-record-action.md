# Brevo - Create record action

The **Create record** action creates a new record in Brevo.

## Input

Input fields are dynamically generated based on the object you select. The following field is common to all object types.

| Input field | Description |
| --- | --- |
| Object type | Select the Brevo object type. For example, `contact`. |

## Output

Output fields are dynamically generated based on the object you select. The following field is common to all object types.

| Output field | Description |
| --- | --- |
| ID | ID of the new record. |
