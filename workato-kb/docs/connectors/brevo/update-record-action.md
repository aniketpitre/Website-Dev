# Brevo - Update record action

The **Update record** action updates a record in Brevo.

## Input

Input fields are generated automatically depending on the object you select. The following inputs are common to all objects. Refer to the [Brevo](https://developers.brevo.com/docs/quickstart-reference) documentation for a complete list of inputs.

| Input field | Description |
| --- | --- |
| Object type | Select the Brevo object type. |

## Output

| Output field | Description |
| --- | --- |
| Success | A boolean response indicating if the record was updated successfully. |
