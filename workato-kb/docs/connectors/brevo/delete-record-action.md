# Brevo - Delete record action

The **Delete record** action deletes a record in Brevo.

## Input

| Input field | Description |
| --- | --- |
| Object type | Select the Brevo object type to delete. |
| Identifier type | Select the type of identifier to delete. For example, a **Contact ID**. |
| Identifier value | Enter the identifier value. For example, a **Contact ID**. |

## Output

| Output field | Description |
| --- | --- |
| Success | A boolean response (`true` or `false`) that indicates if the record was deleted successfully. |
