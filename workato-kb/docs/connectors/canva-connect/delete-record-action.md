# Canva Connect - Delete record action

The **Delete record** action deletes a record from Canva Connect. Supported objects are folders and assets.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the Canva Connect object you plan to delete. |
| ID | The ID of the folder or asset you plan to delete. |

## Output

There is no output for this action.
