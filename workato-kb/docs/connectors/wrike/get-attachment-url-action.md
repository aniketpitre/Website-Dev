# Wrike - Get attachment URL action

The **Get attachment URL** action retrieves a public access URL for an attachment in Wrike. The URL is valid for **24 hours** from the time of the request.

## Input

| Input field | Description |
| --- | --- |
| Attachment ID | Enter the attachment ID to retrieve the URL for. |

## Output

| Output field | Description |
| --- | --- |
| File name | Name of the attachment file. |
| URL | Public access URL for the attachment. |
| Playlist URL | URL for accessing the attachment in a playlist format, if applicable. |
