# Wrike - Create work from custom item type action

The **Create work from custom item type** action creates a work item in Wrike using a specified custom item type.

## Input

| Input field | Description |
| --- | --- |
| Custom item type | Select the custom item type you plan to use to create the action. Toggle to **Enter custom item type ID** to use a custom item type ID instead. |
| Folder | Select a folder to create the work item in. Toggle to **Enter folder ID** to enter a folder ID instead. |
| Task ID | Enter the ID of a parent task to create work as a sub-task. |
| Title | Enter the title of the work item. |

## Output

| Output field | Description |
| --- | --- |
| Created Task ID | Unique identifier for the created work item. |
| Related type | Type of the created work item. |
