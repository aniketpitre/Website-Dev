# Wrike - Delete attachment action

The **Delete attachment** action removes a Wrike attachment based on attachment ID.

## Input

| Input field | Description |
| --- | --- |
| Attachment ID | Enter the ID of the attachment to delete. |

## Output

| Output field | Description |
| --- | --- |
| Deleted attachment ID | Unique identifier of the deleted attachment. |
| Deleted? | Indicates whether the attachment was successfully deleted. |
