# Workday REST

[Workday](https://www.workday.com/) is a cloud financial management and human capital management software that seamlessly combines finance and HR for greater business performance and visibility into organizational data.

Use the Workday REST integration connector to sync data between your Workday REST instance and other cloud applications.

The Workday REST connector is recommended when you are executing workflow-centric actions (for example, approve inbox task). If your use case requires you to work with larger datasets (for example, full reports from Workday) or with custom reports/objects, use the [Workday integration connector](/en/connectors/workday) instead.

The Workday REST connector documentation contains the following chapters:

- [Connection setup](/en/connectors/workday-rest/connection-setup)
- [New worker trigger](/en/connectors/workday-rest/new-worker-trigger)
- [Create a job change action](/en/connectors/workday-rest/create-job-change-action)
- [Get inbox tasks action](/en/connectors/workday-rest/get-inbox-tasks-action)
- [Approve/reject inbox task action](/en/connectors/workday-rest/approve-reject-inbox-task-action)
- [Get worker by ID action](/en/connectors/workday-rest/get-worker-action)
- [Search workers action](/en/connectors/workday-rest/search-worker-action)

## API version

The Workday REST connector uses the [Workday REST API v1](https://community.workday.com/sites/default/files/file-hosting/restapi/index.html).
