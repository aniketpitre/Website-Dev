# CoinGecko - Get record action

The **Get record** action retrieves a single coin detail, coin price, or historical market chart record from CoinGecko.

## Input

Input fields dynamically generate based on the object you select. The following field is common to all objects. Refer to the [CoinGecko](https://docs.coingecko.com/reference/introduction) documentation for a complete list of input fields.

| Input field | Description |
| --- | --- |
| Object | Select the object to retrieve. For example, `Coin detail`, `Coin price`, or `Historical market chart`. |

## Output

Output fields dynamically generate based on the object you select. Refer to the [CoinGecko](https://docs.coingecko.com/reference/introduction) documentation for a complete list of output fields.
