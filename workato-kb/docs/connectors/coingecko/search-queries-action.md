# CoinGecko - Search queries action

The **Search queries** action returns coins, exchanges, categories, and NFTs in CoinGecko that match a free-text search term. Use this action to resolve a coin ID from a name.

## Input

| Input field | Description |
| --- | --- |
| Query | Enter the search term you plan to use. For example, `bitcoin`. |

## Output

| Output field | Description |
| --- | --- |
| Coins | Matching coins, including ID, name, symbol, and market cap rank. |
| Exchanges | Matching exchanges, including ID, name, and market type. |
| ICOs | Matching ICO identifiers. |
| Categories | Matching categories, including ID and name. |
| NFTs | Matching NFT collections, including ID, name, and symbol. |
