> The Trello connector lets you automate project workflows: create boards, lists, and cards, move and comment on cards, and trigger on new cards.

# Trello

[Trello](https://trello.com/) is a project management application by Atlassian that provides tools to plan, organize, and track projects.

## API version

The Trello connector uses the [Trello REST API](https://developer.atlassian.com/cloud/trello/guides/rest-api/api-introduction/).

## Connection setup

The Trello connector uses OAuth 2.0 authentication.

Complete the following steps to connect to Trello in Workato:

1. Click **Create > Connection** or press C twice.
   
2. Search for `Trello` and select it as your app.
   
3. Enter a name for your connection in the **Connection name** field.
   
   ![Connect to Trello](/assets/connect-to-trello.thFd_ZNH.png)_Connect to Trello_
   
4. Use the **Location** drop-down menu to select the project where you plan to store the connection.
   
5. Optional. Use the **Custom OAuth profile** drop-down menu to select a custom OAuth profile for your connection.
   
6. Click **Connect**.
   
7. Sign in to the Trello account you plan to connect to, then click **Allow** to grant Workato access and complete the connection.
