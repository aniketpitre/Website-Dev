# MailChimp - New list trigger

This trigger runs when a new list is detected in MailChimp. This trigger checks for new lists every five minutes by default.

![New list trigger](/assets/new-list-trigger.DKKnaO4f.png)_New list trigger_

## Input

No additional input is required for this trigger.

## Output

The output for this trigger is a datatree that contains information about the MailChimp object.
