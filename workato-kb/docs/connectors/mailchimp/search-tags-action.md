> The Search tags action in the MailChimp connector lets you search for tags contained within a list that you specify.

# MailChimp - Search tags action

This action searches for tags contained within a list you specify in MailChimp.

![Search tags action](/assets/search-tags-action.CAiv6tqf.png)_Search tags action_

## Input

| Input field | Description |
| --- | --- |
| List | The list to which the tags you plan to search for are assigned. |

## Output

| Output field | Description |
| --- | --- |
| ID | The ID of the tag. |
| Name | The name of the tag. |
| Total items | The total count of unique tags. |
