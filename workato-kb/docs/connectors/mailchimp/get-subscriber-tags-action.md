> The Get subscriber tags action in the MailChimp connector lets you fetch the tags assigned to a subscriber on a list you specify.

# MailChimp - Get subscriber tags action

This action fetches the tags assigned to a subscriber on a list.

![Get subscriber tags action](/assets/get-subscriber-tags-action.Bh_T6nOi.png)_Get subscriber tags action_

## Input

| Input field | Description |
| --- | --- |
| List | The list to which the subscriber you plan to fetch tags for is assigned. |
| Email address | The email address of the subscriber. |

## Output

| Output field | Description |
| --- | --- |
| ID | The ID of the tag. For example: `7654321`. |
| Name | The name of the tag. For example: `campaignInfluencer`. |
| Date added | The date the tag was added to the subscriber. |
| Total items | The total number of tags returned for the subscriber. |
