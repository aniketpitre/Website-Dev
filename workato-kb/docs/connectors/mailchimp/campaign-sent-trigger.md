# MailChimp - Campaign sent trigger

This trigger runs when a campaign is sent in MailChimp.

![Campaign sent trigger](/assets/campaign-sent-trigger.BToF7RYm.png)_Campaign sent trigger_

## Input

No additional input is required for this trigger.

## Output

The output for this trigger is a datatree that contains information about the MailChimp object.
