> Define the topic schema for Workato Event streams, setting message field names, data types, and hints manually or with a sample JSON.

# Topic schema configuration

You must define the event stream message structure when you create a new event stream. You can edit this structure later.

![Defining topic schema](/assets/add-new-field.iRYrMHei.png)_Defining topic schema_

- Name
  
- The name of a new message field.
  
- Label
  
- The label that appears for this message field.
  
- Data type
  
- Select the data type from a drop-down.
  
- Optional
  
- Determine if this message field is optional. The default is **No**.
  
- Nest under
  
- Select an object or array to nest this message field under.
  
- Hint
  
- Provide a hint for this message field.
  

> **DEFINE TOPIC SCHEMA WITH JSON**
> 
> Instead of entering each field manually, you can define the topic schema with a sample JSON.
