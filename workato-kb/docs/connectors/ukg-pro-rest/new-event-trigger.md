# UKG Pro - New event trigger

The **New event** real-time trigger monitors UKG Pro in real-time for an event you specify.

## Input

| Input field | Description |
| --- | --- |
| Event type | Select the event type to monitor. |

## Output

| Output field | Description |
| --- | --- |
| Event ID | A unique identifier assigned to each event within UKG Pro. |
| Event time | The timestamp indicating when the event occurred. |
| Event type | Specifies the category or nature of the event. |
| Operation | The type of action performed in the event. |
| Company ID | A unique identifier for the company in UKG Pro. |
| Employee ID | The unique identifier of the employee in UKG Pro. |
| Integration record ID | A reference ID for tracking integrations. This ID allows external systems to correlate UKG Pro events with their corresponding records. |
| Tenant | The UKG Pro environment in which the event was triggered. |
