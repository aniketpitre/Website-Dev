# UKG Pro - Search records action

The **Search records** action retrieves information about a record in UKG Pro.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the object to retrieve. |

> **ADDITIONAL INPUT FIELDS**
> 
> The recipe editor generates additional input fields based on your **Object** selection.

## Output

Output fields for the **Search record** action are loaded dynamically based on your **Object** selection.
