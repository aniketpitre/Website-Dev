# Goto Webinar

GoTo Webinar is a platform designed for hosting and managing webinars. It provides tools for scheduling, promoting, and conducting webinars, as well as features for engaging with attendees and analyzing webinar performance.

## API version

The GoTo Webinar connector uses the [GoTo Webinar API](https://developer.goto.com/GoToWebinarV2/#section/GoTo-Webinar-API-Overview).

## Connection setup

Complete the following steps to create a Goto Webinar connection in Workato:

1. Sign in to Workato.
   
2. Select the project where you plan to store the Goto Webinar connection.
   
3. Click **Create > Connection** or press C twice.
   
4. Search for the Goto Webinar connector.
   
5. Select the connector.
   
6. Enter a name for your connection in the **Connection name** field.
   
   ![Connection setup](/assets/gotowebinar-connection-setup.p8gnL6kP.png)_Goto Webinar connection setup_
   
7. Select the project or folder where you plan to store the connection from the **Location** drop-down menu.
   
8. Click **Connect**.
   
9. Click **Allow** when prompted to authorize Workato to access your Goto Webinar account.
   
   ![Confirm access](/assets/gotowebinar-confirm-access.CGxCKqyo.png)_Authorize access for Workato_
