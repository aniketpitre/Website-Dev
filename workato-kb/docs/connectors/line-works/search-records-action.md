> The Search records action enables you to search an object in LINE WORKS.

# LINE WORKS - Search record action

The **Search records** action searches LINE WORKS for an object type you specify.

![Line works Search record action](/assets/line-works-search-record-action.DQdMqP-1.png)_LINE WORKS **Search record** action_

## Input

| Input Field | Description |
| --- | --- |
| Object | Specify the object type to search for. Additional input fields load dynamically based on the selected object type. |

## Output

The **Search records** action's output fields change dynamically based on the selected object type. Map the relevant datapill from the data tree for downstream steps.
