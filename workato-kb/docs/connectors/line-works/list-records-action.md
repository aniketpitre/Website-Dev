> The List records action enables you to search for an object in LINE WORKS.

# LINE WORKS - List records action

The **List records** action searches LINE WORKS and retrieves a list of all objects of the type you specify.

![Line works List records action](/assets/line-works-list-record-action.bRO6Frwb.png)_LINE WORKS **List records** action_

## Input

| Input Field | Description |
| --- | --- |
| Object | Specify the object type to retrieve from LINE WORKS. Additional input fields load dynamically based on the selected object type. |

## Output

The **List records** action's output fields change dynamically based on the selected object type. Map the relevant datapills from the data tree for downstream steps.
