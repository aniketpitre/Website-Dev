# LINE WORKS - Send message to a channel action

The **Send message to a channel** action sends a message to a chat room in LINE WORKS where the bot is a participant.

![Line works Send message to a channel action](/assets/line-works-send-message-to-a-channel-action.C844vAVV.png)_LINE WORKS **Send message to a channel** action_

## Input

| Input Field | Description |
| --- | --- |
| Bot ID | Enter the unique LINE WORKS identifier of the bot. |
| Members | Enter a list of user IDs to invite to the chat room. The list must contain 1 to 100 unique items. |
| Title | Enter the name of the chat room you plan to create. The name can be up to 1000 characters long. |

## Output

The **Send message to a channel** action's output fields change dynamically based on the selected object type. Map the relevant datapill from the data tree for downstream steps.
