# FTP/FTPS - Remove file action

The **Remove file** action removes a file from the connected server.

## Input

| Input field | Description |
| --- | --- |
| File name | Enter the path of the file to remove. For example, `/user/personal_folder/file_name.txt`. This field is case-sensitive. |

## Output

There is no output for this action.
