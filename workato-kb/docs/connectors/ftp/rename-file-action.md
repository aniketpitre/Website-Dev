# FTP/FTPS - Rename file action

The **Rename file** action renames a file on the connected server.

## Input

| Input field | Description |
| --- | --- |
| From | Enter the full path, including the file extension, of the file to rename. For example, `/user/personal_folder/source_name.txt`. This field is case-sensitive. |
| To | Enter a new name for the file. For example, `Name.txt`. |

## Output

There is no output for this action.
