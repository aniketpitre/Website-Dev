# Jira - Update issue action

The **Update issue** action updates an issue in Jira.

## Input

| Input field | Description |
| --- | --- |
| Issue ID or key | Enter the ID or key of the issue to update. |
| Sample project issue type | Select the project and issue type to retrieve custom fields for the issue. Specify system issue types in English if you use a non-English Jira instance. |
| Reporter account ID | Enter the ID of the account to assign as the issue's reporter. |
| Description | Enter a description for the issue. |
| Issue priority | Select a priority level for the issue. |
| Assignee account ID | Enter the ID of the account to assign the issue to. |

## Output

This action has no output.
