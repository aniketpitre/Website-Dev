> Explore the Jira actions in Workato to create, update, search, and manage issues, comments, users, and attachments in your recipes.

# Jira - Actions

The following Jira actions can be used to execute workflows in your recipes.

## Requirements

The linked Jira account must have sufficient permissions to the respective resource in each action. Learn more with our [Jira project permissions documentation](/en/connectors/jira#roles-and-permissions-required-to-connect).

## Assign user to issue

The [Assign user to issue](/en/connectors/jira/assign-user-to-issue-action) action assigns an issue to a Jira user. This action replaces existing assignees.

## Create comment

The [Create comment](/en/connectors/jira/create-comment-action) action creates a comment on an existing issue.

## Create issue

The [Create issue](/en/connectors/jira/create-issue-action) action creates a new issue in Jira.

## Create user

The [Create user](/en/connectors/jira/create-user-action) action creates a new user in your Jira instance. Creating a new user increases the number of Jira licenses for your organization, which affects Jira subscription fees.

## Download attachment

The [Download attachment](/en/connectors/jira/download-attachment-action) action downloads an attachment from a Jira issue. You can use this action to sync files, such as screenshots attached to tickets, between Jira and another ticket management application.

## Get changelog of an issue

The [Get changelog of an issue](/en/connectors/jira/get-changelog-of-an-issue-action) action retrieves an issue's changelog from Jira.

## Get issue

The [Get issue](/en/connectors/jira/get-issue-action) action retrieves an issue from Jira.

## Get issue comments (batch)

The [Get issue comments (batch)](/en/connectors/jira/get-issue-comments-batch-action) action retrieves the comments belonging to an existing issue in batches.

## Get issue schema

The [Get issue schema](/en/connectors/jira/get-issue-schema-action) action retrieves the name and schema of all fields in a Jira object. You can use this action to replicate the schema to your database or data warehouse.

## Get user details

The [Get user details](/en/connectors/jira/get-user-details-action) action retrieves a user from Jira. This action fails if the user doesn't exist.

## Search assignable users (batch)

The [Search assignable users (batch)](/en/connectors/jira/search-assignable-users-batch-action) action retrieves a list of all users that can be assigned to a specific issue. You can provide the user's login username to narrow the list down to a single user.

## Search issues (batch)

The [Search issues (batch)](/en/connectors/jira/search-issues-batch-action) action searches Jira for issues that exactly match the criteria you specify and retrieves the results in batches.

## Search issues by JQL (batch)

The [Search issues by JQL (batch)](/en/connectors/jira/search-jql-action) action searches Jira for issues that match the JQL query string you provide and retrieves the results in batches.

## Update comment

The [Update comment](/en/connectors/jira/update-comment-action) action updates a comment on an existing issue.

## Update issue

The [Update issue](/en/connectors/jira/update-issue-action) action updates an issue in Jira.

## Update issue status

The [Update issue status](/en/connectors/jira/update-issue-status-action) action updates the status of an issue in Jira.

## Upload attachment

The [Upload attachment](/en/connectors/jira/upload-attachment-action) action uploads an attachment to an existing issue.
