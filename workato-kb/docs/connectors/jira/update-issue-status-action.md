# Jira - Update issue status action

The **Update issue status** action updates the status of an issue in Jira.

## Input

| Input field | Description |
| --- | --- |
| Issue ID or key | Enter the ID or key of the issue to update. |
| Transition name | Enter the name of the transition to apply to the issue. For example: `To do`, `In progress`, `Done`. This field is case sensitive. The action fails if the transition name is invalid for the specified issue. |

## Output

This action has no output.
