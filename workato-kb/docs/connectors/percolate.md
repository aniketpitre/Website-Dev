# Percolate

[Percolate](https://www.percolate.com) provides a dynamic content marketing platform designed for enterprise-scale planning, creation, and execution. You can engage customers and enhance visibility using Percolate's comprehensive tools.

## API version

Percolate's connector uses Percolate's REST-based API for integration. For more information, refer to [Percolate's API documentation](https://percolate.dev/reference/introduction).

### Connection setup

To establish a connection with Percolate in Workato, follow these steps:

1. Enter a unique **Connection name** to identify your Percolate account in Workato.
   
   ![Percolate connection setup](/assets/percolate-connection-setup.DkUbjUew.png)_Name your connection_
   
2. Obtain a **Client ID** and **Client Secret** by registering a new client application in Percolate. If you're a system admin or manager, follow the [Percolate API client creation guide](https://percolate.dev/docs/authorization-authentication-quickstart#creating-an-api-client-via-the-percolate-ui) to create these credentials.
   
3. Select the relevant **Environment** for your connection from the drop-down menu. This determines which Percolate workspace you can access.
   
4. Verify all connection details for accuracy, including the connection name, client ID, client secret, and environment.
   
5. Click **Connect** to authorize a connection between Workato and your Percolate account.
