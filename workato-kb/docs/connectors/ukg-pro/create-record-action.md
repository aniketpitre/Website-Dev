> The Create record action in the UKG Pro connector lets you create a new record, such as a pending hire, in a UKG Pro instance.

# UKG Pro - Create record action

This action creates a record in your UKG Pro instance.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the UKG Pro object to create: Pending hire |
| Object fields | Input field for the object you selected will be shown. |

## Output

| Output field | Description |
| --- | --- |
| Object-specific fields | Record details specific to the object type are provided as datapills. Refer to the [UKG Pro API documentation](https://connect.ultipro.com/documentation#/api/) for more details on the output fields of each object. |
