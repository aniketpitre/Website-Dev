# Ironclad - Delete record action

The **Delete record** action deletes a record in Ironclad.

## Input

Input fields are automatically generated based on the object you select. The following input fields are common to all objects.

| Input field | Description |
| --- | --- |
| Object | Select the object type of the record you plan to delete. For example, **User** or **Group**. |

## Output

| Output field | Description |
| --- | --- |
| Status code | The HTTP status code of the action. |
