# Ironclad - New event trigger

The **New event** trigger monitors Ironclad for events.

## Input

| Input field | Description |
| --- | --- |
| Webhook type | Select the type of webhook you plan to monitor Ironclad for. |
| Set trigger condition | Optional. Set a trigger condition to define additional rules for trigger events to process. To learn more, see [Trigger conditions](/en/recipes/triggers#trigger-conditions). |

## Output

The output of this action varies based on the object you select. Refer to the [Ironclad documentation](https://developer.ironcladapp.com/) for more information on available objects and fields.
