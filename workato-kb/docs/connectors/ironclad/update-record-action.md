# Ironclad - Update record action

The **Update record** action updates a record in Ironclad.

## Input

Input fields are automatically generated based on the object you select. The following input fields are common to all objects.

| Input field | Description |
| --- | --- |
| Object | Select the object type of the record you plan to update. |

## Output

The output of this action varies based on the object you select. Refer to the [Ironclad documentation](https://developer.ironcladapp.com/) for more information on available objects and fields.
