> The Delete post action in the WordPress connector lets you delete a post by its ID and returns whether the deletion succeeded.

# WordPress - Delete post action

The **Delete post** action allows you to delete a post in WordPress.

![Delete post action](/assets/delete-post-action.Dy_zZYDn.png)_Delete post action_

## Input

| Input field | Description |
| --- | --- |
| Post ID | Enter the ID of the post you plan to delete. |

## Output

| Output field | Description |
| --- | --- |
| Deleted post | Indicates whether the post is deleted or not. Values are `true` or `false`. |
| Post ID | The ID of the deleted post. |
