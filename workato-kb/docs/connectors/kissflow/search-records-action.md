# Kissflow - Search records action

The **Search records** action enables you to retrieve a list of records for an object in Kissflow.

## Input

| Input field | Description |
| --- | --- |
| Object | Specify the object to retrieve a list of its records. Fields load dynamically based on the object you select. |

## Output

The output fields are determined by the object selected in the input. Map the relevant datapill from the datatree to subsequent steps.
