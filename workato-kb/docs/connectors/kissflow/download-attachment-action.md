# Kissflow - Download attachment action

The **Download attachment** action lets you download an attachment from a Kissflow record.

## Input

| Input field | Description |
| --- | --- |
| Object | Specify the object to download an attachment to its record. Fields load dynamically based on the object you select. |
| Process ID | Unique identifier of the process record from where the attachment will be downloaded. |

Custom input fields will load based on the attachment field in the specified process.

## Output

| Output field | Description |
| --- | --- |
| Binary data | Binary contents of the attachment file |
