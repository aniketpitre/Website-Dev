# Kissflow - Get record details by its unique key action

The **Get record details by its unique key** action enables you to retrieve the details of a specific record in Kissflow.

## Input

| Input field | Description |
| --- | --- |
| Object | Specify the object to retrieve the details. Fields load dynamically based on the object you select. |

Custom input fields will load based on the object selected and instance IDs.

## Output

The output fields are determined by the object selected in the input. Map the relevant datapill from the datatree to subsequent steps.
