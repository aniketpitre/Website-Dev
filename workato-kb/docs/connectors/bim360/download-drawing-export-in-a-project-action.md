# BIM 360 - Download drawing export in a project action

The **Download drawing export in a project** action retrieves the file content of an exported drawing you specify from BIM 360.

## Input

| Input fields | Description |
| --- | --- |
| Export link | Provide the download URL of the exported drawing you plan to retrieve. |

## Output

| Output fields | Description |
| --- | --- |
| Content | The drawing's file content. |
