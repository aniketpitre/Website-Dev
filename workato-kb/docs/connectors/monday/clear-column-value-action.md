# Monday - Clear column value action

The **Clear column value** action enables you to clear values from a specific column in a Monday board.

## Input

| Input Field | Description |
| --- | --- |
| Board ID | The board’s unique identifier. |
| Column | The column that contains the values to clear. |
| Item ID | The item’s unique identifier. |

## Output

This action doesn't return any output fields.
