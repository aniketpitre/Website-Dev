# Monday - Create record action

The **Create record** action enables you to create a new record in Monday.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the object type for the newly created record. Fields load dynamically based on the object you select. |

Additional input fields are available based on the object you select. Refer to the [Monday](https://developer.monday.com/api-reference/reference/about-the-api-reference) documentation for a complete list of input fields.

## Output

Output fields depend on the object you select in the input. Refer to the [Monday](https://developer.monday.com/api-reference/reference/about-the-api-reference) documentation for a complete list of output fields.
