> The Set integration run status action in the Coupa connector lets you update the status of an existing integration run by its run ID.

# Coupa - Integration actions

You can set the integration run status in Coupa.

**Integration specific actions**

- `Set integration run status`

* * *

### Input fields for integration actions

This action requires you to provide the integration run ID associated with the run you want to change. This action only allows you to set statuses for integration runs that already exist.

You can select Coupa integration run statuses from a list or dynamically set the integration status by toggling the input field to a text field in addition to selecting the run ID.

### Get supplier sites by supplier

This action updates the integration run that you selected.

### Output

This action returns the integration object affected with all attributes associated with it.
