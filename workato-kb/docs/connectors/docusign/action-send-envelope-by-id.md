# Docusign - Send envelope by ID action

The **Send envelope by ID** action sends a draft envelope to its recipients in Docusign. Only envelopes in **created** status can be sent. Refer to the Docusign [Envelopes: update](https://developers.docusign.com/docs/esign-rest-api/reference/envelopes/envelopes/update/) API reference for more information.

## Input

| Input field | Description |
| --- | --- |
| Envelope ID | Enter the ID of the draft envelope to send. |

## Output

| Output field | Description |
| --- | --- |
| Envelope ID | The ID assigned to the envelope for tracking and managing the document lifecycle. |
