# Docusign - Download document action

The **Download document** action downloads a document to a specified location in Docusign.

## Input

| Input field | Description |
| --- | --- |
| Envelope ID | Enter the GUID value that identifies a Docusign [envelope](https://developers.docusign.com/docs/esign-rest-api/esign101/concepts/envelopes/). Docusign automatically generates this value when the envelope is created. |
| Document ID | Enter the document's unique identifier. |

## Output

| Output field | Description |
| --- | --- |
| Document | The document to be downloaded. |
| Size | The download size of the document. |
