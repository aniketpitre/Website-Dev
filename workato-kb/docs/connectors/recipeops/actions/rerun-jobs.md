> The Rerun jobs action in the RecipeOps connector lets you re-run one or more specified recipe jobs by their job IDs.

# RecipeOps - Rerun jobs action

This action re-runs specified recipe jobs.

* * *

## Input

| Field | Description |
| --- | --- |
| **Recipe** | The recipe where the job must be re-run. |
| **Jobs** | Details about the jobs to be re-run. |

* * *

## Output

There are no outputs for this step.
