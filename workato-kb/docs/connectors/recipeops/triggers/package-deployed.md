# RecipeOps - Package deployed trigger

The **Package deployed** trigger monitors selected connections and triggers when a package is deployed.

## Output

| Field | Description |
| --- | --- |
| Package ID | The unique identifier for the deployed package. |
| Lookup table contents | Notes if the deployed package includes lookup table contents or not. |
| Deployed at | The time the package was deployed. |
| Deployed by | The user who deployed the package. |
| Target folder | The project folder where the package was deployed. |
