# Unsupported records in NetSuite

Triggers and search actions do not support certain records because they cannot be queried through the NetSuite API.

## Unsupported objects in search record action and trigger

You can use the **Get all standard records** action to retrieve objects that do not appear in search actions:

- Budget category
- Campaign audience
- Campaign category
- Campaign channel
- Campaign family
- Campaign response
- Campaign offer
- Campaign search engine
- Campaign subscription
- Campaign vertical
- Currency
- Landed cost
- Lead source
- Sales tax item
- State
- Support case issue
- Support case origin
- Support case priority
- Support case status
- Support case type
- Tax account
- Tax group
- Tax type

## Unsupported objects in trigger

- Accounting period
- Billing account
- Billing schedule
- Bin
- Budget
- Campaign response
- Contact category
- Contact role
- Cost category
- Coupon code
- Custom list
- Customer category
- Customer message
- Customer status
- Entity group (new trigger not supported)
- Expense category
- Fair value price
- Folder (new trigger not supported)
- Gift certificate (new/updated trigger not supported)
- Global account mapping
- Inventory number
- Item account mapping
- Item revision
- Job status
- Job type
- Landed cost
- Manufacturing cost template
- Manufacturing operation task
- Manufacturing routing
- Nexus
- Other name category
- Partner category
- Payment method
- Payroll item
- Phone call
- Price level
- Pricing group
- Promotion code
- Rev rec schedule
- Rev rec template
- Sales role
- Sales tax item
- Site category
- Solution
- Tax group
- Tax type
- Term
- TimeSheet
- Topic
- Units type
- Vendor category
- Win loss reason
