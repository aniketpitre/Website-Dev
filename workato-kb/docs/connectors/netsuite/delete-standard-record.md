# NetSuite SOAP - Delete standard record action

The **Delete standard record** action allows you to delete a standard record in NetSuite by internal ID.

## Input

| Input field | Description |
| --- | --- |
| Standard record | Select the NetSuite standard record type to delete. |
| Record ID | Provide the NetSuite internal ID of the record to delete. |

## Output

| Output field | Description |
| --- | --- |
| Name | The name of the deleted record. |
| Internal ID | The internal ID of the deleted record. |
| Type | The type of the deleted record. |
| Deleted date | The date the record was deleted. |
