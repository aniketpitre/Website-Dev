# Xero - Search bank transactions batch action

The **Search bank transactions** batch action allows you to find bank transactions in Xero that match specified search criteria.

![Search accounts action](/assets/search-bank-action.GPirE2rZ.png)_Xero - Search bank transactions batch action_

## Input

| Input field | Description |
| --- | --- |
| Bank account name | Use the name or code of the bank account to find transactions. |
| Total | Enter the total amount of the transaction to include in the search. |
| Status | Choose the status of the transactions to search for. Valid values are `AUTHORISED` or `DELETED`. |

## Output

| Output field | Description |
| --- | --- |
| Bank transactions | A collection of bank transaction details within Xero. |
