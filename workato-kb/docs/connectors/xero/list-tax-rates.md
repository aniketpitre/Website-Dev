# Xero - List tax rates batch action

The **List tax rates** batch action allows you to retrieve a list of tax rate records from your connected Xero account.

![List tax rates action](/assets/list-tax-rates-action.BP6K1XNU.png)_Xero - List tax rates batch action_

## Input

This action does not require any input.

## Output

| Output field | Description |
| --- | --- |
| Name | The name of the tax rate. |
| Tax type | The type of tax associated with the tax rate. |
| Report tax type | This specifies how the tax is reported. |
| Can apply to assets | Indicates whether this tax rate can be applied to asset transactions. |
| Can apply to equity | Indicates whether this tax rate can be applied to equity transactions. |
| Can apply to expenses | Indicates whether this tax rate can be applied to expense transactions. |
| Can apply to liabilities | Indicates whether this tax rate can be applied to liability transactions. |
| Can apply to assets | Indicates whether this tax rate can be applied to asset transactions. |
| Can apply to revenue | Indicates whether this tax rate can be applied to revenue transactions. |
| Display tax rate | The tax rate that is displayed to users, often a percentage. |
| Effective rate | The actual effective tax rate applied after considering all components and potential reductions. |
| Status | The current status of the tax rate. |
| Tax components | A list of components that make up the overall tax rate. Each component can have its own name, rate, and characteristics. |
