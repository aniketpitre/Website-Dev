# Xero - List currencies batch action

The **List currencies** batch action allows you to retrieve a list of currency records from your connected Xero account.

![List currencies action](/assets/list-currencies-action.Ckle40Au.png)_Xero - List currencies batch action_

## Input

This action does not require any input.

## Output

| Output field | Description |
| --- | --- |
| Code | The currency code retrieved from your connected Xero account. |
| Description | The description of the currency retrieved from your connected Xero account. |
