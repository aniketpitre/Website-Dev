# Xero - Search manual journals batch action

The **Search manual journals** batch action allows you to search for manual journals in Xero.

![Search manual journals action](/assets/search-manual-journals.BbbdpJWK.png)_Xero - Search manual journals batch action_

## Input

| Input field | Description |
| --- | --- |
| Journal ID | Enter the unique Xero internal ID for manual journals to retrieve a specific journal. |
| Narration | Input the narration associated with the manual journal. |
| Status | Select the status of the manual journal you plan to find. Options include `Draft`, `Posted`, `Archived`, and `Voided`. |
| Journal date | Specify the date of the journal entry. |

## Output

| Output field | Description |
| --- | --- |
| Manual journals | A list of manual journal entries. |
