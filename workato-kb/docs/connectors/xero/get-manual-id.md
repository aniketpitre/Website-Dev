# Xero - Get manual journal by ID action

The **Get manual journal by ID** action allows you to retrieve the details of a specific manual journal from Xero using the journal's unique identifier.

![Get manual journal by ID action](/assets/get-manual-id-action.B02Ty-yk.png)_Xero - Get manual journal by ID action_

## Input

| Input field | Description |
| --- | --- |
| Journal ID | Enter the unique ID for the manual journal you plan to retrieve information about. |

## Output

| Output field | Description |
| --- | --- |
| Manual journal ID | The unique identifier for the manual journal. |
| Narration | A brief description or note about the manual journal. |
| Line amount types | The type of line amount, indicating whether it includes tax, excludes tax, or has no tax. |
| Status | The current status of the manual journal. |
| Has attachments | Indicates whether there are attachments linked to the manual journal. |
| Show on cash basis reports | Specifies whether the manual journal should appear on cash basis reports. |
| Date | The date the manual journal was created. |
| Updated date UTC | The UTC date and time when the manual journal was last updated. |
| Journal lines | Details of each line within the manual journal. |
