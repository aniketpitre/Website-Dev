# Xero - Search purchase orders batch action

The **Search purchase orders** batch action allows you to search for purchase orders using specific criteria. You must provide at least one search field.

![Search purchase orders action](/assets/search-purchase-orders-action.BpHCGsig.png)_Xero - Search purchase orders batch action_

## Input

| Input field | Description |
| --- | --- |
| Date from | Specify the start date from which to fetch purchase orders. |
| Date to | Specify the end date until which to fetch purchase orders. |
| Status | Enter the status to filter the purchase orders. Valid values are `AUTHORISED`, `BILLED`, or `DRAFT`. |

## Output

| Output field | Description |
| --- | --- |
| Purchase orders | Details about the purchase orders. |
