# Xero - Search payments batch action

The **Search payments** batch action allows you to search for payments using specific criteria, such as the payment ID or reference.

![Search payments action](/assets/search-payments-action.PDvxKq1C.png)_Xero - Search payments batch action_

## Input

| Input field | Description |
| --- | --- |
| Payment ID | Enter the Xero Payment ID to locate a specific payment. |
| Reference | Provide the payment reference. |
| Invoice number | Use the associated invoice number to find payments related to it. |

## Output

| Output field | Description |
| --- | --- |
| Payments | A list of payment details. |
