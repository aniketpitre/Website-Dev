# Xero - Get online invoice URL action

The **Get online invoice URL** action allows you to obtain the URL for an online invoice in Xero by using the invoice's unique identifier. You cannot generate online invoice URLs for deleted or draft invoices.

![Get online invoice URL action](/assets/get-invoice-url-action.C7XsO3AR.png)_Xero - Get online invoice URL action_

## Input

| Input field | Description |
| --- | --- |
| Invoice ID | Input the Xero Invoice ID to get the URL of the sales invoice page. The Invoice ID can be found at the end of the URL of a sales invoice page in Xero. |

## Output

| Output field | Description |
| --- | --- |
| Online invoice URL | The URL that directs to the online invoice within Xero. |
