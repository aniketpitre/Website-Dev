# Gmail (Custom) - Turn off POP action

The **Turn off POP** action updates the POP settings for a Gmail mailbox. This action requires the `https://www.googleapis.com/auth/gmail.settings.basic` OAuth scope.

## Input

| Input field | Description |
| --- | --- |
| User id | Enter the user's email address. |
| Access window | Select the range of messages that are accessible over POP. |
| Disposition | Select the action to take on a message after it's fetched over POP. |

## Output

| Output field | Description |
| --- | --- |
| Access window | The range of messages that are accessible over POP. |
| Disposition | The action taken on a message after it's fetched over POP. |
| User id | The user's email address. |
