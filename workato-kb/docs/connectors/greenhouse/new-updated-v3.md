# Greenhouse - New/updated object (v3) batch trigger

The **New/updated object (v3)** batch trigger triggers when an object is created or updated in Greenhouse using the v3 API.

This trigger is available for OAuth 2.0 connections only.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the object type to monitor. |
| When first started, this recipe should pick up events from | Specify the date and time to start processing events. |
| Batch size | Specify the maximum number of records to process per trigger event. |

## Output

| Output field | Description |
| --- | --- |
| Objects | List of objects that were created or updated. |
