# Greenhouse - Mark candidate as hired (v3) action

The **Mark candidate as hired (v3)** action marks an application as hired in Greenhouse using the v3 API.

This action is available for OAuth 2.0 connections only.

## Input

| Input field | Description |
| --- | --- |
| Application ID | Enter the ID of the application to mark as hired. |
| Start date | Enter the start date of the employee. |
| Opening ID | Enter the opening ID to associate with this hire. |
| Close reason | Provide the reason for closing the application as hired. |

## Output

| Output field | Description |
| --- | --- |
| Application ID | ID of the application. |
| Hired | Indicates whether the application is marked as hired. |
