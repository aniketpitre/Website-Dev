# Greenhouse - New object (v3) trigger

The **New object (v3)** trigger triggers when a new object is created in Greenhouse using the v3 API.

This trigger is available for OAuth 2.0 connections only.

## Input

| Input field | Description |
| --- | --- |
| Trigger poll interval | Select how frequently to check for new events. |
| Object | Select the object type to monitor. |
| When first started, this recipe should pick up events from | Specify the date and time to start processing events. |

## Output

This trigger returns a data tree that contains information about the new Greenhouse object.
