# Allure TestOps - Get record action

The **Get record** action retrieves details of a record by its ID.

## Input

Input fields load dynamically based on the object you select. The following input field is common to all objects. Refer to the [Allure TestOps](https://docs.qameta.io/) documentation for a complete list of input fields.

| Input field | Description |
| --- | --- |
| Object | Select the object type to retrieve. Options include `Project`, `Test case`, `Test plan`, `Launch`, `Test result`, `Custom field`, and `Custom field value`. |

## Output

Output fields load dynamically based on the object you select. Refer to the [Allure TestOps](https://docs.qameta.io/) documentation for a complete list of output fields.
