# Allure TestOps - Delete record action

The **Delete record** action deletes a record by its ID.

## Input

Input fields load dynamically based on the object you select. The following input field is common to all objects. Refer to the [Allure TestOps](https://docs.qameta.io/) documentation for a complete list of input fields.

| Input field | Description |
| --- | --- |
| Object | Select the object type to delete. Options include `Project`, `Test case`, `Test plan`, `Launch`, and `Test result`. |

## Output

| Field | Description |
| --- | --- |
| Success | Whether the record was deleted successfully. |
