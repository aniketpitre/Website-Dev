# Mural - Delete record action

The **Delete record** action enables you to delete a record in Mural.

## Input

| Input fields | Description |
| --- | --- |
| Object | Specify the object to delete a record. Fields load dynamically based on the object you select. |
| Mural ID | Provide the ID of a Mural. |

## Output

| Output fields | Description |
| --- | --- |
| Success | Success message. |
