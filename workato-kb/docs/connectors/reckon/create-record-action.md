# Reckon - Create record action

The **Create record** action adds a new record in Reckon using the selected object type.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the Reckon object to create. |
| Book ID | Enter the Reckon One Book ID. You can find it in the Reckon One URL. For example, `https://app.reckonone.com/{BookID}/Core`. |
| Name | Enter the display name of the new record. |
| Status | Select the record's status, such as **Active**. |

Additional input fields appear depending on the selected object type.

## Output

| Output field | Description |
| --- | --- |
| ID | Unique identifier of the newly created record. |
| Name | Display name of the created record. |
