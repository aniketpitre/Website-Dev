# Reckon - Update record action

The **Update record** action updates an existing record in Reckon.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the Reckon object to update. |
| Record ID | Enter the ID of the record to update. |
| Book ID | Enter the Reckon One Book ID. You can find it in the Reckon One URL. For example, `https://app.reckonone.com/{BookID}/Core`. |
| Name | Enter the name of the organization or entity. |
| Status | Select the status of the record. |

Additional input fields may appear depending on the selected object.

## Output

| Output field | Description |
| --- | --- |
| Status | Indicates the result of the update. |
| Message | Displays details about the update. |
