> The Egnyte connector lets you automate document workflows: upload, download, copy, move, and search files and folders, and trigger on file events.

# Egnyte

[Egnyte](https://www.egnyte.com/) provides a secure, cloud-based file sharing platform, allowing you to share documents or folders with varying privilege levels, such as view, download, or edit. This provides a more secure alternative to email and enables you to locate and manage sensitive content stored in multiple repositories.

## API version

The Egnyte connector uses the [Egnyte API v1](https://developers.egnyte.com/docs).

## Connection setup

Complete the following steps to create an Egnyte connection in Workato:

1. Provide a **Connection name** that identifies which Egnyte instance Workato is connected to.
   
   ![Connection setup](/assets/connection-setup.cB2gqzGL.png)_Connection setup_
   
2. Use the **Location** drop-down menu to select the location where you plan to store your connection.
   
3. Enter the domain for your Egnyte account in the **Egnyte domain** field. For example: `acme.egnyte.com`.
   
4. Optional. Use the **Custom OAuth profile** drop-down menu to select a custom OAuth profile for your connection.
   
5. Click **Connect**.
   
6. Click **Allow access** when prompted to authorize access for Workato.
   
   ![Authorize Egnyte](/assets/authorize-egnyte.C3se-p_m.png)_Authorize access_
