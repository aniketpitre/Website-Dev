> The Search invoice items action in the Stripe connector lets you search for invoice items associated with a given customer ID in Stripe.

# Stripe - Search invoice items action

This action searches for invoice items in Stripe.

![Search invoice items](/assets/search-invoice-items.GXC2nQJ5.png)_Search invoice items action_

## Input

| Input field | Description |
| --- | --- |
| Customer ID | Provide the customer ID for which you plan to search for invoice items. |

## Output

The output of this action is a datatree that contains information about the [Stripe object](https://stripe.com/docs/api/invoices/object).
