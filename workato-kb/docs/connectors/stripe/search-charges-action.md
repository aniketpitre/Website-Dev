> The Search charges action in the Stripe connector lets you search for charges associated with a given customer ID in Stripe.

# Stripe - Search charges action

This action searches for charges in Stripe.

![Search charges](/assets/search-charges.B0TGMeW_.png)_Search charges action_

## Input

| Input field | Description |
| --- | --- |
| Customer ID | Provide the customer ID for which you plan to search for charges. |

## Output

The output of this action is a datatree that contains information about the [Stripe object](https://stripe.com/docs/api/charges/object).
