> The New charge real-time trigger in the Stripe connector fires in real time when a new charge is created in Stripe.

# Stripe - New charge real-time trigger

This trigger checks for new charges in Stripe in real time.

![New charge trigger](/assets/new-charge-trigger.KG2Lna4R.png)_New charge trigger_

## Input

No additional input is required after you select this trigger.

## Output

The output of this action is a datatree that contains information about the [Stripe object](https://stripe.com/docs/api/charges/object).
