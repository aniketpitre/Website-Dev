> The Get customer by ID action in the Stripe connector lets you retrieve transactions for a specific customer using their customer ID.

# Stripe - Get customer by ID action

This action retrieves a transaction by customer ID in Stripe.

![Stripe connection](/assets/get-customer-by-id.Da5EJCYg.png)_Get customer by ID action_

## Input

| Input field | Description |
| --- | --- |
| ID | Provide the customer ID for which you plan to retrieve transactions. |

## Output

The output of this action is a datatree that contains information about the [Stripe object](https://stripe.com/docs/api/customers/object).
