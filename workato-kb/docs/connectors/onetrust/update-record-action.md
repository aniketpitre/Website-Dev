# OneTrust - Update record action

The **Update record** action updates an assessment in OneTrust.

## Input

Input fields are dynamically generated based on the object you select. Refer to the [OneTrust documentation](https://developer.onetrust.com/onetrust/reference/onetrust-api-reference) for more information on available input fields.

| Input field | Description |
| --- | --- |
| Object type | Select the object you plan to update. |

## Output

| Output field | Description |
| --- | --- |
| Success | Indicates whether the assessment was updated. |
