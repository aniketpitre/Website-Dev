# OneTrust - Search record action

The **Search record** action retrieves a list of assessments or users from OneTrust.

## Input

Input fields are dynamically generated based on the object you select. Refer to the [OneTrust documentation](https://developer.onetrust.com/onetrust/reference/onetrust-api-reference) for more information on available input fields.

| Input field | Description |
| --- | --- |
| Object type | Select the OneTrust object you plan to search for. |

## Output

Output fields are dynamically generated based on the object you select. Refer to the [OneTrust documentation](https://developer.onetrust.com/onetrust/reference/onetrust-api-reference) for more information on available fields.
