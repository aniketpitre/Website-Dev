# Baserow - Delete record action

The **Delete record** action deletes an existing row from a table in Baserow.

## Input

| Input field | Description |
| --- | --- |
| Object type | Select the object type, such as **Row**. |
| Table ID | Select the table the row belongs to. |
| Row ID | Enter the unique identifier of the row to delete. |

## Output

| Output field | Description |
| --- | --- |
| Success | A boolean response (`true` or `false`) that indicates if the row was deleted successfully. |
