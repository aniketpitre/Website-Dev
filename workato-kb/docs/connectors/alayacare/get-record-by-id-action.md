# AlayaCare - Get record by ID action

The **Get record by ID** action retrieves details of a record by providing its ID in AlayaCare.

## Input

Input fields load dynamically based on the selected object. For example, if you select the **Client** object, the following fields appear:

| Input fields | Description |
| --- | --- |
| Object | Select the AlayaCare object from the drop-down menu, such as **Client** or **Schedule**. |
| Client ID | Enter the ID of the record to retrieve. |
| Exclude user deactivated groups | Select **Yes** or **No** to include or exclude deactivated user groups. |

## Output

| Output fields | Description |
| --- | --- |
| Status | Brief description of the record's status. |
| Tags | Brief description of the tags associated with the record. |

Additional output fields load dynamically based on the object you select.
