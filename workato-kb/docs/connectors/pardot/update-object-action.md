# Salesforce Account Engagement (Pardot) - Update object action

The **Update object** action updates an object in Salesforce Account Engagement (Pardot), such as a prospect or email template.

## Input

Input fields dynamically generate based on the object you select. Refer to the Salesforce [Account Engagement API](https://developer.salesforce.com/docs/marketing/pardot/overview) documentation for more information on available input fields.

| Input field | Description |
| --- | --- |
| Object type | Select the object to update. |
| ID | Enter the unique ID of the object to update. |

## Output

Output fields dynamically generate based on the object you select. Refer to the Salesforce [Account Engagement API](https://developer.salesforce.com/docs/marketing/pardot/overview) documentation for more information on available output fields. The following field is common to all objects.

| Output field | Description |
| --- | --- |
| ID | The object's unique ID. |
