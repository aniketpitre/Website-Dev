# Salesforce Account Engagement (Pardot) - Delete object action

The **Delete object** action deletes an object from Salesforce Account Engagement (Pardot), such as a prospect or email template.

## Input

| Input field | Description |
| --- | --- |
| Object type | Select the object to delete. |
| ID | Enter the unique ID of the object to delete. |

## Output

| Output field | Description |
| --- | --- |
| Success | A boolean value (`true` or `false`) that indicates whether the action deleted the object. |
