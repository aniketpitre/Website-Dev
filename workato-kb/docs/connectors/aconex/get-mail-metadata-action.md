# Aconex - Get mail metadata action

The **Get mail metadata** action retrieves the metadata for a mail item in Aconex.

## Input

| Input field | Description |
| --- | --- |
| Project | Select the project you plan to get mail metadata from. |
| Mail box | Select the mailbox you plan to get main metadata from. |
| Mail | Select the mail item you plan to get mail metadata from. |

## Output

This action has a large amount of outputs. Refer to the [Aconex documentation](https://help.aconex.com/apis/mail-api-developer-guide/) for a complete list of output fields.
