# Aconex - Delete draft mail action

The **Delete draft mail** action deletes one or more draft mail items in Aconex.

## Input

| Input field | Description |
| --- | --- |
| Project | Select the project where the draft mail item you plan to delete is located. |
| Draft mails | Select the draft mail items you plan to delete. You can select up to 100 draft mail items. |

## Output

| Output field | Description |
| --- | --- |
| Project ID | The ID of the project where the deleted draft mail item is located. |
| Delete results | Information about the deleted draft mail items. |
| Total requested | The total number of draft mail items you requested to delete. |
| Deleted count | The number of deleted draft mail items. |
| Not deleted count | The number of not draft mail items. |
