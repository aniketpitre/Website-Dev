# Aconex - Register document action

The **Register document** action registers a new document with a file upload in Aconex.

## Input

Input fields are dynamically generated based on the file size of the registered document. The following input fields are common to all file sizes:

| Input field | Description |
| --- | --- |
| File size | Select the size of the file to register a new document with. |
| Project | Select the project to of the file register with a new document. |

## Output

Output fields are dynamically generated based on the file size of the registered document. Refer to the [Aconex documentation](https://help.aconex.com/apis/api-guide-documents/#Register-Document) for a complete list of output fields.
