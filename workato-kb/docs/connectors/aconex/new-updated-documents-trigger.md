# Aconex - New/updated documents trigger

The **New/updated documents** trigger monitors Aconex for new or updated documents.

## Input

| Input field | Description |
| --- | --- |
| Project | Select the project you plan to monitor for new/updated documents. |
| When first started, this recipe should pick up events from | Set the date and time to start picking up trigger events. This enables your recipe to capture past events. Refer to [Triggers](/en/recipes/triggers#since-from) to learn more about this input field. |

## Output

| Output field | Description |
| --- | --- |
| Document ID | The ID of the new/updated document. |
| Last modified date | The date that the new/updated document was modified. |
| Last event date | The date of the last event associated with the new/updated document. |
