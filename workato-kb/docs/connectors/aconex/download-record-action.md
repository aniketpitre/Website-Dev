# Aconex - Download record action

The **Download record** action downloads a document or mail attachments from Aconex.

## Input

| Input field | Description |
| --- | --- |
| Download type | Select the type of file you plan to download. |
| Project | Select the project that you plan to download the file from. |
| Mail box | Select the mailbox you plan to download the file from. |
| Mail | Select the mail item you plan to download the file from. |
| Attachment | Select the attachment you plan to download. |

## Output

| Output field | Description |
| --- | --- |
| File content | The content of the downloaded file. |
| Project ID | The ID of the project where the downloaded file is located. |
| Attachment ID | The ID of the downloaded attachment. |
| File name | Enter the name of the downloaded file. |
| File size | Enter the size of the downloaded file. |
| Description | The description of the downloaded file. |
| Mail ID | The ID of the mail item the file was downloaded from. |
| Document ID | The ID of the downloaded document. |
| Document number | The document number of the downloaded file. |
| Title | The title of the downloaded file. |
| Revision | The revision value of the downloaded file. |
