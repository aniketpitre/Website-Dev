# Aconex - List records action

The **List records** action retrieves a list of all records in the object type you select in Aconex.

## Input

| Input field | Description |
| --- | --- |
| Object type | Select the object type to list, such as `Project`. |

## Output

| Output field | Description |
| --- | --- |
| Records | Output fields related to the returned records. These include, Project ID, Project name, start date, stop date, and more. |
| Total results count | The total number of returned results. |
