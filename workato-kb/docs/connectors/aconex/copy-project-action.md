# Aconex - Copy project action

The **Copy project** action copies an existing project in Aconex.

## Input

| Input field | Description |
| --- | --- |
| Source project | Enter the project ID of the project to copy. |
| Project name | Enter the name of the new project copy. Maximum of 60 characters. |
| Project short name | Enter the short name of the new project copy. Maximum of 20 characters. |
| Project code | Enter the code for the new project copy. Maximum 15 characters. |
| Project type | Enter the type of the new project copy. Maximum 20 characters. |
| Register type | Select the type of register for the new project copy. |
| Start date | Enter the start date for the new project copy. |
| Estimated completion date | Enter the estimated completion date of the new project copy. |
| Currency | Enter the currency to use for the new project copy. |
| Project value | Enter the project value for the new project copy. |
| Date project status applied | Enter the date that the project status was applied. |

## Output

| Output field | Description |
| --- | --- |
| Message | A message indicating if the copy project action was successful, or an error message if the project was unsuccessful. |
| Status | The status of the Copy project action. |
| Source project ID | The ID of the project the new project was copied from. |
| New project name | The name of the new project copy. |
