# Aconex - Search records action

The **Search records** action retrieves a list of records that match your search criteria in Aconex.

## Input

Input fields are dynamically generated based on the object you select. The following input fields are common to all objects:

| Input field | Description |
| --- | --- |
| Object type | Select the object type to search for. |

## Output

| Output field | Description |
| --- | --- |
| Records | Information about the returned records, including `Document ID`, `Confidential`, and `Document number`. |
| Total count | The total number of returned records. |
| Project ID | The ID of the project searched for records. |
| Total results on page | The number of results on each page. |
| Total pages | The total number of pages of search results. |
| Page size | The number of records returned in a single response. |
| Current page | The current page you are viewing in the response. |
