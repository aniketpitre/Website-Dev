# HiBob - Delete object action

The **Delete object** action enables you to delete a standard or custom record, such as an employee record, through its HiBob ID. You must select the object, then specify the HiBob ID of the record you plan to delete.

## Input

| Input field | Description |
| --- | --- |
| List name | Provide the internal name of the list. |
| Item ID | Provide the unique ID of the list item to be deleted. |

## Output

The **Delete object** action doesn’t return an output schema.
