# HiBob - Download report action (Async)

The **Download report** action allows you to download a report data file from HiBob in the format you specify when it’s ready.

## Input

| Input field | Description |
| --- | --- |
| Report ID | Enter the report ID to be downloaded from HiBob. |
| Format | Select the file format from the drop-down menu. |
| Include info | Select the suitable Boolean value from the drop-down menu. |
| Locale | Requested language for the report columns in the format of locale. The user's preferred locale is used if you don't provide a value. |

## Output

| Output field | Description |
| --- | --- |
| File contents | The file content of the report data file. |
