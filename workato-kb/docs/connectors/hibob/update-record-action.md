# HiBob - Update record action

The **Update record** action updates the specified record in HiBob.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the object from the drop-down menu. |

Input fields are dynamically loaded based on the selected object. The following example displays the input schema for the **Employee email** object:

| Input fields | Description |
| --- | --- |
| Employee ID | Provide the ID of employee whose email you plan to update. |
| New email | Provide the new email ID. |

## Output

This action doesn’t return an output schema.
