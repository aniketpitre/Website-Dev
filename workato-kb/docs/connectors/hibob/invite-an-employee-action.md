# HiBob - Invite an employee action

The **Invite an employee** action allows you to invite an employee on HiBob.

## Input

| Input field | Description |
| --- | --- |
| Employee ID | Provide the ID of the employee to be invited. |
| Welcome wizard ID | Provide the unique wizard ID to which the employee is being invited. |

## Output

The **Invite an employee** action doesn’t return an output schema.
