# HiBob - Revoke access for employee action

The **Revoke access for employee** action revokes the access for an employee in HiBob.

## Input

| Input field | Description |
| --- | --- |
| Employee ID | Provide the ID of the employee whose access you plan to revoke. |

## Output

This action doesn’t return an output schema.
