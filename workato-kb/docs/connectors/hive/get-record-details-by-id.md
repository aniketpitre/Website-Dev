# Hive - Get record details by ID action

The **Get record details by ID** action retrieves details for a Hive object, such as a user, project, or action, using the object's ID.

## Input

| Input field | Description |
| --- | --- |
| Object | Select a Hive object from the list, such as **User**, **Resource Assignment**, **Project**, **Label**, or **Action**. |
| Record ID | Enter the ID of the object to retrieve. |

## Output

The output fields depend on the object you select in the input. Each object returns a unique set of fields based on its type. Refer to [Hive's API documentation](https://developers.hive.com/reference/introduction) for more information.
