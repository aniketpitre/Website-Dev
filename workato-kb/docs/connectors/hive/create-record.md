# Hive - Create record action

The **Create record** action creates a new record in Hive. This can include users, resource assignments, projects, messages, labels, or actions.

## Input

| Input field | Description |
| --- | --- |
| Object | Select a Hive object from the list. The available input fields depend on the object you select. |

## Output

The output fields depend on the object you select in the input. Each object returns a unique set of fields based on its type. Refer to [Hive's API documentation](https://developers.hive.com/reference/introduction) for more information.
