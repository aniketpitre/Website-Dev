# Hive - Apply action template action

The **Apply action template** action applies a predefined template to a selected action in Hive.

## Input

| Input field | Description |
| --- | --- |
| Action ID | Provide the ID of the action to apply the template. |
| Action template | Select an action template from the list, such as **New Hire Onboarding**. |

## Output

| Output field | Description |
| --- | --- |
| Success | Indicates whether Hive successfully applied the template. |
| Message | Provides details about the template application result. |
