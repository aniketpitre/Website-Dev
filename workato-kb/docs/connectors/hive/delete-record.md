# Hive - Delete record action

The **Delete record** action deletes a Hive object by its ID. This can include users, resource assignments, projects, labels, or actions.

## Input

| Input field | Description |
| --- | --- |
| Object | Select a Hive object from the list, such as **Resource assignment**, **Project**, **Label**, or **Action**. |
| Record ID | Enter the ID of the object to delete. |

## Output

| Output field | Description |
| --- | --- |
| Success | Indicates whether Hive successfully deleted the object. |
| Message | Provides details about the delete operation result. |
