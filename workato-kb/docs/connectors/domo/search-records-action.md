# Domo - Search records action

The **Search records** action retrieves a list of records for an object you select, such as accounts, datasets, or users, in Domo.

## Input

Input fields are dynamically generated based on the object you select. The following input fields are common to all objects.

| Input field | Description |
| --- | --- |
| Object | Select the Domo object to search. For example, **User** or **Dataset**. |
| Limit | Enter the number of records to return. |
| Offset | Enter the offset of the first record to return in the response. |

## Output

Output fields are dynamically generated based on the object you select. Refer to the [Domo API documentation](https://developer.domo.com/) for more information about output fields.
