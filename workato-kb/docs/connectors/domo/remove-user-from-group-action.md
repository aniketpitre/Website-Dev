# Domo - Remove user from group action

The **Remove user from group** action removes a user from a group in Domo.

## Input

| Input field | Description |
| --- | --- |
| Group ID | Enter the ID of the group. |
| User ID | Enter the ID of the user to remove. |

## Output

| Output field | Description |
| --- | --- |
| Status | Returns `Success` when the user is removed from the group. |
