# Domo - Import data action

The **Import data** action imports data into a Domo dataset. This action replaces the existing data in the dataset.

## Input

Input fields are dynamically generated based on the dataset you select. The following input fields are common to all datasets.

| Input field | Description |
| --- | --- |
| Dataset name | Select the dataset to import data into. Toggle to **Dataset ID** to enter a dataset ID as a custom value. |
| Data | Enter the data source list and the data fields you plan to import. |

## Output

| Output field | Description |
| --- | --- |
| Status | Returns `Success` when the data is imported. |
