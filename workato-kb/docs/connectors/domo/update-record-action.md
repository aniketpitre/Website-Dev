# Domo - Update record action

The **Update record** action updates an existing record for an object you select, such as an account, dataset, or user, in Domo using its Domo ID.

## Input

Input fields are dynamically generated based on the object you select. The following input fields are common to all objects.

| Input field | Description |
| --- | --- |
| Object | Select the Domo object to update, for example, **User** or **Dataset**. |

## Output

Output fields are dynamically generated based on the object you select. Refer to the [Domo API documentation](https://developer.domo.com/) for more information about output fields.
