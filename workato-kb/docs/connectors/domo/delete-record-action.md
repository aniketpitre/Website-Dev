# Domo - Delete record action

The **Delete record** action deletes a record for an object you select, such as an account, dataset, or user, in Domo.

## Input

Input fields are dynamically generated based on the object you select. The following input fields are common to all objects.

| Input field | Description |
| --- | --- |
| Object | Select the Domo object to delete. For example, **User** or **Dataset**. The available objects are account, dataset, group, user, project, and list. |

## Output

| Output field | Description |
| --- | --- |
| Status | Returns `Success` when the record is deleted. |
