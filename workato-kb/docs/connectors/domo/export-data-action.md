# Domo - Export data action

The **Export data** action exports the data from a Domo dataset.

## Input

| Input field | Description |
| --- | --- |
| Dataset name | Select the dataset you plan to export data from. |
| Include header | Select whether to include the column header row in the exported data. |
| File name | Enter the filename of the exported CSV. |

## Output

| Output field | Description |
| --- | --- |
| Data | The exported dataset data in CSV format. |
