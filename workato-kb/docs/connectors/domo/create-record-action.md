# Domo - Create record action

The **Create record** action creates a record for an object you select, such as an account, dataset, or user, in Domo.

## Input

Input fields are dynamically generated based on the object you select. The following input fields are common to all objects.

| Input field | Description |
| --- | --- |
| Object | Select the Domo object to create, for example, **User** or **Dataset**. |

## Output

The output of this action varies based on the object you select. Refer to the [Domo API documentation](https://developer.domo.com/) for more information on available objects and fields.
