# Domo - Add user to group action

The **Add user to group** action adds a user to a group in Domo.

## Input

| Input field | Description |
| --- | --- |
| Group ID | Enter the ID of the group. |
| User ID | Enter the ID of the user to add. |

## Output

| Output field | Description |
| --- | --- |
| Status | Returns `Success` when the user is added to the group. |
