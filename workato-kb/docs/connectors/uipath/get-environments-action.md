# UiPath - Get environments action

The **Get environments** action retrieves the list of environments in the UiPath Orchestrator.

## Input

This action doesn’t require input.

## Output

| Output field | Description |
| --- | --- |
| ID | ID of the environment. |
| Name | Name of the environment. |
| Description | Description associated with the environment. |
