# UiPath - Get queues action

The **Get queues** action allows you to retrieve a list of queues from UiPath Orchestrator.

## Input

The action doesn’t require input.

## Output

| Output field | Description |
| --- | --- |
| ID | A unique identifier for the queue. |
| Name | Display name of the queue. |
| Description | Optional text providing details about the queue’s purpose or usage. |
