# UiPath - Get machine sessions action

The **Get machine sessions** action allows you to retrieve a list of machine sessions from UiPath Orchestrator.

## Input

This action doesn’t require input.

## Output

| Output field | Description |
| --- | --- |
| ID | Unique identifier of the machine session. |
| Host machine name | Name of the physical or virtual host where the session is running. |
| Machine name | Name of the UiPath machine resource associated with the session. |
| State | Current state of the session. |
| Machine ID | Unique identifier of the machine linked to the session. |
