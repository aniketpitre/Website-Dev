# Adobe Commerce - Powered by Magento

[Adobe Commerce - Powered by Magento](https://magento.com/) is an open-source e-commerce management platform that helps merchants and brands across B2C and B2B industries build eCommerce websites with customization and scalability. Use the trigger from the Magento/ Adobe Commerce connector on Workato to run the recipe each time a new event occurs in Adobe Commerce, and the actions to add customers and products, as well as search for customers, products, and orders.

## API version

This connector uses the [Magento web REST API](https://devdocs.magento.com/guides/v2.4/get-started/rest_front.html).

## How to connect to Magento on Workato

Workato uses token-based authentication to connect with Adobe Commerce. To establish a connection, provide your Adobe Commerce/ Magento login credentials including the server domain and account type (admin or customer), and click **Connect**.

> Adobe Commerce/ Magento admin account allows you to manage your store, order, and customer data while a customer workspace allows you to see the site just as the customer does. In most cases, you will be connecting to your admin account.
