> The Delete file action in the Amazon S3 connector lets you delete a file from a specified bucket and region by its object name.

# Amazon S3 - Delete file action

The **Delete file** action deletes a file from Amazon S3.

![Amazon S3 - Delete file action](/assets/delete-file-action.CIEJmAc9.png)_Amazon S3 - Delete file action_

## Input

| Field name | Description |
| --- | --- |
| Region | Select the region of the bucket where the file resides. For example, `us-west-2`. In Amazon S3, go to **Bucket > Properties > Static website hosting** to find your region in the Endpoint URL. |
| Bucket name | Enter the bucket where the file resides. The bucket name is case sensitive. |
| Object name | Enter the file name to delete. The file name is case sensitive. |

## Output

There is no output for this action.
