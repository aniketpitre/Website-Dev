# GitLab - Update record action

The **Update record** action updates a record in GitLab.

## Input

Input fields are dynamically generated based on the object you select. The following field is common to all object types.

| Input field | Description |
| --- | --- |
| Object | Select the object from the drop-down menu. |

## Output

The output of this action varies based on the object you select. Refer to the GitLab [REST API resources](https://docs.gitlab.com/api/api_resources/) guide for more information on available objects and fields.
