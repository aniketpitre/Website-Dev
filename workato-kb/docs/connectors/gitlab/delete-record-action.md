# GitLab - Delete record action

The **Delete record** action deletes a record in GitLab.

## Input

Input fields are dynamically generated based on the object you select. The following field is common to all object types.

| Input field | Description |
| --- | --- |
| Object | Select the object from the drop-down menu. |

## Output

| Output field | Description |
| --- | --- |
| Message | A text string that provides the status of the request. The exact data returned depends on the outcome of your request (Success, Error, and Failure). For example, `"202 Accepted"` or `"403 Forbidden"`. |
