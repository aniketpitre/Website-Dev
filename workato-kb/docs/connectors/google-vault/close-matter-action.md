# Google Vault - Close matter action

The **Close matter** action enables you to close a matter in Google Vault.

![Google Vault Close matter action](/assets/google-vault-close-matter-action.J4qvwMIR.png)_Google Vault **Close matter** action_

## Input

| Input Field | Description |
| --- | --- |
| Matter ID | Use the **Matter ID** drop-down menu to select a hold from Google Vault, or enter the ID manually. |

## Output

| Output Field | Description |
| --- | --- |
| Matter ID | Unique ID of the closed matter. |
| Matter name | Name of the closed matter. |
| Matter description | Description of the closed matter. |
| State | State of the closed matter. |
| Matter permission | A list of permissions for the matter, including roles and associated account IDs. |
| Matter region | The data region where the matter is stored. |
