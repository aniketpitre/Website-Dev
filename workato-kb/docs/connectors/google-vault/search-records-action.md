# Google Vault - Search records action

The **Search records** action enables you to search records in Google Vault.

![Google Vault Search records action](/assets/google-vault-search-records-action.BPJCWlkl.png)_Google Vault **Search records** action_

## Input

| Input Field | Description |
| --- | --- |
| Object | Specify the object you plan to search. Fields dynamically load based on the selected object. |

## Output

The output fields are determined by the object you select in the input. Map the relevant datapills from the data tree for downstream steps.
