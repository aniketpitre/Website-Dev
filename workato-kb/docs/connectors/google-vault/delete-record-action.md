# Google Vault - Delete record action

The **Delete record** action enables you to delete a record in Google Vault.

![Google Vault Delete record action](/assets/google-vault-delete-record-action.CDSV8pAb.png)_Google Vault **Delete record** action_

## Input

| Input Field | Description |
| --- | --- |
| Object | Specify the object you plan to delete. Fields dynamically load based on the selected object. |

## Output

The output fields are determined by the object you select in the input. Map the relevant datapills from the data tree for downstream steps.
