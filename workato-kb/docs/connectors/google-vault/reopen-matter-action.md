# Google Vault - Reopen matter action

The **Reopen matter** action enables you to reopen a matter in Google Vault.

![Google Vault Reopen matter](/assets/google-vault-reopen-matter-action.Bs6N02u-.png)_Google Vault **Reopen matter** action_

## Input

| Input Field | Description |
| --- | --- |
| Matter ID | Use the **Matter ID** drop-down menu to select a hold from Google Vault, or enter the ID manually. |

## Output

| Output Field | Description |
| --- | --- |
| Matter ID | Unique ID of the reopened matter. |
| Matter name | Name of the reopened matter. |
| Matter description | Description of the reopened matter. |
| State | State of the reopened matter. |
| Matter permission | A list of permissions for the matter, including roles and associated account IDs. |
| Matter region | The data region where the matter is stored. |
