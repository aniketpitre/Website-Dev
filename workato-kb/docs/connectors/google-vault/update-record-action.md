# Google Vault - Update record action

The **Update record** action enables you to update a record in Google Vault.

![Google Vault Update record action](/assets/google-vault-update-record-action.DnKlcaJR.png)_Google Vault **Update record** action_

## Input

| Input Field | Description |
| --- | --- |
| Object | Specify the object you plan to update. Fields dynamically load based on the selected object. |

## Output

The output fields are determined by the object you select in the input. Map the relevant datapills from the data tree for downstream steps.
