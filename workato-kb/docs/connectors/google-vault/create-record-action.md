# Google Vault - Create record action

The **Create record** action enables you to create a record in Google Vault.

![Google Vault Create record action](/assets/google-vault-create-record-action.CP_EqMpb.png)_Google Vault **Create record** action_

## Input

| Input Field | Description |
| --- | --- |
| Object | Specify the object you plan to create. Fields dynamically load based on the selected object. |

## Output

The output fields are determined by the object you select in the input. Map the relevant datapills from the data tree for downstream steps.
