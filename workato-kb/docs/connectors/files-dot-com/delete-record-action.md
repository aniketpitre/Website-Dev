# Files.com - Delete record action

The **Delete record** action deletes a record in Files.com.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the type of object to delete. |
| Path | Enter the file path of the record to delete. For example: `folder/file.txt`. |
| Recursive | Select `Yes` to recursively delete folders. Select `No` to return an error on non-empty folders. |

## Output

This action doesn't return any output fields.
