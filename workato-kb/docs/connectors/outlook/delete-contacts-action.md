# Outlook - Delete contact action

Use this action to delete an existing contact from the Outlook contact folder you specify.

## Input

| Field | Description |
| --- | --- |
| Shared contacts mailbox | Provide the email address of the shared mailbox to delete a shared contact. For example, `support@example.onmicrosoft.com`. If left blank, Workato shows the default contacts from your Outlook account. |
| Contact ID | Specify the ID of the contact you plan to delete. |

## Output

| Field | Description |
| --- | --- |
| Success | Indicates whether the contact was deleted successfully. |
