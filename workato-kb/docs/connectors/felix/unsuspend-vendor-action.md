# Felix - Unsuspend vendor action

The **Unsuspend vendor** action unsuspends a vendor that is currently approved and suspended.

## Input

| Input field | Description |
| --- | --- |
| Vendor ID | Enter the numeric ID of the vendor. |

## Output

| Output field | Description |
| --- | --- |
| Code | The error code associated with the job. Is either `204` or `422`. |
| Message | The message associated with the error code. Such as `Vendor is not suspended.`. |
