# Gainsight NXT - Create company record/s action

The **Create company record/s** action creates one or more company records in `Gainsight NXT`.

## Input

| Input field | Description |
| --- | --- |
| Companies | Input a list of up to 50 company records to create. Each record has fields, such as `Name`, `Industry`, `Average recurring revenue`, `Number of employees`, `Stage`, `Status`, and `Tags`. |
| Lookups | Enter CSM fields, including `CSM` and `Parent company`. Select the lookup field, the object name, a multi-match option, and an on-no-match behavior. |

## Output

This action has multiple output fields. Refer to the [Gainsight NXT API](https://support.gainsight.com/gainsight_nxt/API_and_Developer_Docs/Company_and_Relationship_API/Company_API_Documentation) documentation for a complete list of output fields.
