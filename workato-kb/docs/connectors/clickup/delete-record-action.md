# ClickUp - Delete record action

The **Delete record** action deletes the specified record from ClickUp.

## Input

Input fields load dynamically based on object selection. For example, if you select the **Folder** object, then the following input fields are available.

| Input field | Description |
| --- | --- |
| Folder ID | Specify the unique ID of the folder to be deleted. |

## Output

This action doesn’t generate any output.
