# Creatomate - Delete record action

The **Delete record** action deletes a template you specify in Creatomate. This action can't be undone. Renders already created from the template aren't affected.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the object you plan to delete. **Template** is the only available object. |
| Template ID | Enter the ID of the template you plan to delete. |

## Output

| Output field | Description |
| --- | --- |
| Success | Indicates whether the template was deleted. |
| Message | Confirmation message after a successful delete. |
