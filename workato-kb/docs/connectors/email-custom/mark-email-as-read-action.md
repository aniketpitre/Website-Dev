# Email (Custom) - Mark email as read action

The **Mark email as read** action marks an email as read using the **IMAP** protocol. This action is available only with **IMAP**.

## Input

| Input field | Description |
| --- | --- |
| Mailbox | Select or enter the name of the mailbox that contains the email. |
| Email UID | Enter the UID of the email to mark as read. |

## Output

| Output field | Description |
| --- | --- |
| Result | Indicates whether the action successfully marked the email as read or not. |
