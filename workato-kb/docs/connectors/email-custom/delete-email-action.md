# Email (Custom) - Delete email action

The **Delete email** action deletes an email from a mailbox using the **IMAP** protocol. This action is available only with **IMAP**.

## Input

| Input field | Description |
| --- | --- |
| Mailbox | Select or enter the name of the mailbox that contains the email. |
| Email UID | Enter the UID of the email to delete. |

## Output

| Output field | Description |
| --- | --- |
| Result | Indicates whether the action successfully deleted the email or not. |
