# Jira Service Desk - Get issues in queue action

This action gets a list of issues in queue within your Jira Service Desk instance.

![Get issues in queue action](/assets/get-issues-in-queue-action.DYJm72Re.png)_Get issues in queue action_

## Input

| Input field | Description |
| --- | --- |
| Service desk | The service desk where the queue resides |
| Queue ID | The ID of the queue |

## Output

The output of this action will be a list of datatree that contains information about the created Jira Service Desk issues.

Find out more about [Jira Service Desk issue object](https://developer.atlassian.com/cloud/jira/service-desk/rest/api-group-servicedesk/#api-rest-servicedeskapi-servicedesk-servicedeskid-queue-queueid-issue-get).
