# Jira Service Desk - Get queues action

This action gets a list of queues within your Jira Service Desk instance.

![Get queues action](/assets/get-queues-action.B8w28ARu.png)_Get queues action_

## Input

| Input field | Description |
| --- | --- |
| Service desk | The service desk where the queue resides |

## Output

The output of this action will be a list of datatree that contains information about the created Jira Service Desk queues.

Find out more about [Jira Service Desk queue object](https://developer.atlassian.com/cloud/jira/service-desk/rest/api-group-servicedesk/#api-rest-servicedeskapi-servicedesk-servicedeskid-queue-get).
