> The Get comment by ID action in the Jira Service Desk connector lets you retrieve a single comment on an issue in your service desk instance.

# Jira Service Desk - Get comment by ID action

This action gets a comment by ID in an issue within your Jira Service Desk instance.

![Get comment by ID action](/assets/get-comment-by-id-action.CURhClln.png)_Get comment by ID action_

## Input

| Input field | Description |
| --- | --- |
| Issue | Accepts the issue ID or key |
| Comment ID | ID of the comment to retrieve |

## Output

The output of this action will be a datatree that contains information about the created Jira Service Desk comment.

Find out more about [Jira Service Desk comment object](https://developer.atlassian.com/cloud/jira/service-desk/rest/api-group-request/#api-rest-servicedeskapi-request-issueidorkey-comment-commentid-get).
