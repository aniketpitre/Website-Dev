> The JumpCloud connector lets you automate directory management: create, update, search, and delete objects, lock or unlock users, and reset MFA.

# JumpCloud

[JumpCloud](https://jumpcloud.com/) is a cloud-based directory platform that centralizes user and device management and provides secure access to IT resources.

## API version

The JumpCloud connector uses the [JumpCloud API 1.0](https://docs.jumpcloud.com/api/1.0/).

## How to connect to JumpCloud

The JumpCloud connector uses API key authentication to connect to JumpCloud.

Complete the following steps to set up your JumpCloud connection:

1. Enter a **Connection name** that identifies which JumpCloud instance Workato is connected to.
   
2. Enter your JumpCloud **API key**. Refer to JumpCloud's [Accessing Your API Key](https://jumpcloud.com/support/jumpcloud-apis) guide to generate the **API key**.
   
3. Enter your JumpCloud account's **Organization ID**. Refer to JumpCloud's [Settings in the Admin Portal](https://jumpcloud.com/support/settings-in-admin-portal) guide to access your account's **Organization ID**.
   
4. Click **Connect** to complete the setup. ![JumpCloud sign-in dialog](/assets/jumpcloud-connect.DMQkHsqt.png)_Complete the connection fields and click **Connect**_
