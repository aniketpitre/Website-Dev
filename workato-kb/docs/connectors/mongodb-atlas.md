> The MongoDB Atlas connector enables you to automate cloud database workflows, inserting, updating, searching, and replicating documents at scale.

# MongoDB Atlas

[MongoDB Atlas](https://www.mongodb.com/cloud/atlas) is a fully-managed cloud database, developed by the folks who also created MongoDB.

Atlas handles all the complexity of deploying, managing, and healing your deployments on the cloud service provider of your choice (AWS, Azure, and GCP).

* * *

## Supported Features

The MongoDB Atlas connector supports the following:

- Instances deployed to Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP)
- SSL/TLS connections, which MongoDB Atlas instances use by default
- [Custom filter queries](/en/connectors/mongodb-atlas/guides/using-custom-filter-queries) for some actions

* * *

## Supported actions

The MongoDB Atlas connector supports these actions:

- [Delete documents](/en/connectors/mongodb-atlas/actions/delete-documents)
- [Insert documents](/en/connectors/mongodb-atlas/actions/insert-documents)
- [Replicate documents](/en/connectors/mongodb-atlas/actions/replicate-documents)
- [Search documents](/en/connectors/mongodb-atlas/actions/search-documents)
- [Update documents](/en/connectors/mongodb-atlas/actions/update-documents)
