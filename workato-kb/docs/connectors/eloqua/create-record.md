> The Create record action in the Eloqua connector lets you create new standard or custom object records in Eloqua.

# Eloqua - Create record action

The action `Create record` allows you to create standard records or custom records in Eloqua. To begin, you will first need to select the object type of the record you want to create.

![Select Eloqua record](/assets/record-select-record.Cz5MWZNN.png)_You can select standard or custom objects_

## Input

When you select the object you want to create, input fields relevant to the object you have selected are displayed. This includes any custom fields you may have attached to any standard or custom object.

![Eloqua record](/assets/create-record-field.DB-_NxBN.png)

## Output

When you select the object you want to create, output fields relevant to the object you have selected are displayed. This includes any custom fields you may have attached to any standard or custom object. The datapills correspond to the data of the record in Eloqua you have just created.

![Eloqua record](/assets/create-record-output-field.Bwt2IHuq.png)
