# Microsoft Entra ID - Update user action

The **Update user** action updates a user in Microsoft Entra ID.

## Input

| Input fields | Description |
| --- | --- |
| User | Choose a user from the drop-down menu. Alternatively, enter a custom value if the user is not listed. |

Refer to the [User schema](https://learn.microsoft.com/en-us/graph/api/resources/user?view=graph-rest-1.0#properties) section for optional field definitions.

## Output

This action has no output.
