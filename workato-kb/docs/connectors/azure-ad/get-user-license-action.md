# Microsoft Entra ID - Get user license action

The **Get user license** action retrieves license details for a user.

## Input

| Input field | Description |
| --- | --- |
| User | Choose a user from the drop-down menu. Alternatively, enter a custom value if the user is not listed. |

## Output

Refer to the [New group trigger](/en/connectors/azure-ad/new-group-trigger#output) output for more information.
