# Microsoft Entra ID - Update group action

The **Update group** action updates the properties of a group object in Microsoft Entra ID.

## Input

| Input field | Description |
| --- | --- |
| Group | Choose a group from the drop-down. Alternatively, enter a custom value if the group is not listed. |
| Description | Enter a summary of the group’s purpose. |
| Display name | Enter the name displayed for the group in the directory. |
| Mail enabled | Indicate whether the group supports email communication. |
| Mail nickname | Enter an alias for the group’s email address. This forms the local part of the email before the domain. |
| Category | Specify the category or purpose of the group. |
| Security enabled | Indicate whether the group is used for security purposes, such as granting access to resources. |
| Visibility type | Defines the visibility of the group. |
| Allow external sender | Indicate whether external users can send messages to the group. |
| Auto subscribe new members | Indicate whether new members are automatically subscribed to the group’s conversations or notifications. |
| Group types | Specify the group type, such as security, distribution, Microsoft 365, or dynamic. |

## Output

This action has no output.
