# Microsoft Entra ID - Get group details by ID action

The **Get group details by ID** action retrieves default group properties and relationships.

## Input

| Input field | Description |
| --- | --- |
| Group | Choose a group from the drop-down menu. Alternatively, enter a custom value if the group is not listed. |
| Output fields | Choose the output fields you plan to include in the response. |

## Output

Refer to the [New group trigger](/en/connectors/azure-ad/new-group-trigger#output) output for more information.
