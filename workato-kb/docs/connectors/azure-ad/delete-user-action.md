# Microsoft Entra ID - Delete user action

The **Delete user** action deletes a user in Microsoft Entra ID. Deleted users move to a temporary container and can be restored within 30 days. After 30 days, they are permanently deleted.

## Input

| Input field | Description |
| --- | --- |
| User | Choose a user from the drop-down menu. Alternatively, enter a custom value if the user is not listed. |

## Output

This action has no output.
