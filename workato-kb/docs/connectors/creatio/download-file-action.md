# Creatio - Download file action

The **Download file** action enables you to download a file from Creatio.

![Creatio Download file action](/assets/creatio-download-file-action.ExjFJmcF.png)_Creatio Download file action_

## Input

| Input fields | Description |
| --- | --- |
| Entity | Specify the entity you plan to delete. You can select it from the drop-down or define a custom value. |
| Entity column | Specify the entity column you plan to delete. You can select it from the drop-down or define a custom value. |
| File | Select the file you plan to delete from the drop-down menu or define a custom value. |

## Output

The output fields are determined by the object you select in the input. Map the relevant datapill from the data tree for downstream steps.
