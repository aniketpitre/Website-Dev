# Creatio - Update record action

The **Update record** action enables you to update any standard record, for example, **Account** using its `ID`.

![Creatio Update record action](/assets/creatio-update-record-action.o-iymLxP.png)_Creatio Update record action_

## Input

| Input field | Description |
| --- | --- |
| Object | Specify the object you plan to update. Fields dynamically load based on the selected object. First, select the object, then specify the ID of the record to update. |

## Output

The output fields are determined by the object you select in the input. Map the relevant datapill from the data tree for use in downstream steps.
