# Creatio - List attachments action

The **List attachments** action returns all attachments in the specified entity.

![Creatio List attachments action](/assets/creatio-list-attachment-action.DIRQHOVQ.png)_Creatio List attachments action_

## Input

| Input fields | Description |
| --- | --- |
| Entity | Select the entity you plan to list the attachments for. You can select it from the drop-down menu or define a custom value. |
| Entity column | Select the entity column you plan to list the attachments for. You can select it from the drop-down or define a custom value. |

## Output

The output fields are determined by the object you select in the input. Map the relevant datapill from the data tree for use in downstream steps.
