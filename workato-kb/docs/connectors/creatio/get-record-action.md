# Creatio - Get record action

The **Get record** action enables you to retrieve the details of a standard record, for example, **Account** using its `ID`.

![Creatio Get record action](/assets/creatio-get-record-action.BYBEsaOx.png)_Creatio Get record action_

## Input

| Input field | Description |
| --- | --- |
| Object | Specify the object you plan to retrieve. Fields dynamically load based on the selected object. First, select the object, then specify the ID of the record to retrieve. |

## Output

The output fields are determined by the object you select in the input. Map the relevant datapill from the data tree for downstream steps.
