# Creatio - Delete record action

The **Delete record** action enables you to delete a record in Creatio.

![Creatio Delete record action](/assets/creatio-delete-record-action.DJgdg1u4.png)_Creatio Delete record action_

## Input

| Input field | Description |
| --- | --- |
| Object | Specify the object you plan to delete. Fields dynamically load based on the selected object. |

## Output

This action doesn't have any output fields.
