# Syncro - Create record action

The **Create record** action creates a new record in Syncro.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the Syncro object to create. |

Additional input fields appear based on the object you select.

## Output

The output varies depending on the object type you select. For example, your output fields include the following if you select **Invoices** as the **Object**:

| Output field | Description |
| --- | --- |
| ID | Unique ID of the invoice. |
| Customer ID | ID of the customer linked to the invoice. |
| Customer business name | Business name of the associated customer. |
| Name | Name or title of the invoice. |
| Number | Invoice number. |
| Created at | Date and time the invoice was created. |
| Updated at | Date and time the invoice was last updated. |
