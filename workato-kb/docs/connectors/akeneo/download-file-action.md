# Akeneo - Download file action

The **Download file** action downloads an image or document stored in Akeneo. Provide the file URL returned by a product record to download the file for use in later recipe steps.

## Input

| Input field | Description |
| --- | --- |
| File URL | Paste the file URL returned by an Akeneo image or file attribute. The connector automatically extracts the required file reference and downloads the file from your connected Akeneo instance. |

## Output

| Output field | Description |
| --- | --- |
| File content | The binary content of the downloaded file. |
