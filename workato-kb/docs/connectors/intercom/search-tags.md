# Intercom - Search tags by user action

The **Search tags by user** action allows you to retrieve a list of tags associated with a specific user in Intercom by providing the user's unique identifier.

![Search tags by user action](/assets/search-tags-action.CcBtEhlP.png)_Intercom - Search tags by user action_

## Input

- User ID
- Enter the unique identifier for the user whose tags you plan to search.

## Output

<dl><dt>Tags</dt><dd>A collection of tags associated with the user.</dd><dd><dl><dt>Type</dt><dd>The entity type for tags.</dd><dt>ID</dt><dd>The unique identifier for each tag.</dd><dt>Name</dt><dd>The name of the tag.</dd><dt>List size</dt><dd>The total number of tags associated with the user.</dd><dt>List index</dt><dd>The index of the tag in the list of tags.</dd></dl></dd></dl>
