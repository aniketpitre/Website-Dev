# NetSuite REST - Update record action

The **Update record** action allows you to update a selected record in NetSuite REST.

![Update record action](/assets/update-record-action.nhGgF142.png)_Update record action_

## Input

| Input field | Description |
| --- | --- |
| Record | Select the type of record you plan to update, such as task, account, billing account, or assembly item. |
| Internal ID | The internal ID of the record you plan to update. For example: `161234`. |

## Output

| Output field | Description |
| --- | --- |
| Location | The location ID of the record updated. For example: `0w12345670733a2f2f747374647276313237383333362e737569746574616c6b2r6170692s6e657473756974652e636f6d2q89657276696365732f726573742b7265636f72642h76312z7461736b2f313635353535` |
| ID | The internal ID of the record updated. For example: `161234`. |
