# NetSuite REST - Delete record action

The **Delete record** action allows you to delete a selected record in NetSuite REST.

![Delete record action](/assets/delete-record-action.BTlqMOgH.png)_Delete record action_

## Input

| Input field | Description |
| --- | --- |
| Record | Select the type of record you plan to delete, such as task, account, billing account, or assembly item. |
| Internal ID | The internal ID of the record you plan to delete. For example: `161234`. |

## Output

There is no output for this action.
