> The Search contacts action in the Insightly connector lets you find contacts in your Insightly instance by contact ID, email, or tag.

# Insightly - Search contacts action

This action searches for contacts in your Insightly instance.

## Input

| Field | Description |
| --- | --- |
| Contact ID | A comma-separated list of the contact IDs. |
| Email | The email of the contact. |
| Tag | The tag of the contact. |

## Output

The output of this action is a datatree that contains information about the [contacts](https://api.insightly.com/v3.1/Help#!/Contacts/GetEntities) retrieved.
