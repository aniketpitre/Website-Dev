> The Search pipelines action in the Insightly connector lets you find pipelines in your Insightly instance by pipeline name.

# Insightly - Search pipelines action

This action searches for pipelines in your Insightly instance.

## Input

| Input field | Description |
| --- | --- |
| Pipeline name | The name of the pipeline. |

## Output

The output of this action is a datatree that contains information about the [pipelines](https://api.insightly.com/v3.1/Help#!/Pipelines/GetPipelines) retrieved.
