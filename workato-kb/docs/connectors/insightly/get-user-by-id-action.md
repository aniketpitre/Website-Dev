> The Get user by ID action in the Insightly connector lets you retrieve the details of a single user from your Insightly instance by user ID.

# Insightly - Get user by ID action

This action retrieves a user by ID in your Insightly instance.

## Input

| Field | Description |
| --- | --- |
| User ID | The ID of the user. |

## Output

The output of this action is a datatree that contains information about the [user](https://api.insightly.com/v3.1/Help#!/Users/GetUsers) retrieved.
