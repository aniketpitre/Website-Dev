> The Search users action in the Insightly connector lets you find users in your Insightly instance by first name, last name, or email.

# Insightly - Search users action

This action searches for users in your Insightly instance.

## Input

| Input field | Description |
| --- | --- |
| First name | The first name of the user. |
| Last name | The last name of the user. |
| Email | The email address of the user. |

## Output

The output of this action is a datatree that contains information about the [users](https://api.insightly.com/v3.1/Help#!/Users/GetUsers) retrieved.
