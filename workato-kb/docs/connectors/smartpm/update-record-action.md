# SmartPM - Update record action

The **Update record** action enables you to update the details of a specific record in SmartPM.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the object type to update. Fields load dynamically based on your selection. |

For example, if you select the **Project** object, fields such as **Project ID** and **Project metadata** appear.

## Output

Output fields depend on the selected object. Use these fields to map datapills in downstream steps.

For example, if you select the **Project metadata** object, the output includes fields such as the following:

| Output fields | Description |
| --- | --- |
| Project metadata | Additional metadata related to the project |
