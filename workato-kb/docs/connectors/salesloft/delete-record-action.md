# Salesloft - Delete record action

The **Delete record** action enables you to delete an object, such as an account, from Salesloft.

## Input

| Input field | Description |
| --- | --- |
| Object name | Select the object to be deleted from the drop-down menu. |
| ID | Provide the SalesLoft internal ID of the object you plan to delete. |

## Output

| Output fields | Description |
| --- | --- |
| Status | Returns the status of the delete action, for example, `Success`. |
