> The Oracle connector enables you to automate database workflows in Workato by selecting, inserting, upserting, and deleting rows or running custom SQL.

# Oracle

[Oracle database](https://www.oracle.com/database/index.html) is a multi-model database management system by Oracle Corporation. It can be hosted on-premise or in a private cloud.

## API version

The Oracle connector uses APIs from the Oracle database v12.

## Supported features

The Oracle connector supports the following features:

- All releases/versions of the Oracle database

## Triggers

The Oracle connector supports the following triggers:

- [New row trigger](/en/connectors/oracle/new-row-trigger)
- [New/updated row trigger](/en/connectors/oracle/updated-row-trigger)

## Actions

The Oracle connector supports the following actions:

- [Select actions](/en/connectors/oracle/select)
- [Insert actions](/en/connectors/oracle/insert)
- [Upsert actions](/en/connectors/oracle/upsert)
- [Delete actions](/en/connectors/oracle/delete)
- [Run custom SQL action](/en/connectors/oracle/run_sql)
- [Execute stored procedure action](/en/connectors/oracle/stored-procedure)
