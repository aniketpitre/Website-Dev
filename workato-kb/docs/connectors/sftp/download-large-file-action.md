> The Download large file action in the SFTP connector is now merged into a single Download file action that supports both small and large files.

# SFTP - Download large file action

Workato unified the [SFTP connector's](/en/connectors/sftp) **Download file** and **Download large file** actions into a single action called **Download file**, which supports small and large files. Refer to the [Download file](/en/connectors/sftp/download-file-action) documentation for more information.
