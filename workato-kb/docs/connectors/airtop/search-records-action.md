# Airtop - Search records action

The **Search records** action enables you to search and retrieve a list of sessions or windows in Airtop.

## Input

Input fields are dynamically generated based on the object you select. The following input field is common to all objects. Refer to the [Airtop](https://docs.airtop.ai/api-reference/airtop-api) documentation for more information on available input fields.

| Input field | Description |
| --- | --- |
| Object | Select the object you plan to search and retrieve records for. |

## Output

Output fields are dynamically generated based on the object you select. Refer to the [Airtop](https://docs.airtop.ai/api-reference/airtop-api) documentation for more information on available output fields.
