# Power BI - Update record action

The **Update record** action updates a record, such as a user, in Power BI.

## Input

| Input field | Description |
| --- | --- |
| Object | Select an object to update. Fields load dynamically based on your selection. |

## Output

Output fields depend on the selected object. You can use datapills from the datatree to map values in subsequent steps.
