> Add rows to a specific dataset table in Power BI.

# Power BI - Add row to a table action

The **Add rows to a table** batch action adds rows to a table in Power BI.

## Input

| Input field | Description |
| --- | --- |
| Dataset | Select a dataset from the drop-down menu. This is a collection of data that is imported, connected, or created in Power BI. |
| Table name | Select a table from the dataset. |
| Workspace | Select a workspace from the drop-down menu. This is a shared environment in Power BI where users can collaborate on reports, datasets, dashboards, and other assets. |

## Output

This action doesn’t return any output fields.
