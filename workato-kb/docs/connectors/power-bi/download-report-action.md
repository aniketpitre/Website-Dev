# Power BI - Download report action

The **Download report** action downloads the content of a report from a Power BI workspace.

## Input

| Input field | Description |
| --- | --- |
| Report ID | Enter the report ID to identify the report. |
| Workspace | Select a workspace from the drop-down menu. |

## Output

| Output field | Description |
| --- | --- |
| Report contents | The downloaded report file. |
