# Power BI - Delete record action

The **Delete record** action deletes a specified object from a Power BI workspace.

## Input

| Input field | Description |
| --- | --- |
| Object | Select an object to delete. Fields load dynamically based on your selection. |
| ID | Enter the **ID** of the object to delete. The ID must uniquely identify the object in the workspace. |

## Output

| Output field | Description |
| --- | --- |
| Success | Indicates whether the delete action was successful. |
