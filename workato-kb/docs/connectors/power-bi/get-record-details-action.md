# Power BI - Get record details action

The **Get record details** action retrieves the details of a specified object from a Power BI workspace.

## Input

| Input field | Description |
| --- | --- |
| Object | Select an object. Fields load dynamically based on your selection. |
| ID | Enter the ID of the report or dataset to retrieve. |
| Workspace | Select a workspace from the drop-down menu. |

## Output

Output fields depend on the selected object. You can use datapills from the datatree to map values in subsequent steps.
