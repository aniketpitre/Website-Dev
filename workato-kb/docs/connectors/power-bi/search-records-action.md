# Power BI - Search records action

The **Search records** action retrieves records that match the specified search criteria.

## Input

| Input field | Description |
| --- | --- |
| Object | Select an object to search. Fields load dynamically based on your selection. |

## Output

Output fields depend on the selected object. You can use datapills from the datatree to map values in subsequent steps.
