# Power BI - Create record action

The **Create record** action creates a record, such as a dataset, in Power BI. You can select an object and provide the required data.

## Input

| Input field | Description |
| --- | --- |
| Object | Select an object to create. Fields load dynamically based on your selection. |

## Output

Output fields depend on your selected object. You can use datapills from the datatree to map values in subsequent steps.
