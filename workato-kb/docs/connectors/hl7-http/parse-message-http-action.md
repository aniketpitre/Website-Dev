# HL7 HTTP - Parse message action

The **Parse message** action parses a message in HL7 HTTP.

## Input

| Input field | Description |
| --- | --- |
| Version | Enter the message version. |
| Model version | Enter the model version. |
| Message type | Enter the message type. |

## Output

| Output field | Description |
| --- | --- |
| Profile name | The name of the message profile. |
| Model version | The model version of the message. |
| Message type | The type of message. |
| Raw message | The raw message. |
| Message | The message contents. |
