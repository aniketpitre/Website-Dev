# HL7 HTTP - Parse message header action

The **Parse message header** action parses a message header in HL7 HTTP.

## Input

| Input field | Description |
| --- | --- |
| HL7 message | Enter the HL7 message to parse. |

## Output

| Output field | Description |
| --- | --- |
| Model version | The version of the model used to parse the message header. |
| Message type | The type of message. |
