# HL7 HTTP - New message trigger (real-time)

The **New message** trigger (real-time) monitors HL7 HTTP for new messages.

## Input

| Input field | Description |
| --- | --- |
| Model version | Select the model version of the new message. |
| Message type | Select the message type. |
| Custom message schema | Enter a custom schema to add segments and fields. |

## Output

| Output field | Description |
| --- | --- |
| Webhook type | The webhook type of the message. |
| Profile name | The profile name of the message. |
| Model version | The model version of the message. |
| Message type | The message type. |
| Raw message | The contents of the raw message. |
| HL7 message | The HL7 message contents. |
