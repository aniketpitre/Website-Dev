# UKG Pro (SOAP) - List report action

The **List report** action lists all preconfigured reports from your UKG Pro instance.

## Input

There are no inputs for this action.

## Output

| Output field | Description |
| --- | --- |
| Report name | The report name. |
| Report path | The report path. |
