# UKG Pro (SOAP) - Search record action

The **Search record** action searches for records in your UKG Pro instance that match the specified search criteria.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the UKG Pro object to search. Options include `Employee job`, `Employee compensation`, `Employee employment information`, `Employee person`, `Employee address`, `Employee contact`, `Employee phone information`, `Employee last pay statement`, `Pay statement by range`, `Employee user defined fields`, and `Terminated employee`. |
| Company code | Enter the company code to search records for. |
| Company name | Enter the company name to search records for. |
| Country | Enter the country to search records for. |
| Employee number | Enter the employee number to search records for. |
| First name | Enter the first name to search records for. |
| Last name | Enter the last name to search records for. |

## Output

| Output field | Description |
| --- | --- |
| Company code | The company code associated with search results. |
| Company name | The company name associated with search results. |
| Country | The country associated with search results. |
| Employee number | The employee number associated with search results. |
| First name | The first name associated with the search results. |
| Last name | The last name associated with the search results. |
| Addresses | Any addresses associated with the search results. |
