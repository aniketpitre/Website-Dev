# X - Search tweets action

The **Search tweets** action searches for tweets (posts) in X.

## Input

| Input field | Description |
| --- | --- |
| Query | Enter the query for matching tweets using criteria such as `keyword`, `hashtag,` or `user name`. |

## Output

Output fields are dynamically generated based on your search criteria including `Referenced tweets`, `ID`, `Mentions`, and `Public metrics`.
