# X - Search users trigger

The **Search users** trigger searches X for users.

## Input

| Input field | Description |
| --- | --- |
| User names (or user IDs) | Enter the user's user name (handle) or user ID. Don't include the @ symbol. For example, `janedoe`. |

## Output

| Output field | Description |
| --- | --- |
| Users data | Data about the user that was returned in the search including `Verified type`, `ID`, and `Description`. |
