# Typeform - New form trigger

The **New form** trigger monitors a Typeform workspace for newly created forms.

## Input

| Input field | Description |
| --- | --- |
| Workspace name | Select the workspace to monitor. |

## Output

| Output field | Description |
| --- | --- |
| ID | The unique identifier of the form. |
| Title | The title of the form. |
| Last updated at | The date and time when the form was last updated. |
| Self | The API endpoint URL for the form. |
| Theme | The API endpoint URL for the form's theme. |
| Links | Contains links relevant to the form. For example, `https://name.typeform.com/to/o3UmHl7`. |
| Settings | Contains the form's configuration settings. For example, `Is public` and `Is trial`. |
