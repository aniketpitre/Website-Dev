> The Search pages action in the Confluence connector lets you find pages by keyword, space name, or page title and return matching page details.

# Confluence - Search pages action

The **Search pages** action allows you to search for pages in Confluence.

## Input

| Input field | Description |
| --- | --- |
| Text | Enter keywords to search within the content of the pages. |
| Space name | Specify the name of the space where you plan to search for pages. |
| Page title | Input the title of the page if you plan to search for a specific page. |

## Output

| Output field | Description |
| --- | --- |
| Results | Includes comprehensive details about the Confluence page. |
