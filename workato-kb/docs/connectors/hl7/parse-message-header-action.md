# HL7 - Parse message header action

The **Parse message header** action extracts the model version and message type from an HL7 message header.

## Input

| Input field | Description |
| --- | --- |
| HL7 Message | Enter or provide a raw HL7 message. The message can use either newline (`\n`) or carriage return (`\r`) characters to separate segments. |

## Output

| Output field | Description |
| --- | --- |
| Model version | The HL7 model version extracted from the message header. |
| Message type | The HL7 message type extracted from the message header. |
