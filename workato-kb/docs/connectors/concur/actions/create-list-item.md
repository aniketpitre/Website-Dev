# SAP Concur - Create list item action

The **Create list item** action creates a new list item in SAP Concur.

## Input

| Input field | Description |
| --- | --- |
| List ID / List | Select the list to create the list item in or enter the list ID. |
| Short code | Enter the list item short code. This is the individual item's code. |
| Value | Enter the list item value or name. |
| Parent ID / Parent code | Enter the unique identifier of the parent list item or the long code of parent list item. |

## Output

| Output field | Description |
| --- | --- |
| ID | The unique identifier of the list item. |
| Code | The list item long code. |
| Short code | The list item short code. This is the individual item's code. |
| Value | The list item value or name. |
| Parent ID | The unique identifier of the parent list item. |
| Level | The hierarchical level of the list item in the list structure. |
| Is deleted | Indicates whether the list item has been deleted. |
| List ID | The unique identifier of the list this item belongs to. |
| Lists | Information about the lists that contain the list item. |
| ID (Lists) | The unique identifier of the list. |
| Has children | Indicates whether the list item has child items. |
