# SAP Concur - Get entry image URL action

The **Get entry image URL** action retrieves the image URL for a specific entry in SAP Concur.

## Input

| Input field | Description |
| --- | --- |
| Expense Report Entry ID | Enter the unique identifier of the expense report entry. |

## Output

| Output field | Description |
| --- | --- |
| Report Entry ID | The unique identifier of the expense report entry. |
| URL | The URL to access the receipt image for the entry. |
