# ADP Workforce Now

ADP Workforce Now is an HCM solution for midsized companies. It includes solutions for HR management, payroll, benefits, talent management, compliance, time and labor management, and analytics and benchmarking.

## API version

The ADP Workforce Now connector uses the ADP Workforce Now [API v2](https://developers.adp.com/build/api-explorer/hcm-offrg-wfn).

## How to connect to ADP Workforce Now on Workato

Complete the following steps to establish an ADP Workforce Now connection:

1. Click **Create > Connection** or press C twice.
   
2. Search for and select **ADP Workforce Now** as your connection on the **New Connection** page.
   
3. Provide a unique name for the connection in the **Connection name** field.
   
   ![Configured ADP Workforce Now connection](/assets/connection.DaGpHdAW.png)
   
4. Use the **Location** drop-down menu to select the project where you plan to store the connection.
   
5. Use the **Sandbox** drop-down menu to specify if the ADP Workforce Now account is a sandbox account.
   
6. Use the **Data center** drop-down menu to select the data center your ADP Workforce Now account belongs to. Options include **US** and **EU**. Defaults to **US**.
   
7. Enter the **Client ID** and **Client secret**.
   
8. Enter the contents of the **SSL client certificate** and **SSL client key** files.
   
9. Enter a **Custom CA certificate**. This is the key passphrase for SSL. It should be the same string used to generate the SSL key.
   
10. Use the **Unmask sensitive information?** drop-down menu to specify if sensitive information is returned in the response.
    
11. Click **Connect**.
