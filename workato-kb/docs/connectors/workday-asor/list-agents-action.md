# Workday ASOR - List agents action

The **List agents** action retrieves a list of agents in Workday ASOR.

## Input

This action doesn't require any input fields to configure.

## Output

| Output field | Description |
| --- | --- |
| Total | The total number of agents in your Workday ASOR instance. |
| Data | Includes information about the retrieved agents, such as `ID`, `Capabilities`, `Platform`, `Provider`, `Name`, `Supports authenticated extended card`, `Version`, `Workday config`, `Skills`, `URL`, and `Description` . |
