# LevelPath - Create record action

The **Create record** action creates a new record in LevelPath.

## Input

| Input field | Description |
| --- | --- |
| Object type | Required. Select the LevelPath object to create. |

Additional input fields appear based on the object type you select.

## Output

The output fields vary depending on the selected object type. For example, if you select **Supplier** as the **Object type**, the output includes the following fields:

| Output field | Description |
| --- | --- |
| ID | Unique identifier for the created supplier. |
| External ID | External reference ID. |
| Corpus ID | Corpus record identifier. |
| Name | Supplier name. |
| Website | Supplier website URL. |
| Employee ID number | Identifier for the supplier's employee. |
| Description | Text description of the supplier. |
| Primary category ID | ID of the primary category. |
| Ticker | Public stock ticker symbol. |
| Stock exchange | Stock exchange where the supplier is listed. |
| Fiscal year end | Month and day the fiscal year ends. |
| Domain | Supplier's email or web domain. |
| Status | Status of the supplier record. |
| Notes | Additional notes or comments. |
