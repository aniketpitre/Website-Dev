# SAP Business One - Update record action

The **Update record** action enables you to update a record in SAP Business One.

![SAP Business One - Update record action](/assets/update-record-action.D-EmSv2r.png)_SAP Business One Update record action_

## Input

| Input Field | Description |
| --- | --- |
| Object | Specify the object you plan to update. Fields load dynamically based on the object you select. |

## Output

There are no output fields for this action.
