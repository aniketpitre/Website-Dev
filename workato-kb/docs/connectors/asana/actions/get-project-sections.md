# Asana - Get project sections action (batch)

The **Get project sections** batch action retrieves sections of a project in Asana.

## Input

| Input field | Description |
| --- | --- |
| Project ID | Enter the project ID. You can find this value in the URL of the projects page. |

## Output

| Output field | Description |
| --- | --- |
| Sections | Array of sections in the specified project. |
| ID (Sections) | The unique identifier of each section. |
| Name (Sections) | The name of each section. |
