# Asana - Add task to section action

The **Add task to section** action adds a task to a section in Asana.

## Input

| Input field | Description |
| --- | --- |
| Section ID | Enter the ID of the section where you plan to add the task. |
| Task ID | Enter the ID of the task you plan to add. |
| Insert after task ID | Enter the ID of the task after which you plan to insert the new task. |
| Insert before task ID | Enter the ID of the task before which you plan to insert the new task. |

## Output

There is no output for this action.
