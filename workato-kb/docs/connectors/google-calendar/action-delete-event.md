# Google Calendar - Delete event action

The **Delete event** action removes an existing event from a calendar you specify.

> **ENSURE CALENDAR ACCESS**
> 
> Ensure the calendar you plan to modify is accessible from your connected account that you have the necessary permissions to delete events.

## Input

| Input field | Description |
| --- | --- |
| Calendar | Select the calendar from which you plan to delete an event. |
| Event ID | Enter the Google Calendar ID of the event you plan to delete. Alternatively, you can switch this field to **Enter event name** enter the name of the event you plan to delete. |
| Send notification? | Select whether to send notifications about the deletion of the event. This field may be deprecated based on the specific implementation in your system. |

## Output

This action does not have any output fields.
