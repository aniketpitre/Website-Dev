# Anaplan - Download file action

The **Download file** action allows you to download a file from Anaplan.

![Download file from Anaplan action](/assets/download-file-action.CKIx29zD.png)_Anaplan - Download file action_

## Input

| Input field | Description |
| --- | --- |
| Workspace | Select the Anaplan workspace from which you plan to download the file. |
| Model | Choose the model within Anaplan that contains the file you plan to download. |
| File | Select the file you plan to download in Anaplan. |

## Output

| Output field | Description |
| --- | --- |
| File ID | The unique identifier of the downloaded file in Anaplan. |
| File contents | The contents of the downloaded file. |
