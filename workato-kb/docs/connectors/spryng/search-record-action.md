# Spryng - Search record action

The **Search record** action searches for a specific record in Spryng.

## Input

| Input field | Description |
| --- | --- |
| Object type | Select the object type to search for. |
| Limit | Enter a quota for how many records to return. |
| Page | Enter the page number to return results from. Defaults to `1`. |

## Output

| Output field | Description |
| --- | --- |
| Total | The total number of records in the search results. |
| Per page | The number of records per page. |
| Current page | The current page that the search results are shown on. |
| Last page | The number of the last page of the search results. |
| Next page URL | The URL of the next page of the search results. |
| Previous page URL | The URL of the previous page of the search results. |
| From | The originator of the record returned in search results. |
| To | The recipient of the record returned in search results. |
| Subaccounts | Any subaccounts associated with the search results. |
