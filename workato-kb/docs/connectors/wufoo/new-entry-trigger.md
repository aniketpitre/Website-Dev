# Wufoo - New entry trigger

This trigger runs when a new entry is detected in Wufoo. The trigger checks for new entries every five minutes by default.

![New entry trigger](/assets/new-entry-trigger.TFHdVcDM.png)_New entry trigger_

## Input

| Input field | Description |
| --- | --- |
| Form name | Select the form you plan to monitor for new entries. |

## Output

The output for this action is a datatree containing information specific to the form you selected, including field names and questions.
