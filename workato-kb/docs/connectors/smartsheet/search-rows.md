# Smartsheet - Search rows action (batch)

The **Search rows** [batch action](/en/features/batch-processing) allows you to search for rows in Smartsheet that match specific text criteria.

![Search rows action](/assets/search-rows-action.y6IBrsrE.png)_Smartsheet - Search rows action_

## Input

| Input field | Description |
| --- | --- |
| Sheet name | The name of the sheet in Smartsheet you plan to search. Select from a list of your available sheets. |
| Text | The text string you're looking for. The action returns rows with a partial match to this string. |

## Output

| Output field | Description |
| --- | --- |
| Rows | A list of rows from the sheet that contain the specified columns for that sheet. |
