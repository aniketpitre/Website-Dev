# Filevine - Archive/Delete record action

The **Archive/Delete record** action archives a specified object in Filevine, such as a project or collection item.

## Input

Input fields load dynamically based on the selected **Object type**. For example, if you select the **Project** object, the following input fields are available:

| Input field | Description |
| --- | --- |
| Object type | Select the Filevine object to archive, such as **Project**. |
| Project ID | Select the ID of the project to archive. |

Additional input fields may appear depending on the object selected.

## Output

| Output field | Description |
| --- | --- |
| Success | Indicates whether the archive operation completed successfully. |
