# Filevine - Check batch limit action

The **Check batch limit** action verifies if a given batch size meets a specified threshold.

## Input

| Input field | Description |
| --- | --- |
| Amount requested | Enter the numeric value representing the requested batch size. |
| Limit | Enter the numeric value that defines the batch size limit. |
| Operation | Define the comparison logic to apply. |

## Output

This action doesn't return any output.
