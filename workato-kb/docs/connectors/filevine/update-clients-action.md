# Filevine - Update project clients action

The **Update project clients** action updates project-person associations in Filevine.

## Input

| Input field | Description |
| --- | --- |
| Project person pairs source list | Provide a list datapill containing project-person mappings. |
| Project ID | Specify the ID of the Filevine project. |
| Person ID | Specify the ID of the person to associate with the project. |

## Output

This action doesn't return any output.
