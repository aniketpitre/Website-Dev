# Filevine - Unlock document action

The **Unlock document** action removes the lock from a specified document in Filevine.

## Input

| Input field | Description |
| --- | --- |
| Document ID | Enter the ID of the document to unlock. |

## Output

| Output field | Description |
| --- | --- |
| Document ID | ID of the unlocked document. |
| Current version | Version number of the document. |
| Folder ID | ID of the folder containing the document. |
| Project ID | ID of the associated project. |
| Uploader ID | ID of the user who uploaded the document. |
| Upload date | Timestamp of the document upload. |
| User last viewed date | Last viewed timestamp of the document. |
| Hashtags | Tags associated with the document. |
| Links | Resource links related to the document. |
| Filename | Name of the document file. |
| Folder name | Name of the folder containing the document. |
| Size | File size of the document. |
| Uploader full name | Full name of the document uploader. |
| Organization ID | ID of the organization the document belongs to. |
