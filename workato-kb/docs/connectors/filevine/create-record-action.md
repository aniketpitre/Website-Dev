# Filevine - Create record action

The **Create record** action adds a new record to Filevine for a selected object type.

## Input

| Input field | Description |
| --- | --- |
| Object type | Select the Filevine object to create. |
| Project type ID | Select the ID of the project type. |
| Sections | Select the ID of the section where you plan to add the record. |

Additional input fields appear based on the selected object and section.

## Output

The output varies depending on the selected object type. It typically includes details of the created record.
