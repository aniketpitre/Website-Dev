# Freshservice - Restore ticket action

The **Restore ticket** action can help you restore deleted tickets.

## Input

| Input field | Description |
| --- | --- |
| Ticket ID | Provide the ID of the ticket you plan to restore. |

## Output

| Output field | Description |
| --- | --- |
| Success | Indicates the success of the restore ticket action. |
