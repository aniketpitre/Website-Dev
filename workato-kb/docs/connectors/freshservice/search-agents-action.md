# Freshservice - Search agents action

The **Search agents** action returns results that match all of your search criteria. Returns a maximum of 30 records.

## Input

| Input field | Description |
| --- | --- |
| Email | Provide the email ID of the agent. |
| Work phone number | Provide the work phone number of the agent. |
| Mobile phone number | Provide the mobile phone number of the agent. |
| Active | Select the boolean value from the drop-down menu. |
| State | Select the state from the drop-down menu. |

## Output

| Output field | Description |
| --- | --- |
| Agent ID | Unique identifier for the agent. |
| First name | First name of the agent. |
| Last name | Last name of the agent. |
| Email | Email address of the agent. |
| Language | Preferred language of the agent. |
| Job title | Job title or designation of the agent. |
| Work phone number | Work phone contact of the agent. |
| Work schedule ID | ID of the work schedule assigned to the agent. |
| Workspace IDs | List of workspaces the agent belongs to. |
| Workspace info | Additional details about the workspaces. |
| Member of pending approval | Groups the agent is pending approval for membership. |
| Observer of pending approval | Groups the agent is pending approval as an observer. |
| Mobile phone number | Mobile phone contact of the agent. |
| Address | Physical address of the agent. |
| Location ID | Unique identifier of the agent’s location. |
| Time zone | Time zone the agent operates in. |
| Time format | Preferred time format (12h/24h). |
| Background information | Additional background details about the agent. |
| Reporting manager ID | ID of the agent’s reporting manager. |
| Role IDs | List of role IDs assigned to the agent. |
| Roles | Roles assigned to the agent. |
| Department IDs | List of department IDs the agent belongs to. |
| Department names | Names of the departments the agent is part of. |
| Scoreboard level ID | ID of the agent's scoreboard level. |
| Scoreboard points | Points earned by the agent in the scoreboard. |
| Signature | Email signature of the agent. |
| Occasional | Indicates if the agent is an occasional agent (true/false). |
| Can see all tickets from associated departments | Indicates if the agent can view all tickets from associated departments (true/false). |
| Has logged in | Indicates whether the agent has logged in (true/false). |
| Active | Indicates if the agent account is active (true/false). |
| Auto assign tickets | Specifies if tickets should be auto-assigned to the agent (true/false). |
| VIP user | Specifies if the agent is a VIP user (true/false). |
| Group IDs | List of group IDs the agent belongs to. |
| Member of | Groups where the agent is an active member. |
| Observer of | Groups where the agent is an observer. |
| External ID | External system identifier for the agent. |
| Scopes | Permissions or access levels assigned to the agent. |
| Auto assign status changed at | Timestamp when the auto-assign status was last changed. |
| Last active at | Timestamp when the agent was last active. |
| Last login at | Timestamp when the agent last logged in. |
| Created at | Timestamp when the agent record was created. |
| Updated at | Timestamp when the agent record was last updated. |
| Custom fields | Additional custom fields associated with the agent. |
