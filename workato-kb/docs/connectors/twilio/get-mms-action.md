# Twilio - Get Media from MMS action

This action allows you to retrieve media, such as images, GIFs, or videos, from the Multimedia Messaging Service (MMS).

![Get media from MMS action](/assets/get-media-mms-action.C92riL4j.png)_Get media from MMS action_

## Input

| Input field | Description |
| --- | --- |
| SID | This is the string identifier of the MMS from which you plan to retrieve media. This provides a unique key that is used to identify specific resources. Each SID has 34 digits. |

## Output

The output for this action is a datatree containing the retrieved media from the MMS.
