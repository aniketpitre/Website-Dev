# Active Directory - Disable a user account action

The **Disable a user account** action disables a user account you specify in Active Directory.

## Input

| Input field | Description |
| --- | --- |
| User DN | Specify the distinguished name (DN) of the user account you plan to disable. |

## Output

The **Disable a user account** action does not have any output fields.
