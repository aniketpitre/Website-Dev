# Active Directory - Remove user from group action

The **Remove user from group** action removes a user account from a group you specify in Active Directory.

## Input

| Input field | Description |
| --- | --- |
| User DN | Specify the distinguished name (DN) of the user account you plan to remove from the group. |
| Group DN | Specify the distinguished name of the group from which you plan to remove the user account. |

## Output

The **Remove user from group** action does not have any output fields.
