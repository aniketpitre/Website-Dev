> The Delete entry action in the Active Directory connector lets you delete an entry you specify by distinguished name (DN).

# Active Directory - Delete entry action

The **Delete entry** action deletes an entry you specify in Active Directory.

## Input

| Input field | Description |
| --- | --- |
| Entry DN | Specify the distinguished name (DN) of the entry you plan to delete. |

## Output

The **Delete entry** action does not have any output fields.
