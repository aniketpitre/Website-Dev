# Active Directory - Move user to organizational unit action

The **Move user to organizational unit** action moves a user account to an organizational unit you specify in Active Directory.

## Input

| Input field | Description |
| --- | --- |
| User DN | Specify the distinguished name (DN) of the user account you plan to move. |
| Organizational unit DN | Specify the distinguished name (DN) of the organizational unit where you plan to move the user account. |

## Output

The **Move user to organizational unit** action does not have any output fields.
