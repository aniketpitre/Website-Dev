> The Delete file action in the On-prem files connector lets you delete an existing on-prem file at the relative path you specify.

# On-prem files - Delete file action

The **Delete file** action deletes an existing on-prem file. The file and filepath must exist for this action to work.

## Input

| Input field | Description |
| --- | --- |
| File to delete | Select or manually enter the [relative path](/en/connectors/on-prem-files#relative-path) to the file to delete. |

## Output

| Output field | Description |
| --- | --- |
| Deleted file | The [relative path](/en/connectors/on-prem-files#relative-path) to the deleted file. |
