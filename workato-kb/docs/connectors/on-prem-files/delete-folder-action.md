> The Delete folder action in the On-prem files connector lets you delete an existing on-prem folder, with an option to skip folders that aren't empty.

# On-prem files - Delete folder action

The **Delete folder** action deletes an existing on-prem folder. This action fails if the target folder doesn't exist.

## Input

| Input field | Description |
| --- | --- |
| Folder to delete | Select or manually enter the [relative path](/en/connectors/on-prem-files#relative-path) to the folder to delete. |
| Only delete empty folders? | Select whether to skip folders that aren't empty. |

## Output

| Output field | Description |
| --- | --- |
| Path to folder delete | The [relative path](/en/connectors/on-prem-files#relative-path) to the deleted folder. |
