# Ghost - Create record action

The **Create record** action creates a post or member in Ghost.

## Input

Input fields dynamically generate based on the object you select. The following field is common to all objects. Refer to the [Ghost Admin API](https://docs.ghost.org/admin-api) documentation for more information on available input fields.

| Input field | Description |
| --- | --- |
| Object type | Select the object to create. You can select `Post` or `Member`. |

## Output

Output fields dynamically generate based on the object you select. Refer to the [Ghost Admin API](https://docs.ghost.org/admin-api) documentation for more information on available output fields.
