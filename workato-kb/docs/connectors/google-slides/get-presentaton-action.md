# Google Slides - Get presentation details action

The **Get presentation details** action retrieves metadata and structural information for a specific presentation in Google Slides.

## Input

| Input field | Description |
| --- | --- |
| Presentation ID | Enter the unique ID of the presentation. You can find this in the URL. |

## Output

| Output field | Description |
| --- | --- |
| Presentation ID | Unique identifier of the presentation. |
| Page size | Dimensions of the slides (height and width). |
| Slides | List of slide objects, including text, images, and layout. |
| Title | Title of the presentation. |
| Masters | List of master slide definitions. |
| Layouts | List of slide layout definitions. |
| Locale | Locale setting for the presentation. |
| Revision ID | Identifier of the current version of the file. |
| Notes master | Notes master layout used across slides. |
