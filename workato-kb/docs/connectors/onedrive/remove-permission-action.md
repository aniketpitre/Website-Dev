# OneDrive - Remove permission action

The **Remove permission** action removes permission for a file or folder in Microsoft OneDrive.

## Input

| Input fields | Description |
| --- | --- |
| File/folder ID | Provide the ID of the file or folder for which you plan to remove the permission. For example, `01G65C3RKY7QJD67NCMVAYKVFGW3KBGK75`. |
| Permission ID | Provide the ID of the permission to remove. For example, `aTowIy5mfG1lbWJlcnNoaXB8ZGVtb0B3b3JrYXRvei5vbm1pY3Jvc29mdC5jb20`. |

## Output

| Output field | Description |
| --- | --- |
| Success | Indicates whether the permission was successfully removed. |
