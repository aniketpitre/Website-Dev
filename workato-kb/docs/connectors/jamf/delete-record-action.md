# JAMF - Delete record action

The **Delete record** action deletes a record from JAMF Pro. Supported objects are account users and computers.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the JAMF object type to delete. |

## Output

Output fields are dynamically generated based on the object you select.
