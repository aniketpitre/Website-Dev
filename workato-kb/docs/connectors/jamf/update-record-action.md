# JAMF - Update record action

The **Update record** action updates an existing record in JAMF Pro. The current connector version supports updating account users.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the JAMF object type to update. Available value: `Account user`. |

Additional input fields are dynamically generated based on the object you select.
