# JAMF - Search records action

The **Search records** action retrieves a list of records of a selected object type from JAMF Pro. Use it to look up computers, account users, computer invitations, departments, and Mac applications.

## Input

| Input field | Description |
| --- | --- |
| Search for | Select the JAMF object type to search for. |

Additional input fields are dynamically generated based on the object you select.

## Output

Output fields are dynamically generated based on the object you select.
