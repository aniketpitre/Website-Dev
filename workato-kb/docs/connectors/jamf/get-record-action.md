# JAMF - Get record action

The **Get record** action retrieves the details of a single record from JAMF Pro by ID or another unique identifier.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the JAMF object type to retrieve. |

Additional input fields are dynamically generated based on the object you select.

## Output

Output fields are dynamically generated based on the object you select.
