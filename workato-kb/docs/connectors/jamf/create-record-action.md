# JAMF - Create record action

The **Create record** action creates a new record in JAMF Pro. Supported objects are account users, MDM commands, computers, and computer invitations.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the JAMF object type to create. |

Additional input fields are dynamically generated based on the object you select.

## Output

Output fields are dynamically generated based on the object you select.
