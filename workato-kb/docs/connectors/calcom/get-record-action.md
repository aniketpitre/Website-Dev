# Cal.com - Get record action

The **Get record** action retrieves a booking, the available time slots for an event type, or a public booking link from Cal.com.

## Input

Input fields dynamically generate based on the object you select. The following input field is common to all objects. Refer to the [Cal.com](https://cal.com/docs/api-reference/v2/introduction) documentation for a complete list of input fields.

| Input field | Description |
| --- | --- |
| Object | Select the object type you plan to retrieve. Options include **Booking**, **Available time slots**, and **Booking link**. |

## Output

Output fields dynamically generate based on the object you select. Refer to the [Cal.com](https://cal.com/docs/api-reference/v2/introduction) documentation for a complete list of output fields.
