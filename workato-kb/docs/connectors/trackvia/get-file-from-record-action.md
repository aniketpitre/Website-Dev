# TrackVia - Get file from record action (File)

The **Get file from record** action retrieves a file from a TrackVia record you specify.

## Input

| Input field | Description |
| --- | --- |
| Application | Select the TrackVia application that contains the record from which you plan to retrieve a file. |
| View | Select the TrackVia view that contains the record from which you plan to retrieve a file. A TrackVia view is a set of filters and customizations linked to a data table in TrackVia. |
| ID | Specify the TrackVia ID of the record from which you plan to retrieve a file. |
| Field name | Specify the field from which you plan to retrieve a file. |

## Output

| Output field | Description |
| --- | --- |
| File name | The name of the file retrieved from the TrackVia record. |
| Content | The file's content retrieved from the TrackVia record. |
