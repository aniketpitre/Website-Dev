# TrackVia - Delete record action

The **Delete record** action deletes a TrackVia record you specify.

## Input

| Input field | Description |
| --- | --- |
| Application | Select the TrackVia application that contains the record you plan to delete. |
| View | Select the TrackVia view that contains the record you plan to delete. A TrackVia view is a set of filters and customizations linked to a data table in TrackVia. |
| ID | Specify the TrackVia ID of the record you plan to delete. |

## Output

| Output field | Description |
| --- | --- |
| Status | Displays the status of the API request for the **Delete record** action. |
