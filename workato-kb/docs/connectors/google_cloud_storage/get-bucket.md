> The Get bucket action in the Google Cloud Storage connector lets you retrieve the details of a single bucket by its bucket name.

# Google Cloud Storage - Get bucket action

This action will get the details of a bucket in your Google cloud storage instance.

## Input

| Field | Description |
| --- | --- |
| Bucket name **Required** | The name of the bucket to be retrieved. |

Object specific output fields will be dynamically rendered base on the objects you select.
