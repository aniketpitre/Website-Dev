> The Delete bucket action in the Google Cloud Storage connector lets you delete a bucket from a specified project by its bucket name.

# Google Cloud Storage - Delete bucket action

This action will delete a bucket in the Google Cloud Storage system.

## Input

| Field | Description |
| --- | --- |
| Project name **Required** | The name of the project where the bucket is located. |
| Bucket name **Required** | The name of the bucket to be deleted. |

## Output

| Field | Description |
| --- | --- |
| Successfully deleted | Whether the bucket was deleted. |
