> The Create bucket action in the Google Cloud Storage connector lets you create a new bucket with a unique name within a specified project.

# Google Cloud Storage - Create bucket action

This action will create a new bucket in the Google Cloud Storage system.

## Input

| Field | Description |
| --- | --- |
| Bucket name **Required** | The name of the bucket to be created. Bucket name must be unique. |
| Project name **Required** | The name of the project where the bucket needs to be created. |

## Output

Object specific output fields will be dynamically rendered base on the objects you select.
