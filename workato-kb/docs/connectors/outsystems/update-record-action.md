> The Update record action in the OutSystems connector updates a single record you specify by its ID in the selected module.

# OutSystems - Update record action

The Update record action updates a record you specify.

![Update record action](/assets/update-record-action.CeoC6DwE.png)_Update record action_

## Input

| Input field | Description |
| --- | --- |
| Module | Select the module that contains the record you plan to update. |
| Entity ID | Select the entity ID of the module. |
| ID | The ID of the record you plan to update. You can find the record ID in the OutSystems URL. |

## Output

| Output field | Description |
| --- | --- |
| Record | This entry contains information specific to the record attributes and other configurations, such as `ID` and `UPLOADDATETIME`, you selected for the OutSystems object. |
