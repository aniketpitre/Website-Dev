> The Update records batch action in the OutSystems connector updates multiple records you specify by their IDs in the selected module.

# OutSystems - Update records batch action

The Update record batch action updates records that you specify.

![Update records batch action](/assets/update-records-batch-action.BxSAm3E8.png)_Update records batch action_

## Input

| Input field | Description |
| --- | --- |
| Module | Select the module that contains the records you plan to update. |
| Entity ID | Select the entity ID of the module. |
| ID | The ID of the records you plan to update. You can find the record ID in the OutSystems URL. |

## Output

| Output field | Description |
| --- | --- |
| Entity | The entity ID of the module. |
| Number of records | The number of records updated for the batch action. |
