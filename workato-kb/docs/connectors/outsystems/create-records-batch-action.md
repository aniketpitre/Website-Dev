> The Create record batch action in the OutSystems connector creates multiple records at once in the module you select.

# OutSystems - Create record batch action

The Create record batch action creates records in the OutSystems module you select.

![Create records batch action](/assets/create-records-batch-action.xSBHHOQT.png)_Create records batch action_

## Input

| Input field | Description |
| --- | --- |
| Module | Select the module in which you plan to create records. |
| Entity ID | Select the entity ID of the module in which you plan to create records. |

## Output

| Output field | Description |
| --- | --- |
| Entity | The entity ID you selected for the action. |
| Number of records | The number of records created for the batch action. |
