# Insightly

[Insightly](https://www.insightly.com/) is a powerful CRM platform that combines project and business management tools to help businesses grow faster by building strong customer relationships.

## API version

The Insightly connector uses the [Insightly API v2.1](https://api.insight.ly/v2.1/Help).

## Prerequisites

Workato requires an API key to connect to Insightly. Refer to the Insightly [API Key and URL](https://support.insight.ly/en-US/Knowledge/article/2775#API%20Key%20and%20URL) guide to create an API key.

## How to connect to Insightly on Workato

Complete the following steps to set up an API key connection to Insightly in Workato:

1. Click **Create > Connection** or press C twice.
   
2. Search for `Insightly` and select it as your app.
   
3. Enter a name for your connection in the **Connection name** field.
   
4. Use the **Location** drop-down menu to select the project where you plan to store the connection.
   
5. Enter your API key in the **API Key** field.
   
6. Click **Connect**.
