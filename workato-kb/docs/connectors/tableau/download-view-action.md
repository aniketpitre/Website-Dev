# Tableau - Download view action

The **Download view** action returns an image or PDF of the specified view.

## Input

| Input field | Description |
| --- | --- |
| Download view as | Select the type of file you plan to download the view as. |
| View ID | Specify the Tableau ID of the view you plan to download. |

## Output

| Output field | Description |
| --- | --- |
| File contents | The content of the downloaded view. |
