# JumpCloud - Get object by ID action

The **Get object by ID** action retrieves data about an object you specify in JumpCloud.

## Input

| Field | Description |
| --- | --- |
| Object | Select the type of object you plan to retrieve. |
| Object ID | Provide the JumpCloud ID of the object you plan to retrieve. |

## Output

The **Get object by ID** action's output fields vary based on your selected **Object** type. Refer to JumpCloud's [API 1.0 documentation](https://docs.jumpcloud.com/api/1.0/index.html) for more information about the output fields for each type.
