# JumpCloud - Update user on system action

The **Update user on system** action updates a user’s settings on a system you specify in JumpCloud.

## Input

| Field | Description |
| --- | --- |
| User ID | Provide the JumpCloud ID of the user whose settings you plan to update. |
| System ID | Provide the JumpCloud ID of the system that contains the user. |
| Sudo enabled | Specify whether to enable sudo privileges for the user. |

## Output

The **Update user on system** action does not have any output fields.
