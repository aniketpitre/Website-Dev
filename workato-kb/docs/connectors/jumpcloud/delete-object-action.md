# JumpCloud - Delete object action

The **Delete object** action deletes an object you specify in JumpCloud.

## Input

| Field | Description |
| --- | --- |
| Object | Select the type of object you plan to delete. |
| Object ID | Provide the JumpCloud ID of the object you plan to delete. |

## Output

The **Delete object** action's output fields vary based on your selected **Object** type. Refer to JumpCloud's [API 1.0 documentation](https://docs.jumpcloud.com/api/1.0/index.html) for more information about the output fields for each type.
