> The Create object action in the JumpCloud connector lets you create a new object of the type you select, such as a user, system, or group.

# JumpCloud - Create object action

The **Create object** action creates a new object in JumpCloud.

## Input

| Field | Description |
| --- | --- |
| Object | Select the type of object you plan to create. |

> **ADDITIONAL INPUT FIELDS**
> 
> The recipe editor generates additional input fields based on the **Object** type you select. Use these fields to enter details for the new object. Refer to JumpCloud's [API 1.0 documentation](https://docs.jumpcloud.com/api/1.0/index.html) for more information about the input fields for each type.

## Output

The **Create object** action's output fields vary based on your selected **Object** type. Refer to JumpCloud's [API 1.0 documentation](https://docs.jumpcloud.com/api/1.0/index.html) for more information about the output fields for each type.
