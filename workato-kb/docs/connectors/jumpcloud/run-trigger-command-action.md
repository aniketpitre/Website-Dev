# JumpCloud - Run trigger command action

The **Run trigger command** action runs a trigger command you specify in JumpCloud.

## Input

| Field | Description |
| --- | --- |
| Command trigger name | Provide the name of the JumpCloud trigger command you plan to run. |

## Output

| Field | Description |
| --- | --- |
| Triggered | Displays the status of the trigger command in JumpCloud. |
