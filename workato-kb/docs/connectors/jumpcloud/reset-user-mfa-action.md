# JumpCloud - Reset user mfa action

The **Reset user mfa** action resets multi-factor authentication (MFA) and postpones its enforcement for a JumpCloud user you specify.

## Input

| Field | Description |
| --- | --- |
| User ID | Provide the JumpCloud ID of the user whose MFA you plan to reset. |
| Exclusion until | Specify the date and time until which to postpone MFA enforcement. |

## Output

| Field | Description |
| --- | --- |
| Reset | Displays the status of the API request for the **Reset user mfa** action. |
