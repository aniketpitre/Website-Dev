# JumpCloud - List objects by ID action (batch)

The **List objects by ID** batch action searches for JumpCloud objects in batches and returns a list of results matching the object type and ID you specify.

## Input

| Field | Description |
| --- | --- |
| Object | Select the type of objects you plan to search for. |
| Object ID | Provide the JumpCloud ID of the objects you plan to search for. |

## Output

The **List objects by ID** action's output fields vary based on your selected **Object** type. Refer to JumpCloud's [API 1.0 documentation](https://docs.jumpcloud.com/api/1.0/index.html) for more information about the output fields for each type.
