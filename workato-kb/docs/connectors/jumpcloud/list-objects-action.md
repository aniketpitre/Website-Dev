# JumpCloud - List objects action (batch)

The **List objects** batch action searches for JumpCloud objects in batches and returns a list of results matching the object type you specify.

## Input

| Field | Description |
| --- | --- |
| Object | Select the type of object you plan to search for. |

## Output

The **List objects** action's output fields vary based on your selected **Object** type. Refer to JumpCloud's [API 1.0 documentation](https://docs.jumpcloud.com/api/1.0/index.html) for more information about the output fields for each type.

> **MAXIMUM OUTPUT LENGTH**
> 
> The **List objects** action returns a maximum of 100 records from JumpCloud in ascending order.
