# Box - Delete file or folder action

The **Delete file or folder** action deletes a file or folder from Box. Set the **Delete folder content?** field to `true` if you plan to delete a folder that contains files or subfolders.

## Input

| Input field | Description |
| --- | --- |
| Type | Choose whether to delete a `file` or `folder`. The default is `file`. |
| File or folder | Select the file or folder you plan to delete. |
| Delete folder content? | Set to `true` if you plan to delete the folder along with all its contents. |

## Output

This action doesn't return any output.
