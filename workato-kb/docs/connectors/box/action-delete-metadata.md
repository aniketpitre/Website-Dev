# Box - Delete file metadata action

The **Delete file metadata** action deletes standard or custom metadata associated with a file in Box. An enterprise account is required to delete metadata templates.

## Input

| Input field | Description |
| --- | --- |
| File | Select the file from which you plan to delete metadata. |
| Metadata template | Choose the metadata template applied to the file. This option overrides the **Delete custom metadata** field if both are set. |
| Delete custom metadata? | Specify whether to delete custom metadata properties created for this file. |

## Output

This action doesn't return any output.
