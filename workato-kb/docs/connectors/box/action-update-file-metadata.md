# Box - Update file metadata action

The **Update file metadata** action updates metadata fields for a file in Box. You can update metadata based on standard templates or apply custom metadata from another file.

## Input

| Input field | Description |
| --- | --- |
| File ID | Enter the ID of the file you plan to update metadata for. |
| Metadata template | Select the metadata template used in the file. |
| Sample file ID with custom metadata | Enter the ID of a file containing custom metadata to apply. |

## Output

This action doesn't return output fields.
