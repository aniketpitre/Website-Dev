# Box - Resend sign request action

The **Resend sign request** action allows you to resend sign requests to all outstanding signers in the created list.

## Input

| Input field | Description |
| --- | --- |
| Sign request ID | Enter the ID of the sign request you plan to resend to outstanding signers. |

## Output

| Output field | Description |
| --- | --- |
| Status | Displays the status of the resend operation. |
