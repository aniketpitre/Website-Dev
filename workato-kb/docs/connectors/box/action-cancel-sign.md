# Box - Cancel sign request action

The **Cancel sign request** action allows you to cancel an existing sign request in Box.

## Input

| Input field | Description |
| --- | --- |
| Sign request ID | Enter the ID of the sign request you plan to cancel. |

## Output

| Output field | Description |
| --- | --- |
| Status | Indicates the status of the cancellation process. |
