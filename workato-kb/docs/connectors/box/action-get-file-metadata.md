# Box - Get file metadata action

The **Get file metadata** action retrieves metadata that has been applied to a file in Box. This action requires an **Enterprise account** to access metadata templates.

## Input

| Input field | Description |
| --- | --- |
| File | Select the file from which to fetch metadata. |
| Template list | Choose the metadata template(s) applied to the file. |
| Sample file ID with custom metadata | Provide the ID of a file that contains the custom metadata structure, if retrieving custom metadata. |

## Output

This action doesn't return any output.
