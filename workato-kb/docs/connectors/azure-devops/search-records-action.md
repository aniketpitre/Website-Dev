# Azure DevOps - Search records action

The **Search records** action searches for records in Azure DevOps.

## Input

Input fields are dynamically generated based on the object you select.

| Input field | Description |
| --- | --- |
| Object | Select the type of object to search for in Azure DevOps records. Object types include `project`, `board`, `board_column`, `build`, `build_log`, `run`, and `work_item`. |

## Output

Output fields are dynamically generated based on the object you select. Refer to the [Azure DevOps](https://learn.microsoft.com/en-us/rest/api/azure/devops/?view=azure-devops-rest-7.2) documentation for a complete list of output fields.
