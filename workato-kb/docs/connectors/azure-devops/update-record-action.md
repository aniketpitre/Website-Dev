# Azure DevOps - Update record action

The **Update record** action updates a record in Azure DevOps.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the object to update. |
| Project | Select the project where you plan to update a record. |
| ID | Enter the ID of the record, such as a Work item ID for a work item object. |
| Type | Select the work item type. |

## Output

This action has a large number of output fields. Refer to the [Azure DevOps](https://learn.microsoft.com/en-us/rest/api/azure/devops/?view=azure-devops-rest-7.2) documentation for a complete list of output fields.
