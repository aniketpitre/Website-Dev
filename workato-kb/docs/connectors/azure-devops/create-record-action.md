# Azure DevOps - Create record action

The **Create record** action creates a new record in Azure DevOps.

## Input

Input fields are dynamically generated based on the object you select. The following input fields are common to all object types:

| Input field | Description |
| --- | --- |
| Object | Select the object type of the record you plan to create. |
| Project | Select the project where you plan to create a new record. |

## Output

Output fields are dynamically generated based on the object you select. Refer to the [Azure DevOps](https://learn.microsoft.com/en-us/rest/api/azure/devops/?view=azure-devops-rest-7.2) documentation for a complete list of output fields.
