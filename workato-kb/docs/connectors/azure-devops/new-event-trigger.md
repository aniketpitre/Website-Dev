# Azure DevOps - New event trigger

The **New event** trigger monitors Azure DevOps for new events.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the object type to monitor for new events. |

## Output

Output fields are dynamically generated based on the object you select. Refer to the [Azure DevOps](https://learn.microsoft.com/en-us/rest/api/azure/devops/?view=azure-devops-rest-7.2) documentation for a complete list of output fields.
