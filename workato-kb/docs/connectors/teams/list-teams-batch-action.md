# Microsoft Teams - List teams (batch) action

The **List teams** batch action lists teams the authenticated user is a member of in Microsoft Teams.

## Input

This action has no input.

## Output

| Output field | Description |
| --- | --- |
| Team ID | The team unique identifier. |
| Display name | The team name. |
| Description | The team description. |
| Is archived | A boolean response (`true` or `false`) that indicates if the team is archived. |
| Tenant ID | The team tenant unique identifier. |
