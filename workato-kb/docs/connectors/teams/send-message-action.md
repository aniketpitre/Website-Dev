# Microsoft Teams - Send message action

The **Send message** action sends a message in Microsoft Teams.

## Input

| Input field | Description |
| --- | --- |
| Message destination | Select message destination. Options are `Channel message` and `Chat message`. |

The remaining input fields vary based on the message destination you select. Refer to the [Microsoft Teams](https://learn.microsoft.com/en-us/connectors/teams/?tabs=text1%2Cdotnet) guide for more information on available objects and fields.

## Output

The output of this action varies based on the message destination you select. Refer to the Microsoft Teams guide link in the [Input](#input) section for more information on available objects and fields.
