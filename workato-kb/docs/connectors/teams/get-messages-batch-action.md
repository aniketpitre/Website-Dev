# Microsoft Teams - Get messages batch action

The **Get messages** batch action gets messages from a channel, thread, or chat in Microsoft Teams.

## Input

| Input field | Description |
| --- | --- |
| Message source | Select the message source to retrieve. Sources include `Channel messages`, `Thread replies`, and `Chat messages`. |

The remaining input fields vary based on the message source you select. Refer to the [Microsoft Teams](https://learn.microsoft.com/en-us/connectors/teams/?tabs=text1%2Cdotnet) guide for more information on available objects and fields.

## Output

The output of this action varies based on the message source you select. Refer to the Microsoft Teams guide link in the [Input](#input) section for more information on available objects and fields.
