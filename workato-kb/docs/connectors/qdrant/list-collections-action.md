> List the names of all collections on a Qdrant cluster.

# Qdrant - List collections action

The **List collections** action returns the names of all collections on your Qdrant cluster.

## Input

This action has no input fields.

## Output

| Output field | Description |
| --- | --- |
| Usage | Resources the request used. Includes hardware usage and inference usage. |
| Time | The time the request took to process, in seconds. |
| Status | The status of the request. Returns `ok` when the request succeeds. |
| Collections | The names of the collections on the cluster. |
