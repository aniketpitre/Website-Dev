# Airwallex

[Airwallex](https://www.airwallex.com/) is a global payments platform that enables businesses to send and receive payments in over 150 currencies. This connector allows you to automate payments and transfers to and from your Airwallex account.

## Prerequisites

Ensure you have completed the following steps before using the Airwallex connector in Workato:

1. Sign in to the [**Airwallex**](https://www.airwallex.com/app/login) portal.
   
2. Go to account options and select **Developer**.
   
3. Click on **Manage API keys**.
   
4. Select the **Admin API key** or click **Create restricted API key** to create a new API key.
   
5. Enter a **Name** for the API key and provide **Access** for objects as per requirements.
   
6. Click **Create API key**.
   
7. Enter your account password if prompted by the system to verify the account.
   
8. Copy the **Client ID** and **API key** and store the values securely for later use.
   

## How to connect to Airwallex

1. Click **Create > Connection** or press C twice.
   
2. Search for and select **Airwallex** as your connection on the **New Connection** page.
   
3. Provide a unique name for the connection in the **Connection name** field.
   
   ![Airwallex Connection](/assets/airwallex-connection.PSID9z0L.png)_Airwallex Connection_
   
4. Use the **Location** drop-down menu to select the project where you plan to store the connection.
   
5. Enter the **Client ID** and **API key**.
   
6. Select the **Environment** of the Airwallex account.
   
7. Click **Connect**.
