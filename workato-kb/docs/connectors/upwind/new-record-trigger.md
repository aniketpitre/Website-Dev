# Upwind - New record trigger

The **New record** trigger monitors Upwind for new records.

## Input

| Input field | Description |
| --- | --- |
| Object | Select the Upwind object you plan to monitor for new Upwind records. |

## Output

Output fields are dynamically generated based on the object you select. Refer to the [Upwind](https://docs.upwind.io/restapi/v1/introduction) documentation for a complete list of output fields.
