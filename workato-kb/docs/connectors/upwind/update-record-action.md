# Upwind - Update record action

The **Update record** action updates a record in Upwind.

## Input

Input fields are dynamically generated based on the object you select. The following field is common to all object types:

| Input field | Description |
| --- | --- |
| Object | Select the Upwind object to update. |

## Output

Output fields are dynamically generated based on the object you select. Refer to the [Upwind](https://docs.upwind.io/restapi/v1/introduction) documentation for a complete list of output fields.
