# SAP Ariba - Search objects action

Use the **Search objects** action to search for an object in SAP Ariba.

> **COMPATIBLE APIS**
> 
> The SAP Ariba connector supports multiple APIs, and each API provides access to different objects and operations. Refer to the [Available APIs](/en/connectors/sap-ariba#available-apis) section to identify the APIs compatible with this action.

## Input

| Input field | Description |
| --- | --- |
| Object | Specify the object to search for, such as a Contract workspace. Additional fields load dynamically based on the object you select. |

## Output

The output of this action is determined by the object selected in the input. Use the data tree in the recipe editor to see all available output fields and map them to subsequent steps.
