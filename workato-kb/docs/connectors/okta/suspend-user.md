# Okta - Suspend an existing user action

This action suspends an existing user in Okta. This operation can only be performed on users with an ACTIVE status. The user has a status of SUSPENDED when the process is complete. Requires Organization Administrator or Super Administrator roles to use this action.

## Input

| Field | Description |
| --- | --- |
| User ID | The unique ID of the target user. |

## Output

| Field | Description |
| --- | --- |
| Suspended | Returns true if the user is successfully suspended. |
