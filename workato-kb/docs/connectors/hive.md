# Hive

Hive provides a project management and collaboration platform that helps teams plan, track, and execute work in a centralized workspace. Hive enables you to track tasks, communicate with your team, and manage project timelines in a centralized workspace.

## API version

The Hive connector uses the [Hive API](https://developers.hive.com/reference/introduction).

## Connection setup

Complete the following steps to create a Hive connection in Workato:

1. Provide a **Connection name** that identifies which Hive instance Workato is connected to.
   
   ![Connection setup](/assets/connection-setup.BUTuQDlH.png)_Hive connection setup_
   
2. Use the **Location** drop-down menu to select the project where you plan to store the connection.
   
3. Use the **Connection type** drop-down menu to select a connection type.
   
4. Enter your API key from your Hive profile in the **API key** field.
   
5. Enter your user ID from your Hive profile in the **User ID** field.
   
6. Enter your workspace ID from your Hive profile in the **Workspace ID** field.
   
7. Click **Connect**.
