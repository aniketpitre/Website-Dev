# OData - Update record action

The **Update record** action allows you to update a record in OData.

## Input

Input fields load dynamically based on the object you select. For example, the following input fields are available if you select **Sales order**:

| Input fields | Description |
| --- | --- |
| Object | Select the object to update the record for. |
| Sales order | Enter the numeric identifier for the sales order. |

## Output

Output fields load dynamically based on the object you select.
