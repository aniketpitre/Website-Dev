# OData - Execute operation action

The **Execute operation** action enables you to execute an operation in OData. The list of operations is dynamically generated based on the API endpoints found in the OData document. Standalone actions are shown in this execute operation action.

## Input

Additional input fields load dynamically based on the object you select.

| Input fields | Description |
| --- | --- |
| Object | Select the object to execute an operation on. |

## Output

Output fields load dynamically based on the object you select.
